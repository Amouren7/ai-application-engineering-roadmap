# 04.01｜Agent 干活会留下什么痕迹：过程、日志与改动清单

## 本节目标

分清 Agent 干活留下的三种痕迹，并知道每种该看哪一眼。

## 一句话结论

> Agent 不是黑盒，它每干一步都会留下痕迹；读懂这些痕迹，是后面验收的地基。

## 展开讲

你把任务交给 Agent 后，别急着盯"最终结果"。好的 Agent 在干活时会一路"报流水账"。

这些流水账就是痕迹。主要看三类。

### 三类痕迹一览

| 痕迹 | 长什么样 | 你该看什么 |
|-|-|-|
| 步骤说明 | "我先读文件 A""接下来分 3 步""第 2 步我改了 XXX" | 它是否按你任务书的顺序走，有没有跳过哪一步 |
| 改动清单 | "已修改 summary.py""新增了数据表.csv" | 它到底碰了哪些文件，有没有碰你没让它碰的 |
| 运行输出 | 它跑完打印出来的结果，或报错信息 | 结果对不对、报错出在哪个环节 |

> 记一个类比：**痕迹就是 Agent 的"行车记录仪"。** 出了事，你第一时间调行车记录仪，而不是反复问司机"你刚才干嘛了"。

### 三种痕迹，分别在什么时候出现

| 什么时候 | 会冒出哪种痕迹 | 你要做什么 |
|-|-|-|
| 刚接到任务 | 步骤说明（它说打算怎么做） | 看它理解的任务对不对，不对立刻纠正 |
| 干到一半 | 步骤说明 + 运行输出 | 看它有没有跑偏、有没有报错 |
| 干完 | 改动清单 + 运行输出 | 看它动了什么、结果对不对 |
| 需要你拍板 | 一句明确的询问 | 决定放行还是喊停 |

看懂这张表，你就知道**什么时候该盯屏幕**。

### 痕迹不是越多越好

痕迹多说明它肯报账，但也别被淹死。你只挑三样看：

1. **它碰了什么**——文件、数据、账号。
2. **它按没按顺序走**——你任务书里的步骤有没有被跳过。
3. **有没有意外动作**——发消息、删东西、装东西。

### 为什么这一步现在就要练

第 05 章讲验收与纠错。验收的前提是"你知道它干了什么"。

痕迹看不懂，验收就只能凭感觉；痕迹看懂了，验收才有抓手。

### 小橙的例子

小橙让 Agent 给她的文档学习助手加一个功能：文章太短时给提示。

Agent 干了 3 分钟，回复里有三段。

它先说"我读了 summary.py"，再说"我加了一个判断"，最后给出改动清单。

小橙当时只看了最后一句"完成"。后来文章一长一短地试，才发现短的还是会出错。

> 她漏看的，正是中间那两段痕迹。这次以后她养成一个习惯：**先看过程，再看结果。**

### 问答型 AI 也有痕迹，只是少

| 工具类型 | 有步骤说明吗 | 有改动清单吗 | 有运行输出吗 |
|-|-|-|-|
| 纯问答型 | 有时有（它自己说思路） | 基本没有 | 没有 |
| 办公综合型 | 有 | 有（以"改动说明"形式） | 有时有 |
| 开发型 Agent | 有，而且很细 | 有（标准 diff） | 有，含报错 |

> 用什么工具看什么痕迹。看不到改动清单，不代表你不用学——判断力是一样的。

## 照着做

拿你最近一次交给 Agent 的任务，练一遍"找痕迹"：

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 打开那次任务的对话记录 | 一大段它说的话 | 找不到就用新任务重做一次 |
| 2 | 找"步骤说明" | "我先…""接下来…"这类句子 | 一句都没有，说明它没报账，下次任务书里加一句"每步先说一句你在干什么" |
| 3 | 找"改动清单" | 文件名、`+`、`-` | 工具不支持，就退一步看它给的"改动说明" |
| 4 | 找"运行输出" | 结果文字或报错 | 没输出就问它"跑的结果贴出来" |
| 5 | 对照你任务书的步骤 | 它跳没跳步、有没有多余动作 | 跳步了就补一句"请按第 1、2、3 步顺序做" |
| 6 | 写下你的判断 | 三行字：它做了什么 / 对不对 / 下一步 | 写不出来，说明你还没看清 |

写下的这三行，就是你后面验收的底稿。

## 常见错误

- **错误一：只看最终结果。** Agent 说"完成"不等于真完成；痕迹和改动清单才是判断依据。
- **错误二：把步骤说明当废话。** "我先读了 A"这句话在告诉你它动了什么，别跳过。
- **错误三：痕迹太乱就放弃看。** 只挑"碰了什么、按没按顺序、有没有意外动作"三样看。
- **错误四：以为看不到改动清单就学不了。** 用问答型工具也能练判断力，换个形式而已。
- **错误五：事后才去找痕迹。** 对话一关就难找，边干边看最省事。

## 本节练习

5 分钟，手机就能做。找一个你刚交给 AI 的小任务，填三行：

```text
它碰了什么：【文件/数据/账号】
它按顺序走了吗：【是/否，跳过了哪一步】
有没有意外动作：【发消息/删东西/装东西/没有】
```

三行都填出来，就说明你已经会"看痕迹"了。
