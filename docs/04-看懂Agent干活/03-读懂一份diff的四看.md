# 04.03｜读懂一份 diff 的四看：文件、加、删、为什么

## 本节目标

用四个固定动作读完任何一份改动清单，30 秒内给出判断。

## 一句话结论

> 读 diff 只做四件事：改了哪些文件、加了什么、删了什么、它说为什么。

## 展开讲

上一节你认出了 diff 长什么样。这一节把它变成**四个固定动作**，练到不用想。

读 diff 时，你**不需要看懂代码语法**，只看四件事。

### 四看一览

| 看 | 看什么 | 为什么看 |
|-|-|-|
| 一看文件 | 清单开头列出的文件名 | 它有没有碰你没让它碰的文件 |
| 二看加了什么 | 带 `+` 的行 | 加的东西是不是你要的 |
| 三看删了什么 | 带 `-` 的行 | 删错东西比加错更麻烦 |
| 四看为什么 | Agent 附带的解释 | 理由成不成立，决定放不放行 |

> 四看的顺序不要换。先看"碰了什么"，再看"改得对不对"。

### 第一看：改了哪些文件

清单开头会列出文件名。你要对照任务书问一句：**我让它动的是这几个吗？**

| 情况 | 判断 | 动作 |
|-|-|-|
| 文件数和你预期一致 | 正常 | 继续往下看 |
| 多出一个你没提过的文件 | 可疑 | 问它"为什么动了 X，是我要求的吗" |
| 少了一个应该改的文件 | 没做完 | 说"Y 还没改，请补上" |
| 出现了配置文件、账号文件 | 高度可疑 | 立刻喊停，问清原因 |

### 第二看：加了什么

带 `+` 的行是新加的。你只看**方向和数量**，不看语法。

- 加的是你要求的功能吗？
- 加的东西有没有超出边界（比如它顺手加了个联网功能）？
- 加了几行？突然加 200 行，通常意味着它自作主张了。

### 第三看：删了什么

带 `-` 的行是被删掉的。这一看最容易被忽略，也最容易出事。

| 删的内容 | 风险 | 怎么办 |
|-|-|-|
| 删掉一行旧的写法 | 低，通常是替换 | 看新写法是不是替代它 |
| 删掉一整段功能 | 高 | 问"这段为什么删，以后还需要吗" |
| 删掉文件 | 最高 | 先确认有没有备份，再决定放行 |
| 删掉你的原始资料 | 极高 | 立刻喊停，别让它继续 |

### 第四看：它说为什么

负责任的 Agent 会在清单下面用大白话解释改动理由。

| 它说的理由 | 你该怎么判断 |
|-|-|
| "加了判断，空文章不会再卡住" | 具体、能对上改动 → 成立 |
| "优化了一下" | 太笼统 → 追问"优化了什么" |
| "顺手清理了不用的东西" | 危险信号 → 问清删了什么 |
| 没有任何解释 | 不算痕迹 → 要求它补一句理由 |

### 四看合起来，就是一次判断

小橙读到的那份清单，用四看走一遍是这样：

| 四看 | 她看到 | 她的判断 |
|-|-|-|
| 文件 | 只有 summary.py | 符合预期 |
| 加 | 三行，含"太短就提示" | 方向对得上需求 |
| 删 | 一行旧写法 | 被新写法替代了，正常 |
| 为什么 | "防止空文章卡死" | 理由成立 |

四条都对，她回复"可以，继续"。

### 什么时候该喊停

| 看到的情况 | 喊停还是继续 |
|-|-|-|
| 文件、加、删、理由四项都对得上 | 继续 |
| 有额外文件但解释得通 | 先问一句，再决定 |
| 删了你没让它删的东西 | 喊停，问清楚 |
| 理由说不出、或含糊 | 要求它重说，再决定 |

## 照着做

拿一份真实的改动清单（或本章样例），走一遍四看：

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 先找文件名 | 一串文件名 | 没有文件名，就要它补 |
| 2 | 数一数文件个数 | 1 个或几个 | 和你预期不符就记下来问它 |
| 3 | 扫一遍带 `+` 的行 | 新加的内容 | 看不懂就只看"加的是不是我要的功能" |
| 4 | 扫一遍带 `-` 的行 | 被删的内容 | 有整段被删，立刻标记 |
| 5 | 找它给的解释 | 一两句人话 | 没有就要求它补一句 |
| 6 | 四项写成一个判断 | "可以放行 / 先问一句 / 喊停" | 拿不准就选"先问一句" |
| 7 | 把判断发给它 | 它继续或停下 | 别忘了说"其他不用动" |

第 7 步那句"其他不用动"，能省掉很多返工。

## 常见错误

- **错误一：只数加了几行，不看删了几行。** 删错东西的代价通常比加错更大。
- **错误二：跳过"为什么"这一看。** 理由说不清，说明它自己也没想明白。
- **错误三：看不懂代码就说"我看不了"。** 四看里没有一项需要懂语法。
- **错误四：文件数不对也不问。** 多动一个文件就是多一个风险点。
- **错误五：一次让它改完再一起看。** 改动堆在一起，四看就失效了，小步看才看得清。

## 本节练习

5 分钟，手机就能做。对着本章样例填这张小表：

```text
一看文件：动了【几个】文件，是【文件名】
二看加：加了【N】行，方向是【……】
三看删：删了【N】行，内容是【……】
四看为什么：它的理由是【……】，我觉得【成立/不成立】
我的判断：【放行 / 先问一句 / 喊停】
```

六行都填出来，四看就练成了。
