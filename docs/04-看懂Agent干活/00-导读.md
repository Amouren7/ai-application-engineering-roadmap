# 04｜看懂 Agent 干活：过程、diff 与确认点

> 本章目标：你从"下完任务就干等结果"，升级到"能看懂它一路干了什么、改了什么，并在关键动作前决定放行还是喊停"。
> 一句话：这一章练的是"看"的能力，不是"写"的能力。

## 本章开始前：准备与产出

| 项目 | 说明 |
|-|-|
| 账号要求 | 一个能"读写文件、分多步干活"的 Agent 工具（办公综合型或开发型；纯问答型看不到改动清单） |
| 能否只用手机完成 | 部分可以。看改动清单和过程记录建议用电脑，屏幕大看得清 |
| 主线要不要写代码 | 不需要。本章出现的代码块只作"阅读样例"，看懂大意即可 |
| 预计用时 | 约 1 小时 40 分钟，建议分 3 次学完 |
| 本章产出 | 一份"痕迹检查记录"：过程痕迹 + 改动清单 + 你的判断 + 放行还是喊停 |

> 名词先解释一句：**Agent** 就是"会分多步干活的 AI"。
> 它不只回答你，还能自己动手改东西。

## 这一章在路线里的位置

第 03 章你学会了把任务写清楚。这一章回答下一个问题：**它写完了，你怎么知道它到底干了什么？**

| 你现在的状态 | 学完本章的状态 |
|-|-|
| 只盯最终结果，它说"完成"你就信 | 会先看过程痕迹，再看结果 |
| 不知道 diff 是什么，看到就跳过 | 能读出一份 diff 的四个要点 |
| 它一路自动跑到底，你中途没参与 | 关键动作前你会被问，你也会主动喊停 |
| 出了错只会说"重做一遍" | 能分清"该重试"还是"该补信息" |

## 怎么用这一章

| 情况 | 怎么学 |
|-|-|
| 你用的是开发型 Agent（能改文件） | 边学边做，每节都有能立刻上手的动作 |
| 你用的是办公综合型工具 | 看它给的"改动说明"，把 diff 那两节当"读改动清单"练 |
| 你手边只有问答型 AI | 也能学：本章重点是判断力，读样例同样有效 |
| 只有 30 分钟 | 学 03、04、07 三节，先拿到"看清单 + 喊停"的手感 |

> 一句话：看懂过程不是为了怀疑它，是为了让你敢放手用它。
