# 04.05｜什么时候让它停，什么时候放行

## 本节目标

分清"可以重试""该停下补信息""绝不能盲目重试"三种情况。

## 一句话结论

> 网络卡了可以重试，需求没说清不该重试，碰钱的动作绝不盲目重试。

## 展开讲

上一节讲"它什么时候该问你"。这一节反过来讲：**它出状况时，你该怎么决定。**

旧版教材里有一张"重试决策表"，全是工程师术语。这里把它改成人话，你只需记住三种情况。

### 三种情况一张表

| 遇到的情况 | 该不该让它重试 | 怎么做 |
|-|-|-|
| 网络波动、超时、临时卡顿 | 可以，重试 1–2 次 | 让它再跑一次，并把这次的出错信息一并给它 |
| 参数没给全、需求没说清 | 不该重试 | 先停下，把缺的信息补给它再继续 |
| 涉及钱、删除、对外发送的动作 | 绝不盲目重试 | 先查"动作到底发生了没有"，再决定下一步 |

> 核心心法：**重试解决的是"临时故障"，不是"没交代清楚"。**

需求错了，重试一百次还是错，还会把时间和钱都搭进去。

### 怎么一眼分辨是哪一种

问自己两个问题：

1. **它是不是"跑到一半卡住"了？** 是 → 多半是临时故障，可以重试。
2. **它是不是"做出来的东西不是我要的"？** 是 → 需求问题，重试没用。

| 现象 | 属于哪一类 | 你的动作 |
|-|-|-|
| "请求超时，请重试" | 临时故障 | 重试 1–2 次 |
| 页面转圈很久没反应 | 临时故障 | 重试 1 次，再卡就问它原因 |
| 结果格式完全不是你要的 | 需求没说清 | 停下，把格式要求补清 |
| 它说"缺少某文件" | 材料没给全 | 停下，把材料补上 |
| 它说"已发送邮件，但报错" | 危险 | 立刻去查邮件到底发没发 |

### 重试要带上"这次的出错信息"

只说"再试一次"，它可能用同样的方式再撞一次墙。

正确说法是：**"刚才报错说 XXX，请重试一次；如果是同样原因，停下来告诉我。"**

| 你怎么说 | 它怎么反应 |
|-|-|
| "再试一次" | 可能重复同样的失败 |
| "刚才报错 XXX，重试一次，同样原因就停下告诉我" | 有信息、有边界，效率高 |
| "重试 10 次直到成功" | 浪费时间，可能重复扣费 |

### 绝不盲目重试的动作，怎么处理

| 动作 | 重试前必须先做 |
|-|-|
| 已发送消息 | 去收件箱/已发送确认发了没有 |
| 已下单或付费 | 去订单记录确认扣没扣钱 |
| 已删文件 | 去回收站/备份确认还在不在 |
| 已对外发布 | 去线上看一眼是不是已经公开了 |

> 顺序永远是：**先查"发生了没有"，再决定下一步。** 反过来就是二次事故。

### 什么时候是"放行"

放行不是"它说完成就算"。放行的三个条件：

| 条件 | 怎么确认 |
|-|-|
| 改动清单对得上需求 | 用上一节的四看过一遍 |
| 结果你自己验过 | 拿一个你已知答案的输入试一次 |
| 没有遗留的不可逆动作 | 确认没有多发的消息、多扣的钱 |

三条都过，才叫放行。

### 小橙的一次重试判断

小橙的助手某天报"读取文件超时"。她没急着改需求，先让它重试一次，成功。

第二次报"文章太短"，她这次没重试。

因为她看出这不是卡顿，是需求没覆盖到的场景。

> 同样一句报错，判断不同，动作就不同。这就是本节要练的。

## 照着做

拿一次真实的报错，练一遍判断：

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 把报错原文完整复制下来 | 一段文字 | 只看到半句，就往下翻记录 |
| 2 | 判断属于哪一类 | 临时故障 / 需求问题 / 危险动作 | 拿不准就按更严重的那类处理 |
| 3 | 临时故障 → 让它重试一次 | 结果或同样报错 | 同样报错就停下，别再试 |
| 4 | 需求问题 → 补清要求再发 | 一份改写后的要求 | 说不清就回到 03 章补任务书 |
| 5 | 危险动作 → 先查是否已发生 | 确认发/扣/删了没有 | 不确定就先别继续 |
| 6 | 在任务卡里记一行 | "这次是 X 类，我做了什么" | 不记就学不到经验 |

第 6 步那一行记录，是你以后判断越来越快的来源。

## 常见错误

- **错误一：一出错就让它重试。** 需求没说清时，重试没用，先补信息再继续。
- **错误二：重试不带出错信息。** 它会用同样的方式再撞一次墙。
- **错误三：碰钱的动作直接重试。** 可能重复下单、重复扣费，先查再动。
- **错误四：把"它说完成"当放行。** 放行要过三条件，不是听一句话。
- **错误五：报错只看半句。** 后半句往往才是原因，复制完整再判断。

## 本节练习

5 分钟，手机就能做。想一个你最近遇到的报错，填三行：

```text
报错原文：【……】
属于哪一类：【临时故障 / 需求没说清 / 危险动作】
我的动作：【重试一次 / 补信息再发 / 先查是否已发生】
```

再想一个"绝不该盲目重试"的例子写下来，比如"让它重发一遍那封邮件"。
