# 10｜沉淀与复用：把做过的事变成下次能直接抄的资产

> 本章目标：把前九章攒下的成果，沉淀成三样能长期用的东西——一个随取随用的模板库、一份"我指挥 AI 交付了什么"的作品清单、一套带回本职的工作方法。

## 本章开始前：准备与产出

| 项目 | 说明 |
|-|-|
| 账号要求 | 用你手头已有的 AI 工具即可，本章不需要新账号 |
| 能否只用手机完成 | 可以。整理模板和作品清单，用备忘录或笔记 APP 就能做 |
| 主线要不要写代码 | 不需要。本章是收尾沉淀，全程不写代码 |
| 预计用时 | 约 1 小时 15 分钟，可分 3 次学完 |
| 本章产出 | 一个模板库（至少 3 个文件）+ 一份作品清单（至少 3 条）+ 一段三句话自我介绍 |

> 术语先说清：**沉淀**就是把这次做完的东西整理好存起来，让下次不用从头再来。
> **复用**就是下次遇到同类事，直接把存好的东西拿出来改几个字就用。

## 这一章在整个主线里的位置

前九章你一直在"做"：写任务书、看 Agent 干活、验收、纠错、做应用。

这一章不教新技能，它做一件更值钱的事——**把你会的东西留下来。**

| 你现在的状态 | 学完本章的状态 |
|-|-|
| 每个任务都从零开始想任务书 | 手边有模板库，改几个字就能跑 |
| 干完就忘了，说不清自己会什么 | 有一张能讲给人听的交付清单 |
| 会用了，但没带回工作 | 每周至少一件事交给 Agent 做 |
| 不知道自己算不算"会了" | 有三条可讲的事实当证据 |

> 一句话：前面九章是攒本钱，这一章是把本钱存进银行。

## 贯穿案例：小橙这一章做什么

小橙不会编程，目标是用 AI 做一个"文档学习助手"。

她已经跑通过 6 个真实任务，但每张任务书都散在聊天记录里。

本章她会：把 6 张任务书整理成模板库；挑 3 件写进作品清单；用三句话讲给同事听；再把"每周汇总销售邮件"这件事固定成模板。

她的进度会在 01、02、03、05 四节里具体出现。

> 建议顺序：先读 01 建立"为什么要存"的动机，再读 02 动手建库。
