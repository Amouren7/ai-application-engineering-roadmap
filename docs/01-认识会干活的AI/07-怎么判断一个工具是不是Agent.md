# 01.07｜怎么判断一个工具是不是Agent：四个问题当场判断

## 本节目标

学会用四个问题，当场判断一个 AI 工具能不能干活。

## 一句话结论

> 会读你的文件、会多步执行、会交出成品、动手前会问你——四条占三条以上，就是 Agent 工具。

## 展开讲

市面上的工具名字越来越花。名字不重要，**能不能干活才重要。**

这一节给你四个问题。任何工具，问一遍就有答案。

### 四个问题

| 问题 | 问什么 | 答"是"说明什么 |
|-|-|-|
| 问题一 | 它能读/写我电脑里的文件吗？ | 它有"手"，不只是嘴 |
| 问题二 | 它会自己安排多步、连续做完吗？ | 它有流程，不是一问一答 |
| 问题三 | 它做完会交给我一个成品（文件/改动）吗？ | 它给结果，不给建议 |
| 问题四 | 动手之前它会停下来问我吗？ | 它有边界意识，能放心用 |

前三个决定它"能不能干活"，第四个决定它"敢不敢用"。

### 四问的对照结果

| 工具 | 读文件 | 多步执行 | 交成品 | 会问你 | 判断 |
|-|-|-|-|-|-|
| 普通聊天 AI | 否 | 否 | 否 | — | 不是 Agent，是问答型 |
| 聊天 AI + 上传文件 | 读上传的 | 部分 | 部分 | — | 半个 Agent，够用 |
| 办公综合型工具 | 是 | 是 | 是 | 一般会 | 是 Agent |
| 开发型工具 | 是 | 是 | 是 | 会 | 是 Agent，能力最强 |

**四条占三条以上，就是 Agent 工具。** 占不到，就还是问答型。

### 每个问题怎么问出来

不用看说明书，用一件小事试。

**试问题一：** 让它读一个你电脑里的文件。

> "读一下我桌面的 `测试.txt`，告诉我第一行是什么。"

读得到 → 有手。读不到 → 它只能处理你贴进去的文字。

**试问题二：** 给它一个需要三步的活。

> "把这篇文章总结成要点，再存成 `要点.md`。"

它一口气做完 → 有流程。它每步都停下等你 → 流程弱。

**试问题三：** 看它最后给你什么。

给你一个文件名或一段改动说明 → 交成品。只给你一段文字 → 还是答案。

**试问题四：** 给它一个会改动东西的活。

> "把桌面那 10 个文件重命名。"

它先列出清单问你 → 可以放心。它直接改了 → 慎用。

> 第四问最重要。**一个不问就动手的工具，能力越强越危险。**

### 判断结果怎么用

| 你的任务 | 判断结论 | 怎么用 |
|-|-|-|
| 改一段话 | 不是 Agent | 用问答型，快 |
| 整理一批文件 | 是 Agent | 用它，但先让它列清单 |
| 做一个小应用 | 是 Agent，能力强 | 用它，但每步验收 |
| 不确定 | 先试四问 | 试完再决定，别猜 |

## 照着做

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 挑一个你手边的 AI 工具 | 一个工具 | 没装就用网页版先试前三问 |
| 2 | 问一：让它读一个文件 | 读到 / 读不到 | 读不到就在表上打叉 |
| 3 | 问二：给它一个三步任务 | 一口气做完 / 每步都停 | 只做一步就停，说明流程弱 |
| 4 | 问三：看它最后交什么 | 文件 / 一段文字 | 只给文字就再补一句"存成文件" |
| 5 | 问四：让它改一批文件，观察它问不问 | 先列清单 / 直接改 | 直接改就别把重要文件交给它 |

五步，十分钟。做完你就知道自己手上是什么档位的工具。

## 常见错误

- **错误一：看名字判断。** 名字里带 "Agent" 不代表它能干活，四问才算数。
- **错误二：只试前三问，跳过第四问。** 能干活但不问你，恰恰是最危险的组合。
- **错误三：用一次失败就否定工具。** 也可能是你没说清任务。先按 01.05 的"症状表"定位。
- **错误四：拿问答型硬做 Agent 的活。** 做不了就换工具，别跟工具较劲。

## 本节练习

5 分钟。给你手上那个工具打一次分：

```text
工具名：
问题一 能读我的文件：□是 □否
问题二 会多步执行：  □是 □否
问题三 交给我成品：  □是 □否
问题四 动手前问我：  □是 □否
结论：它是 □Agent 工具  □还是问答型
```

四个方框填完，你对这个工具的信任程度也就定了。
