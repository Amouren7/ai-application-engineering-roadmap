## 1. 最小环境：四条命令

只需确认四样东西在不在（Windows 用 PowerShell，按 Win 键输入 powershell 打开）：

```powershell
python --version   # 能显示版本号 = Python 装好了
git --version      # 能显示版本号 = Git 装好了
```

- Python：让电脑按你写的步骤执行的语言（可去 python.org 下载安装，安装时勾选 "Add Python to PATH"）。
- 一个编辑器：VS Code 或 Cursor（Cursor 自带 AI 帮手，适合本附录读者）。
- Git：给项目留"存档点"，改坏了能退回（可去 git-scm.com 下载）。
- 如果命令提示"不是内部或外部命令"：多半是安装时没勾 PATH，重装一次即可，别慌。

## 2. 最小 Python：六个概念看懂 80% 的代码

AI 应用的代码翻来覆去就这几样。每个概念配一个"它是什么"的人话解释：

| 概念 | 人话 | 长什么样 |
|-|-|-|
| 变量 | 贴了名字的盒子，存东西 | `name = "小橙"` |
| 列表 | 按顺序排好的盒子串 | `tasks = ["写周报", "开会"]` |
| 字典 | 贴标签的抽屉，按标签取 | `doc = {"title": "笔记", "text": "……"}` |
| 函数 | 可重复使用的小机器 | `def summarize(text): ...` |
| 循环 | 对一串东西逐个做同一件事 | `for t in tasks: print(t)` |
| 条件 | 如果……就…… | `if not text: print("文件为空")` |

> 你现在不需要会写。先做到：看到上面六行，能说出"这行大概在干嘛"。这就是"读懂"。

一个综合例子（每行都有注释，先读懂大意，别管语法细节）：

```python
# 下面这段代码由 Agent 生成。你只需要看懂大意：
# 它打开一个文件、统计字数并打印结果。
from pathlib import Path            # 引入"文件路径"工具

path = Path("notes.txt")            # 指向 notes.txt 这个文件
text = path.read_text(encoding="utf-8")  # 读出全部文字
print("字符数：", len(text))        # 打印字符数
```

## 3. 程序怎么"开口说话"：API 与 JSON（概念版）

当你让程序调用云端 AI（比如给模型发一段文字要摘要），双方通过 HTTP 接口通信：

- **API**：程序与云端服务之间"约定好的服务窗口"——你按格式发请求，它按格式回结果。
- **JSON**：一种结构化文本，像"机器能读的表单"。模型返回的结果常常是 JSON，程序要解析它。
- **密钥（API Key）**：你的"门禁卡"，证明你有权限调用。铁律：**只放在环境变量里，绝不写进代码、截图、公开仓库。**

```text
你的程序
  ↓ 发送模型名、任务、文字、输出要求
云端模型服务
  ↓ 返回文本或结构化结果
你的程序（校验、保存、展示）
```

> 到这里，"程序调 AI"就不再神秘：它和你用聊天工具提问本质一样，只是把"打字发送"换成了"程序自动发送"。

## 4. 一次真实的模型调用（阅读样例）

> 下面代码由 Agent 生成。不同厂商 SDK 略有差异，以你实际使用的官方文档为准；你只需看懂数据流：创建连接 → 发请求 → 拿结果。

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["OPENAI_API_KEY"])  # 从环境变量读密钥

response = client.responses.create(
    model="your-model",                    # 换成实际模型名
    input="用三句话解释什么是 Agent。",
)

print(response.output_text)                # 打印模型回答
```

如果报错，把**完整报错**复制给 AI 让它解释——你已经会"驾驶"，这只是把驾驶对象换成代码。
