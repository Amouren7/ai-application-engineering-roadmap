# 08.02｜敏感数据：交之前先问自己三句

## 本节目标

学会用三句话判断一份材料能不能给 AI，不会判断就脱敏。

## 一句话结论

> 只要"能不能识别到人"答有、"泄露最坏后果"不是无所谓，就先脱敏，再给 AI。

## 展开讲

**敏感数据** = 一旦泄露会造成损失的数据，比如个人信息、公司机密、合同、薪酬。
判断"能不能交"别凭感觉，用三句话过一遍。

### 三句话，一句话一个问题

| 第几问 | 你问自己 | 举例答案 | 答完怎么用 |
|-|-|-|-|
| 第一句 | 这是什么数据？ | 工作报告 / 合同 / 聊天记录 | 先给它定个身份 |
| 第二句 | 里面有没有能识别到人的信息？ | 姓名、工号、电话、身份证号、地址、照片 | 答"有"就要脱敏 |
| 第三句 | 如果泄露，最坏后果是什么？ | 自己尴尬 / 公司罚款 / 客户投诉 / 法律纠纷 | 答"无所谓"才能直接给 |

**能识别到人的信息**，就是"光看这一条就能找到具体某个人"的信息。

判断规则只有一条：**第二问答"有"、第三问不是"无所谓"，就先脱敏。**

### 第三问怎么答才不糊弄

很多人卡在第三问，因为"最坏后果"听起来很虚。换成下面这张表就好答了：

| 材料 | 泄露后的最坏后果 | 结论 |
|-|-|-|
| 自己的读书笔记 | 自己尴尬一下 | 可以直给 |
| 团队周报（含姓名） | 同事关系受影响 | 先脱敏 |
| 客户投诉记录 | 客户投诉升级、公司赔偿 | 先脱敏 |
| 劳动合同 | 法律纠纷 | 先脱敏，或干脆不给 |
| 薪酬明细 | 劳动仲裁、公司罚款 | 先脱敏，且只给结构 |
| 账号密码 | 财产损失 | 绝不给 |

规律很清楚：**后果越"往外扩"，越要脱敏。**

### 先脱敏，再给 AI

**脱敏** = 把能识别到人的信息换成假名，结构和规律保留给 AI 用。
AI 要的是"字段规律"，不是"真人是谁"。

以一份报销明细为例：

| 字段 | 原样（别给） | 脱敏后（可以给） |
|-|-|-|
| 姓名 | 王芳 | 张三 |
| 工号 | 04821 | 001 |
| 电话 | 138xxxx1234 | 删掉 |
| 邮箱 | wangfang@abc.com | 删掉 |
| 部门 | 市场部二组 | 市场部（去掉组号） |
| 金额 | 5280.00 | 约 5000（只留数量级） |
| 事由 | 拜访 XX 客户 | 客户拜访 |

> 一个口诀：**名字换成"张三/李四"，工号换成"001/002"，电话邮箱删掉，金额只留数量级。**

### 脱敏的三个级别，按风险选

| 级别 | 做什么 | 什么时候用 |
|-|-|-|
| 轻 | 只删电话、邮箱、身份证号 | 材料里没有真实姓名 |
| 中 | 姓名换张三、工号换 001 | 大部分内部表格 |
| 重 | 姓名、工号、金额、部门全换或只留结构 | 薪酬、合同、客户隐私 |

不确定选哪级，就选重的那级。**脱敏过头顶多多花一分钟，脱敏不够是一次事故。**

### 什么算"能识别到人的信息"

第二问最容易答错，因为很多人只想到姓名。下面这张表照着扫：

| 算识别信息 | 为什么 | 怎么处理 |
|-|-|-|
| 姓名、照片 | 直接指向人 | 换成张三 / 删掉 |
| 工号、员工编号 | 公司内部能对上人 | 换成 001 |
| 电话、邮箱、微信号 | 一眼找到本人 | 删掉 |
| 身份证号、银行卡号 | 直接是身份凭证 | 删掉，绝不能给 |
| 家庭住址、定位 | 能定位到人 | 删掉，或只留城市 |
| 订单号、客户编号 | 后台一查就是人 | 换成 001 序号 |
| 部门 + 岗位 + 入职时间 | 组合起来常能唯一确定 | 至少去掉一项 |

最后一条最隐蔽：**单个字段不敏感，组合起来就能定位人。**

### 小橙的做法

小橙要 Agent 整理一份培训签到表，原表里有 60 个真名和工号。
她先做了三件事：

1. 姓名全部换成"学员01…学员60"。
2. 工号列整列删掉。
3. 只保留"部门 + 是否签到 + 时长"三列。

Agent 照样能统计出"哪个部门签到率最低"，而她没交出去任何一个真人。

## 照着做

拿一份你手边的真实材料，走一遍：

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 问第一句：这是什么数据 | 一个词，如"客户投诉记录" | 说不清就先按最敏感处理 |
| 2 | 扫一遍找识别信息 | 圈出姓名、工号、电话、地址、照片 | 漏了不确定的，也算"有" |
| 3 | 问第三句：最坏后果 | 一句具体的话 | 想不出后果，就当"有后果" |
| 4 | 决定脱敏级别 | 轻 / 中 / 重 | 犹豫就选重 |
| 5 | 动手替换 | 一张改过的表 | 替换不干净，就整列删掉 |
| 6 | 再扫一遍确认 | 找不出一个真人 | 还能找到，回第 5 步 |

第 6 步是硬要求：**给出去之前，你自己先当一次"泄密者"去找真人。**

## 常见错误

- **错误一：把敏感数据顺手贴进去问一句。** 问一句也可能被记录、被用于训练。先脱敏，再问。
- **错误二：只删姓名，忘了工号能对上人。** 工号、邮箱、手机号、订单号都能定位到人，一起处理。
- **错误三：以为"打码"就等于脱敏。** 用星号盖住一部分，原始内容还在文件里。要真的替换或删除。
- **错误四：金额不动。** 金额加部门，往往就能反推出是谁。只留数量级更安全。
- **错误五：以为脱敏一次就永久有效。** 新任务要重新走一遍三问，材料换了风险就变了。
- **错误六：第二问答"大概没有"。** "大概"就是"有"。不确定的字段一律当识别信息处理。

## 本节练习

5 分钟，手机就能做。复制下面这张表，用你自己的材料填两行：

```text
材料名称：【……】
第一句 这是什么数据：【……】
第二句 有没有识别到人的信息：【有/没有】具体是：【……】
第三句 泄露最坏后果：【……】
结论：【直接给 / 脱敏后给 / 不给】
```

填完把你替换后的版本和原版并排放，看一眼：还能不能认出是谁？
