> 08 安全成本与边界 ｜ 本章收尾

# 08｜本章验收与下一步

## 常见误区（本章汇总）

- **误区一：只要是大厂出的工具，就什么都敢交。** 大厂不等于零风险，泄露的后果还是你担。判断标准是"数据敏不敏感"，不是"工具名气大不大"。
- **误区二：把敏感数据"顺手贴进去问一句"。** 问一句也可能被记录、被用于训练。先脱敏，再问。
- **误区三：以为设了预算上限就万事大吉。** 还要确认它真的"用完即停"——空转也在花钱。
- **误区四：重要结论 AI 说"没问题"就信了。** 幻觉不会自己承认，出处要你自己核。
- **误区五：出事了第一反应是"再让它修一下"。** 先停、先收权，再谈补救。
- **误区六：把"能交"理解成"随便交"。** 能交指的是资料公开、后果可控，不是可以不看结果。
- **误区七：把"要小心"当成"不能交"。** 这一栏是换交法：先让它说第一步计划，你确认再继续。
- **误区八：只删姓名，忘了工号能对上人。** 工号、邮箱、手机号、订单号都能定位到人，一起处理。
- **误区九：看到有出处就当过关。** 出处本身也可能是它编的，要回原文亲眼看到。
- **误区十：嫌日志烦，随手关掉。** 关了等于把行车记录仪砸了，出事只能认。
- **误区十一：只停任务，不收授权。** 它下次还能动你的东西；停和收是两件事。
- **误区十二：应用改动前不备份。** 没有"上一个能用的版本"，就没有回滚。
- **误区十三：只写"做什么"，不写"不许做什么"。** 第 2 查最常被漏，补三句边界就好。
- **误区十四：第 3 条答"我大概能看出来"。** "大概"不算过；要能说出具体怎么核。

## 本章验收

- [ ] 能不看表，说出至少 2 个"绝不能直接交"的例子（如账号密码、对外发布、人事决定）
- [ ] 能把"能花钱、能对外说话、能泄露隐私、能替你做决定"这条万能底线背下来
- [ ] 能用自己的话解释"敏感数据三问"和"先脱敏再给 AI"
- [ ] 把一段含姓名/工号/电话的材料做了脱敏示范（换成张三/001）
- [ ] 能说出日志的五项内容，并知道重要任务要自己留档
- [ ] 能解释"谁用谁负责"，并给小橙的核对清单补上一条自己的检查项
- [ ] 能说出控制成本的四个动作（先问价 / 免费额度 / 预算上限 / 用完即停）
- [ ] 能按顺序说出四个刹车（停止 → 收权 → 断开 / 回滚）
- [ ] 背下"交任务前 5 查"，并在下一次真实任务里实际用过一次
- [ ] 手里有一张三栏清单，写着自己真实的材料分类

## 可选动手（想做就做，不做不影响主线）

**给你的下一单"上保险"：** 拿出你手上一个马上要交给 AI 的真实任务，用"交任务前 5 查"逐条过一遍。

过不了的补上，比如补一句：

```text
不要联网搜索，只用我给你的材料。
不要花钱、不要订阅任何服务。
不要删除或覆盖原文件，需要改就另存一份。
```

然后把这份清单存进你的任务卡。

**进阶可选：** 给小橙的核对清单再加一条你自己的检查项，比如"凡是数字都问一句出处"。

**再进阶可选：** 找出你正在用的工具的日志入口，截图存下来，下次出事不用现找。

## 本章小结

边界划清了，你才敢用 AI。三栏分类管住"能交什么"，三问加脱敏管住"敏感数据"。

日志是你的行车记录仪，重要结论要自己核，钱要估量级、设上限、用完即停。

最后收成一张 5 秒清单：交之前扫一眼，出事先停再收权。
