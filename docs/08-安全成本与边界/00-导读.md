# 08｜安全、成本与边界：什么能交、什么绝不能交

> 本章目标：给你一套"交任务前的安全习惯"——知道什么能交给 Agent、什么要小心、什么绝不能交，以及出事了怎么停、钱花多了怎么控。
> 这一章不是让你怕 AI，而是让你敢用 AI。边界划清楚了，你才敢把活交出去。

## 本章开始前：准备与产出

| 项目 | 说明 |
|-|-|
| 账号要求 | 一个 AI 聊天工具即可；本章是"想清楚再交"，不强制装新工具 |
| 能否只用手机完成 | 可以。本章全是判断和清单，手机就能练 |
| 主线要不要写代码 | 不需要。本章没有任何需要你写的代码 |
| 预计用时 | 约 95 分钟，建议分 2 次学完 |
| 本章产出 | 一张"能交 / 要小心 / 绝不能交"三栏清单 + 交任务前的 5 个安全检查 |

> 先记住本章唯一一句话：**Agent 是工具，签字的是你。**
> 它干得再快，结果错了，责任还是你的。

## 这一章在整条路线里的位置

前面七章教你"怎么把活交出去、怎么验收"。
这一章补上另一半：**哪些活根本不该交出去。**

| 你现在的状态 | 学完本章的状态 |
|-|-|
| 想到什么就贴什么给 AI | 贴之前先过三栏、再过三问 |
| 觉得"大厂工具应该没事" | 按数据敏不敏感判断，不按工具名气判断 |
| 出事了第一反应是让它再改 | 先停、再收权、最后才补救 |
| 做应用时不知道钱怎么花的 | 会估量级、会设上限、会用完即停 |
