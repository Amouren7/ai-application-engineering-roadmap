> 03 任务书方法论 ｜ 本章收尾

# 03｜本章验收与下一步

## 常见误区（本章汇总）

- **误区一：把四要素当文采题。** 任务书不需要漂亮，只需要"别人拿去能照做"。朴素但字段齐全，远胜辞藻华丽但啥也没说。
- **误区二：一次把大目标全丢给 AI。** "帮我做个万能助手"注定失败，先拆成 3–5 步。
- **误区三：只说"格式"，不说"空的地方怎么办"。** 要写"负责人未知写待定、原文没写写待定"，否则它就会编一个填进去。
- **误区四：改要求时一次改一堆。** 一次只改一处，你才知道是哪处起了作用。
- **误区五：做完不验收就交差。** "它说做完了"不等于"做对了"；拿验收标准一条条打钩才算完。
- **误区六：用感受词代替要求。** "专业一点""简洁一点"——AI 无法执行感受，换成数字和形态。
- **误区七：以为 AI 能读你电脑里的文件。** 不上传、不粘贴，它看不到。二选一。
- **误区八：材料一次塞太多。** 十几篇文档一起贴，它会漏看中间。分批给，或只给最相关的。
- **误区九：边界写一次就永久生效。** 新任务要重写，它不记得上一次。
- **误区十：验收标准写超过 5 条。** 你核到第 4 条就放弃，等于没写。

## 本章验收

- [ ] 能不看教程，背出四要素（要什么结果 / 给什么材料 / 边界 / 什么算完成）
- [ ] 能把"总结一篇文章"改写成一份四要素齐全的任务书
- [ ] 能把一个大目标（比如"做我的资料问答助手"）拆成 3–5 个可执行小步
- [ ] 能写出至少一条"只使用我给的资料，不确定就写不确定"的边界
- [ ] 能解释"为什么分步确认比一步到位更不容易翻车"
- [ ] 手头有一份复制即可用的最小任务书模板
- [ ] 能说出四种输出格式写法（表格 / 清单 / 固定字段 / 字数限制）各什么时候用
- [ ] 能写出 3 条可打钩的验收标准
- [ ] 能把一个模糊要求改成"形态 + 读者 + 长度"三句
- [ ] 知道结果不对时，先查"材料 / 要求 / 验收"哪一项

## 可选动手（想做就做，不做不影响主线）

**复制粘贴级练习：** 把下面的任务书整段复制，发给你的 AI 聊天工具，把【】里的内容换成你自己的一篇文章（比如一篇你最近在看的公众号文章），看它输出什么。

> 这是任务书模板，复制后替换【】里的内容即可。

```text
请把下面这篇文章整理成学习笔记：
1）用一句话总结这篇文章说了什么；
2）列出 3 个关键概念，每个用一句大白话解释；
3）标注每个概念的原文依据（引用原句）。
要求：只使用文章内容，不要补充外部信息；文章里没有的就写"文章未说明"；
用表格输出，三列：概念、大白话解释、原文依据。

文章内容：【在这里粘贴文章】
```

做完后，对照"什么算完成"检查：一句话总结有没有、概念是不是 3 个、依据能不能在原文搜到。

不满足，就在同一对话里让它改（参考第 02 章的"卡住怎么办"）。

**进阶可选：** 用第 07 节小橙的四步，把你自己的一个目标拆成 3–5 步，每步写一张四要素任务书，只跑第 1 步。

## 本章小结

任务书不是文采，是把"我要什么"写得像给同事的工单一样清楚。

四要素齐了，结果才稳定；拆成 3–5 步，出错才只改一步。

本章所有方法，最后都收进一张最小可用模板——复制、填空、发出、逐条验收。
