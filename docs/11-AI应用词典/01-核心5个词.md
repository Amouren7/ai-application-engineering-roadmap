# 11.01｜核心5个词：模型、Agent、任务、上下文、工具

## 本节目标

用大白话讲清 5 个词，遇到问题能定位到是哪一项。

## 一句话结论

> 模型是脑子，Agent 是脑子加手脚，上下文是它眼前看到的材料，任务是你要的结果，工具是它能伸出去的手。

## 展开讲

第 01 章你已经见过这 5 个词。这一节把每个词讲透一层，并加上"在哪一章会用到"。

### 5 个词速查表

| 词 | 一句话人话 | 一个类比 | 在哪一章会用到 |
|-|-|-|-|
| 模型 | AI 的"大脑"，负责理解和生成文字的那部分 | 一个读过海量书的员工 | 第 01 章首次出现；全课每章都在用 |
| Agent（智能体） | 会自己安排步骤、调用工具、把一件事干完的 AI | 一个会主动干活的助理 | 第 01 章；第 04、06、07 章反复用 |
| 任务 | 你交给 AI 的、有明确结果的一件事 | 一张写清交付物的工单 | 第 00 章；第 03 章拆开细讲 |
| 上下文 | AI 这次"眼前看到"的全部信息（你的要求 + 资料 + 历史） | 助理手边的文件夹 | 第 01 章；第 03、05 章用到 |
| 工具 | AI 能调用的能力（读文件、查网页、发消息等） | 助理能用的电脑和打印机 | 第 01 章；第 04、07 章用到 |

记住这张表就够用了。下面逐条说清容易走偏的地方。

### 模型：它只会想，不会动手

模型（model）是 AI 里负责"理解和生成文字"的那部分。

你问一句，它答一句。它答完就停，不会去动你的文件。

| 你看到的 | 说明 |
|-|-|
| 它给你一段答案，让你自己复制 | 这就是纯模型 |
| 它说"我无法访问你的文件" | 这就是纯模型 |
| 它自己打开文件、改完、给你看改了什么 | 这不是模型，这是 Agent |

### Agent：会想，也会干

Agent（智能体）是"模型 + 一套干活流程 + 能调用的工具"。

它比模型多两件事：**自己排步骤**、**自己动手**。

| 对比 | 模型 | Agent |
|-|-|-|
| 它是什么 | 脑子，负责想和写 | 脑子 + 手 + 流程 |
| 它会动手吗 | 不会 | 会 |
| 你给它的 | 一句话问题 | 一件带结果的任务 |
| 例子 | "解释一下什么是周报" | "读这份记录，生成周报并存成文件" |

一句话：**模型会想，Agent 会想也会干。**

### 上下文：它看不见你没给的东西

上下文（context）是它这次"眼前看到"的全部信息。

包含三样：**你的要求、你给的材料、之前的对话**。

| 你给的上下文 | 它的回答 | 你要做的 |
|-|-|-|
| 只问"这篇文章写了什么" | 不知道是哪篇，只能反问或瞎猜 | 先把文章贴进去 |
| 给了文章再问 | 有依据，能引用 | 核对它引的对不对 |
| 给了文章 + 说清要 3 条要点 | 有依据，形态也对 | 直接能用 |

> 它不是你肚子里的蛔虫，它只看得见你递过去的那个文件夹。

### 任务和工具：一个管"对不对"，一个管"能不能"

**任务**决定干得对不对。你说得越清楚，它干得越准。

**工具**决定能不能干。它没有读文件的能力，你让它读文件就白说。

| 你遇到的症状 | 大概率是哪一项的问题 |
|-|-|
| 结果形态不对、太长太短 | 任务没写清 |
| 结果里全是编的 | 上下文没给全 |
| 它说"我做不到" | 工具没这个能力 |
| 它答得对但你没法用 | 任务没写清形态 |

这张表以后会反复用。**遇到问题先定位是哪一项，再改。**

### 5 个词之间的关系

| 关系 | 一句话 |
|-|-|
| 模型 → Agent | Agent 里面装着模型 |
| 上下文 → 模型 | 上下文是喂给模型的材料 |
| 任务 → Agent | 任务是你交给 Agent 的活 |
| 工具 → Agent | 工具是 Agent 能伸出去的手 |

## 照着做

用新学的词，把你自己的一个提问重写一遍。

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 打开你常用的 AI，翻出你最近问过的一句话 | 一句模糊提问，如"帮我看看这个" | 找不到就现场随便问一句 |
| 2 | 圈出这句话里的"任务"部分 | 你发现它只说了动作，没说要什么结果 | 补上结果形态，如"总结成 3 条" |
| 3 | 检查"上下文"给全了没有 | 材料要么没给，要么只给了半篇 | 把材料完整贴进去 |
| 4 | 判断这次是"模型"还是"Agent"在答 | 它答完就停 = 模型 | 想让它动手，就换一个开发型 Agent 工具 |
| 5 | 用新词重写这句话 | 一句含"任务 + 上下文"的清楚提问 | 还是别扭就回到 01 章第 05 节对照 |
| 6 | 把重写前后的两次答案并排看 | 通常差别很明显 | 差别不大就换更长的材料再试 |

第 5 步那句重写，就是你本节唯一的产出。

## 常见错误

- **错误一：把模型和 Agent 混着说。** 模型不会动手，Agent 会。说混了后面全乱。
- **错误二：以为上下文只是"聊天记录"。** 它包含你的要求、你给的材料、以及之前的对话，三样都算。
- **错误三：把工具和 Agent 搞混。** 工具是能力，Agent 是会调用能力的那套流程。
- **错误四：背名词不理解。** 背下来没用，要能说出"我这个问题属于哪一项"。
- **错误五：以为任务越短越省事。** 任务短了它就得猜，猜错的返工更费时间。
