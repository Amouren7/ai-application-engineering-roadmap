# 11.06｜我自己的词卡：遇到新词就填一张

## 本节目标

学会用一张词卡，把卡住你的词变成你自己的话。

## 一句话结论

> 词卡不是抄词典，是把"我卡在哪"写下来。填完这张卡，这个词就归你了。

## 展开讲

词典里的解释是别人的。词卡上的解释是你的。

### 词卡模板（复制这份）

> 复制后把【】里的内容换成你的。

```text
词：
一句话人话（用大白话）：
一句类比（像什么）：
我在哪一章第一次遇到：
它解决了我的什么疑问：
```

五行的作用不一样，别省：

| 行 | 它逼你想什么 | 写不好的样子 |
|-|-|-|
| 词 | 到底哪个词卡住你 | 一次写三个词 |
| 一句话人话 | 用自己的话复述 | 抄词典原文 |
| 一句类比 | 找到它像什么 | 写"就是那种东西" |
| 在哪一章遇到 | 记住上下文 | 写"忘了" |
| 解决什么疑问 | 记下卡点 | 写"没什么疑问" |

### 一张填好的词卡长什么样

小橙在第 07 章卡在"索引"这个词上，她填的卡是：

| 行 | 她写的 |
|-|-|
| 词 | 索引 |
| 一句话人话 | 把资料整理成一份能快速翻到的目录 |
| 一句类比 | 书最后面的"关键词 → 页码"表 |
| 我在哪一章第一次遇到 | 第 07 章，做文档学习助手时 |
| 它解决了我的什么疑问 | 为什么它说"读进来了"却还不回答 |

对比一下"抄词典"和"自己写"：

| 写法 | 内容 | 有用吗 |
|-|-|-|
| 抄词典 | "索引是一种数据结构，用于加速检索" | 没用，明天就忘 |
| 自己写 | "能快速翻到的目录，像书的索引表" | 有用，下次能讲给别人 |

### 什么时候该填词卡

**只在"这个词不搞懂就卡住"的时候填。** 不用每章都填。

| 情况 | 要不要填 |
|-|-|
| 这个词挡住了你这一步的活 | 要，立刻填 |
| 只是听着陌生，但不影响干活 | 不用，跳过 |
| 一天遇到十几个新词 | 只填最卡的那一个 |
| 是附录级概念（Embedding 等） | 不用，直接跳过 |

> 一周能填 2–3 张，就已经很多了。**填多了反而记不住。**

### 词卡攒起来之后怎么用

| 用法 | 具体动作 |
|-|-|
| 复述 | 拿词卡讲给同事听，讲得出来才是真懂 |
| 排查 | 卡住时先翻自己的词卡，比查词典快 |
| 沉淀 | 攒到 10 张，你就有了自己的小词典 |
| 交接 | 换工作或带新人时，这叠卡比教程管用 |

## 照着做

用新词重写一句你自己的提问，并给它配一张词卡。

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 从 01–04 四张表里挑一个你刚学会的词 | 一个词 | 挑不出就挑"上下文" |
| 2 | 复制上面那份词卡模板 | 五行空白 | 手写也可以，用便签纸 |
| 3 | 用大白话写第二行，不许抄原文 | 一句你自己的话 | 抄了就擦掉重写 |
| 4 | 想一个类比，越日常越好 | 一句"像什么" | 想不出就先写"像…再说" |
| 5 | 写下你在哪一章第一次遇到它 | 一个章号 | 忘了就写"记不清" |
| 6 | 写下它解决了你的什么疑问 | 一句"原来是因为…" | 没疑问说明这词不用填 |
| 7 | 用这个词重写你原本那句模糊提问 | 一句更清楚的提问 | 还是不顺手就回 05 节找易混词 |
| 8 | 把重写后的提问发出去，看结果差别 | 通常更贴你的心意 | 差别不大就补上下文再试一次 |

**第 7 步是本节的核心动作**：新词要落到你自己的句子里，才算学会。

## 常见错误

- **错误一：抄词典原文当词卡。** 抄来的记不住，用自己的话才记得住。
- **错误二：一张卡写三个词。** 一张卡只写一个词，否则哪行都写不实。
- **错误三：每个新词都填。** 只填"不搞懂就卡住"的那些，其余跳过。
- **错误四：只填不看。** 填完压在文件夹里等于没填，每周翻一次。
- **错误五：追求类比精准。** 类比不需要精准，只需要让你一秒想起来。
