# 11｜本章验收与下一步

## 常见误区（本章汇总）

- **误区一：把词典当课文从头背。** 词典是备查手册，用到哪个查哪个，背下来没用。
- **误区二：看到英文缩写就慌。** 大多数缩写背后就是一件很日常的事，类比一下就好懂。
- **误区三：为了"显得专业"硬用术语。** 任务书写清楚，比用词高级重要一百倍。
- **误区四：把模型和 Agent 混着说。** 一个是脑子，一个是脑子加手脚，说混了后面全乱。
- **误区五：以为上下文就是聊天记录。** 它包含你的要求、你给的材料、之前的对话，三样都算。
- **误区六：把任务和任务书当一回事。** 任务是那件事，任务书是那张把事说清楚的纸。
- **误区七：只用验收，不做测试集。** 改了几版之后，你分不清是变好了还是改坏了。
- **误区八：硬啃附录级概念。** Embedding、向量数据库、MCP、Workflow 框架主线用不到，啃完也用不上。
- **误区九：看到 API、Token 就以为必须学编程。** 它们是"按量付费的调用方式"，用工具时在背后发生。
- **误区十：把知识库和上下文混了。** 一个是常备资料册，一个是这一次递过去的文件夹。
- **误区十一：卡住时硬猜词义。** 先描述现象，再查词，比猜快得多。
- **误区十二：每遇到一个新词就填词卡。** 只填"不搞懂就卡住"的那个，填多了记不住。

## 本章验收

- [ ] 任选 3 个词，能用"一句话人话 + 一个类比"讲给一个完全不懂的人听
- [ ] 能不看教程，说出核心 5 个词（模型 / Agent / 任务 / 上下文 / 工具）
- [ ] 知道 Token、API、Git 这些词该去哪深究（附录，不是主线）
- [ ] 遇到不懂的词，第一反应是回这里查，而不是卡住不动
- [ ] 能一句话分清 6 组易混词里至少 4 组
- [ ] 填过至少 1 张自己的词卡，且第二行不是抄来的
- [ ] 能用"四行现象描述"说出一次卡住的经历（做的事 / 预期 / 实际 / 哪一步）
- [ ] 知道"现象 → 词"对照表在哪一节，卡住时能自己翻到
- [ ] 能说出 diff 和日志各回答什么问题
- [ ] 能说出交任务前保命的三步（过三栏 / 脱敏 / 先备份）

## 可选动手（想做就做，不做不影响主线）

**复制粘贴级练习：** 把下面这段发给你常用的 AI，看它怎么用大白话解释这 5 个词。

> 这是练习用的提问，复制后直接发即可。

```text
请用大白话给我解释这 5 个词，每个词配一个日常生活里的类比，
每句话不超过 20 字，不要用其他术语：
模型、Agent、任务、上下文、工具。
```

它答完，你对照 01 节的速查表看一遍：

| 对照结果 | 说明 |
|-|-|
| 它说的和 01 节差不多 | 你已经掌握这 5 个词 |
| 它绕了术语 | 让它"用更简单的话再说一遍" |
| 它说错了 | 说明这个词你还没真懂，回 01 节重看那一段 |

**进阶可选：** 从 01–04 四张表里挑一个你最容易忘的词，填一张词卡，然后拿它讲给一个同事听。讲得出来，才算真懂。

## 本章小结

这本词典不是用来背的，是用来查的。查得到、看得懂，就够用。

真正要记的只有核心 5 个词；其余是"遇到时能定位到是哪一类"。

卡住时别从词开始，从现象开始——描述清楚现象，答案自己就浮出来了。
