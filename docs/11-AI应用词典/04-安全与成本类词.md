# 11.04｜安全与成本类词：管住你的钱和责任

## 本节目标

记住 6 个"关乎钱和责任"的词，交任务前能自己过一遍。

## 一句话结论

> Agent 是工具，签字的是你。权限决定它能动什么，敏感数据决定你能给什么，Token 和计费决定你要花多少钱。

## 展开讲

这一节的词来自第 08 章。它们不是"知识"，是"习惯"。

### 速查表

| 词 | 一句话人话 | 一个类比 | 在哪一章会用到 |
|-|-|-|-|
| 权限 | 你允许 AI 能动哪些东西的范围 | 给助理哪几把钥匙 | 第 04、08 章 |
| 确认点 | 某些动作必须停下来问你，你点了才继续 | 转账前的短信验证码 | 第 04 章 |
| 敏感数据 | 一旦泄露会造成损失的数据，如个人信息、公司机密、合同、薪酬 | 家里的钥匙，不随便给人 | 第 08 章是主章 |
| 脱敏 | 把敏感内容替换或打码，再去给 AI | 复印件上把身份证号涂黑 | 第 08 章 |
| Token | 模型算文字多少的计量单位，像"字数"但又不完全等于字数 | 计价器上的"格" | 第 08 章（成本）；附录 |
| 计费 | 按用掉多少来算钱，不是一次性买断 | 打电话按分钟算 | 第 08 章 |
| 回滚 | 把改动退回到之前那版 | 游戏读档 | 第 08 章 |
| API Key | 证明你有权限调用某个服务的"门禁卡" | 一把不能给别人看的钥匙 | 附录 04 节 |

### 权限：不是"能不能干"，是"能动多少"

权限给得越大，出事时影响越大。

| 权限档位 | 它能做什么 | 什么任务适合 |
|-|-|-|
| 只读 | 只能看，不能改 | 总结、分析、对比 |
| 读写 | 能改你给的文件 | 改表格、整理文档 |
| 能对外发 | 能发邮件、发消息 | 几乎不直接给，先让它起草 |
| 能花钱 | 能下单、充值、付费 | 不给，人工来 |

> 一句话：**别一次放权做太多。** 先给最小的一档，不够再加。

### 确认点：什么动作必须先问你

| 动作 | 要不要先问 | 为什么 |
|-|-|-|
| 读一个文件 | 通常不用 | 影响小，可逆 |
| 覆盖你的原文件 | 要 | 覆盖了可能找不回来 |
| 删除文件 | 要 | 删了不一定能恢复 |
| 对外发送（邮件/消息） | 要 | 发出去就收不回 |
| 花钱类动作 | 要 | 钱花了不退回 |

### 敏感数据：交之前问自己三句

**敏感数据** = 一旦泄露会造成损失的数据。

| 三问 | 答"不确定"怎么办 |
|-|-|
| 这数据泄露了会不会造成损失？ | 不确定 = 按敏感处理 |
| 能不能先脱敏再给？ | 能脱敏就脱敏 |
| 不给它，我能不能干成这活？ | 能不给就不给 |

**脱敏**的常见做法：替换人名（甲、乙、丙）、打码账号、删掉身份证号。

### Token 和计费：钱是怎么花出去的

- **Token**：模型算文字多少的单位，像"字数"，但一个汉字、一个英文单词、一个标点都可能各占若干 Token。
- **计费**：按用掉的量算钱，用得越多花得越多。

| 你的疑问 | 人话回答 |
|-|-|
| 为什么问一句也要钱？ | 因为它每次都要"读一遍"你的上下文，上下文越长越贵 |
| 为什么长文档特别费钱？ | 文档越长，占的 Token 越多 |
| 怎么控制？ | 先问价 → 用免费额度 → 设预算上限 → 用完即停 |
| 我什么时候要操心？ | 第 07 章做应用之后；体验期通常免费额度够用 |

### 回滚和 API Key：出事时的两条保险

- **回滚**：把改动退回到之前那版。所以动手前先备份一份。
- **API Key**：你的门禁卡。**绝不写进代码、截图、公开仓库。**

| 出事了 | 四个紧急刹车（按顺序） |
|-|-|
| 它在乱改 | 先停 |
| 权限给大了 | 收权 |
| 可能还在往外传 | 断开 |
| 已经改坏了 | 回滚 |

## 照着做

用这一节的词，给一件事做一次"交任务前体检"。

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 写下这次要交出去的活 | 一句话 | 太笼统就先写清要什么结果 |
| 2 | 给它的材料过"三栏"（能交/要小心/绝不能交） | 材料被分成三堆 | 分不出来就归到"要小心" |
| 3 | 对"要小心"那一堆做脱敏 | 替换/打码后的版本 | 脱敏不了就干脆不给 |
| 4 | 定权限档位 | 选"只读"或"读写" | 犹豫就选更小的一档 |
| 5 | 列出必须"先问我"的动作 | 一份确认点清单 | 拿不准就都列进去 |
| 6 | 动手前先备份 | 原件 + 备份两个文件 | 没备份就先复制一份再让它动 |
| 7 | 做完看花了多少、改了什么 | 用量 + diff | 超了就停下，改用免费额度或更短的输入 |

**第 2、3、6 步是保命三步**，做应用之前每次都要过。

## 常见错误

- **错误一：觉得"大厂工具应该没事"。** 判断标准是数据敏不敏感，不是工具名气大不大。
- **错误二：觉得"只是问一句不算交出去"。** 问一句也会被记录，敏感内容同样要脱敏。
- **错误三：一次把读写权限全给了。** 先只读，需要改再放开，改完就收回去。
- **错误四：把 API Key 贴在聊天里或写进截图。** 那是你的门禁卡，泄露等于把钥匙给出去。
- **错误五：动手前不备份。** 没有备份就没有回滚，改坏了只能重来。
- **错误六：以为费用是固定的。** 按量计费，输入越长、问得越多，花得越多。

## 本节练习

5 分钟，手机就能做。拿你最近想交给 AI 的一件活，过一遍六行：

> 复制后把【】里的内容换成你的。

```text
这次要交的活：
材料属于哪一栏：（能交/要小心/绝不能交）
要不要脱敏：（要/不要）
给它的权限：（只读/读写）
必须先问我的动作：
这次大概要花多少：
```

最后一行答不出来也没关系，写"先看免费额度"。
