# 13.01｜任务卡模板：全课通用的一张卡

## 本节目标

拿到一张能一直用下去的任务卡模板，并知道每一行填什么。

## 一句话结论

> 任务卡是这门课的账本：跑完一个任务记一笔，一个月后你会有自己的经验库。

## 展开讲

**任务卡**：一次任务干完后，你记下的一笔账。记在哪都行，备忘录最快。

它回答四个问题：

- 我本来想要什么？（目标）
- 我给了它什么？（资料）
- 它不许干什么？（边界）
- 做到什么程度算完？（验收）

再加三段：过程、结果、经验。这三段是后面复盘和进步的原料。

### 全课通用模板（复制走）

> 复制后把【】里的内容换成你的。

```text
日期：
任务名称：

【任务书四要素】
目标（我要什么结果）：
资料（我给 AI 什么）：
边界（不许 AI 做什么）：
验收（什么算完成）：

【过程】AI 做了什么、我改了什么：
【结果】做成了吗、差在哪：
【经验】下次照做 / 下次别犯：
```

不用一次填满。**先填前四行，跑完任务再补后面三行。**

### 每一行填什么

| 行 | 填什么 | 填坏了会怎样 |
|-|-|-|
| 日期 | 写全，如 2026-03-12 | 只写"3月12日"，跨年就分不清 |
| 任务名称 | "把 X 变成 Y"，一句话 | 写"整理文档"，三个月后认不出 |
| 目标 | 形态 + 读者 + 长度 | 写"写个总结"，等于没写 |
| 资料 | 给了什么、给了多少 | 写"给了些材料"，复盘时对不上 |
| 边界 | 明确不许做什么 | 空着，下次它还犯同一个错 |
| 验收 | 可打钩的 1–3 条 | 写"看着还行"，等于没验收 |
| 过程 | 它做了什么、你改了什么 | 空着，卡住时无从回看 |
| 结果 | 成了 / 没成 + 差在哪 | 写"还行"，说不清真真假假 |
| 经验 | 下次照做 / 下次别犯 | 空着，这一笔就白记了 |

### 一张填好的卡长什么样

这是小橙记的第三笔（她把前两笔补全后，开始按标准版记）：

```text
日期：2026-09-12
任务名称：把三页会议记录整理成待办清单

【任务书四要素】
目标（我要什么结果）：8 条以内待办，每条含"谁做 + 什么时候 + 做什么"
资料（我给 AI 什么）：会议记录原文 3 页，一次贴完
边界（不许 AI 做什么）：不许编造会议里没提过的人名和日期
验收（什么算完成）：每条都能在原文找到出处，没有多出来的事

【过程】AI 做了什么、我改了什么：它先给 12 条；我让它合并重复、删无关，改到 8 条
【结果】做成了吗、差在哪：成了，8 条都有原文依据
【经验】下次照做 / 下次别犯：资料里没写的它真会编；下次先让它每条标"出自第几段"
```

注意最后一行：那句话下次能直接省掉一轮返工。

### 三段式为什么这么排

| 段 | 回答的问题 | 什么时候填 |
|-|-|-|
| 四要素 | 我打算怎么干 | 开工前就写，写完直接当任务书用 |
| 过程 + 结果 | 实际发生了什么 | 跑完立刻补，隔天就忘 |
| 经验 | 我学到了什么 | 和上一行一起写，一句话就够 |

> 四要素那一段，本质就是你的任务书。写一次，两用。

### 记在哪

| 方式 | 适合 |
|-|-|
| 手机备忘录 | 最快，随时能记 |
| 飞书 / 石墨文档 | 方便按日期整理，能分享 |
| 一个 Word 文件 | 想攒成作品集时 |
| 纸质本子 | 喜欢手写的人 |

选一个就行，别在挑工具上花时间。

## 照着做

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 打开备忘录，新建一条 | 空白页 | — |
| 2 | 把上面的模板整段粘进去 | 九行空字段 | 粘不全就手打，字段名别改 |
| 3 | 填日期 + 任务名称 | 两行 | 名称写"把 X 变成 Y"这种句式 |
| 4 | 填四要素四行 | 四行 | 想不起来就翻聊天记录 |
| 5 | 跑完任务后补过程 | 两三句话 | 只写你改了什么也行 |
| 6 | 补结果 | 一句话，成了没、差在哪 | 别只写"还行" |
| 7 | 补经验 | 一句话 | 实在没有就写"暂无"，别空着 |

第 4 步的四行，写的时候可以直接当任务书发给 AI，一次写两用。

## 常见错误

- **错误一：一次想填满。** 前四行先写，后面跑完再补。追求一次填完的人，往往第二次就不记了。
- **错误二：只记成功的。** 失败那笔最值钱——写下来，下次就避开了。
- **错误三：任务名称写动作，不写结果。** "整理文档"认不出，"把会议记录变成待办清单"一眼就懂。
- **错误四：验收那行空着。** 没有验收标准的记录，等于没记，因为你没法判断到底成没成。
- **错误五：任务书没留档。** 任务卡里就存着四要素，下次同类任务直接复制这四行。
- **错误六：一天开一个新文件。** 一个地方记到底，不然复盘时你得满世界找。

