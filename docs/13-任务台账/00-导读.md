# 13｜任务台账：记录、复盘与进步

> 本章目标：给你一套"记账"方法——每干完一个任务记一笔，每周每月回看一次。让你看得见自己真的在进步。

## 本章开始前：准备与产出

| 项目 | 说明 |
|-|-|
| 账号要求 | 不需要。这一章不用 AI 也能做完 |
| 能否只用手机完成 | 可以。备忘录、飞书文档、纸笔任选 |
| 主线要不要写代码 | 不需要 |
| 预计用时 | 约 1 小时，建议分 3 次学完 |
| 本章产出 | 一张你自己的任务卡（填满）+ 一份本周复盘 |

## 这一章在解决什么问题

前面 12 章教你怎么指挥 AI。这一章教你怎么**记住自己指挥过什么**。

不记账的人，三个月后只记得"好像做过不少事"，说不出做成了什么。

| 不记账的状态 | 记账后的状态 |
|-|-|
| 干完就忘，同类任务每次从零写 | 翻出上次的任务书改一改就能用 |
| 卡住时想不起上次怎么出来的 | 回看过程那几行，路子立刻清楚 |
| 说不清自己进步了没有 | 四个信号一条条对，看得见 |
| 攒不出作品集 | 任务卡就是现成的交付清单 |

> 记录不是为了交差，是为了让经验留得下来。

## 和 02 章那张卡的关系

第 02 章你已经见过一张任务卡，那是**随手记的第一版**。

这一章把它升级成**全课通用的标准版**：字段更全，还讲清每行怎么填。

| | 02 章的任务卡 | 13 章的任务卡 |
|-|-|-|
| 定位 | 让你立刻开始记 | 让记录长期可用、可复盘 |
| 字段 | 7 行，够用就行 | 分三段：四要素 / 过程 / 结果经验 |
| 讲法 | 给个样子照着填 | 每行拆开讲，配好差对照 |

> 一句话：02 章是"先记起来"，13 章是"记对、记得能复用"。
