# 00.05｜能力地图L0到L6：七个阶段与每阶段成果

## 本节目标

看懂七个阶段，定位你在哪一级，圈出你的下一级成果。

## 一句话结论

> 整条路线分 7 个阶段，每阶段结束你都有一份拿得出手的成果。成果比"学完了"更能证明你。

## 展开讲

先说这张全图。左边是阶段，右边是你能带走的东西。

| 阶段 | 学会什么 | 你的成果 |
|-|-|-|
| L0 | Agent 能干什么、不能干什么 | 一张想交给 AI 的任务清单 |
| L1 | 第一次驾驶：让 AI 帮你跑通第一件真事 | 第一条完整任务记录 |
| L2 | 拆任务、写任务书（这门课的核心方法） | 一个被拆成 3–5 步的大任务 |
| L3 | 验收与纠错：判断对不对、让它改 | 一次"从失败到修好"的复盘 |
| L4 | 用 Agent 完成真实工作：文档、表格、数据、自动化 | 3 个真实工作产出 |
| L5 | 指挥 Agent 做出 AI 应用 | 一个能运行的应用 |
| L6 | 安全、成本、边界 + 沉淀你的模板库 | 个人任务书模板库 |

### 每一级用一句人话解释

- **L0 认清工具**：它不是搜索引擎，它会动手。
- **L1 跑通一次**：第一次让它把一件真事干完。
- **L2 学会拆任务**：把大目标切成 AI 能执行的小步。全课的核心。
- **L3 学会验收**：它说完成不算完成，你核对过才算。
- **L4 搬到工作里**：文档、表格、数据、自动化，各来一件真活。
- **L5 做出应用**：从"用一次"走到"能反复用"。
- **L6 守住边界**：哪些不能给、花多少钱、出事怎么停。

### 七个阶段大致对应哪几章

| 阶段 | 大致对应章节 |
|-|-|
| L0 | 第 00 章、第 01 章 |
| L1 | 第 02 章 |
| L2 | 第 03 章（核心） |
| L3 | 第 05 章（核心） |
| L4 | 第 06 章 |
| L5 | 第 07 章 |
| L6 | 第 08 章 + 第 10 章 |

对照表只用来定位，不用背。学到哪一章，自然就在哪一级。

### 为什么强调"成果"

因为成果可核对，感觉不可核对。

| 说法 | 能不能验证 | 作用 |
|-|-|-|
| "我学完了 L2" | 不能 | 只有自我感觉 |
| "我把一件大任务拆成了 4 步，每步都能验收" | 能 | 可以直接给别人看 |

L0 到 L6 的成果是逐级变重的：从一张清单，到一份记录，到一个能运行的应用。
你现在只需要管好下一级的成果。

## 照着做

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 读上表七行，找出你现在的真实位置 | 一个阶段编号 | 拿不准就选最像的，后面会自己修正 |
| 2 | 圈出你的下一级 | 例如"我现在 L0，下一级 L1" | 跳级也行，但先把下一级成果做出来 |
| 3 | 写下这一级的成果物是什么 | 一句话 | 写不出就抄表里那列 |
| 4 | 判断你现在能不能立刻做出这个成果 | 能/不能 | 不能就说明还差一个小任务 |
| 5 | 把"我的下一级成果"记进备忘录 | 一行文字 | 顺手标日期 |

如果第 1 步你选的是 L0，那你的下一级成果就是**一张任务清单**。
这件事今天就能做：把 01 节写的"最烦的重复劳动"扩成 3 条。

## 常见错误

- **错误一：想直接跳到 L5 做应用。** 没跑通过 L1–L2，做应用只会卡在"说不清要什么"。
- **错误二：只看"学会什么"，不看"成果"。** 成果才是你能拿给别人看、也能自己核对的东西。
- **错误三：把阶段当考试，不敢往下走。** 每级都是练出来的，不是考出来的，允许回头补。
- **错误四：以为 L6 是"高级安全课"。** 它管的是你每天的日常：哪些不能给、花多少钱、出事怎么停。
- **错误五：把对照表当死规定。** 它只是定位工具，学到哪算到哪。

## 本节练习

```text
我现在大概在：【L0 / L1 / L2 / L3 / L4 / L5 / L6】
我的下一级是：【 】
我的下一级成果是：【 】
```

写完把中间那行读一遍。它就是你这几周的方向。
