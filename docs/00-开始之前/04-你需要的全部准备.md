# 00.04｜你需要的全部准备：清单只有五项

## 本节目标

看清全部准备清单，然后只做今天该做的那一件事。

## 一句话结论

> 现在你只需要做一件事：确认自己有一个能用的 AI 聊天工具。其他的，遇到再准备。

## 展开讲

新手最常见的浪费，是**在准备阶段就耗光热情**。
买一堆课、装一堆软件、研究半天哪个模型最强——然后一件活没干。

这门课的准备清单其实只有五项。

| 准备项 | 什么时候要 | 说明 |
|-|-|-|
| 一个 AI 聊天工具 | 今天就要 | 手机或电脑都行；用来提问、完成你的第一批任务 |
| 能上网的电脑 | 第 02 章起 | 部分 Agent 工具需要装到电脑上 |
| 一个邮箱 | 注册工具时用 | 用来注册账号 |
| API 预算（少量钱） | 第 07 章做应用时 | 调用云端模型要按量付费；体验期通常用免费额度即可 |
| 编程环境 | 主线始终不需要 | 想深入编程的人，看附录《真正的工程进阶》 |

看最后一行：**编程环境那一项，整条主线都不用准备。**

### 今天的唯一动作

> 打开你的 AI 聊天工具，问它一句"你是谁、能做什么"。能回答，就算准备完成。

| 你能用哪类工具 | 举例 | 今天够不够 |
|-|-|-|
| 问答型聊天工具 | 豆包、Kimi、DeepSeek、ChatGPT | 够。第 00–01 章全靠它 |
| 办公综合型工具 | 带文档处理能力的办公 AI | 够，也能用来练 |
| 开发型 Agent 工具 | Codex、Claude Code、WorkBuddy | 第 02 章起再装，别现在折腾 |

三类工具的差别，01 章会给你一张全景对照表。今天不用分清。

### 关于钱：现在别焦虑

- 体验期用免费额度就够，不用先充钱。
- 到第 07 章做应用时，才可能用到少量按量付费。
- 真要花钱时，对应章节会告诉你怎么设上限，08 章专讲成本控制。

### 关于设备：手机真的够

本章全部内容手机就能做完。
第 02 章起才逐步需要电脑，因为部分 Agent 工具要装到电脑上。

## 照着做

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 打开你选的 AI 聊天工具（APP 或网页） | 出现输入框 | 打不开就换浏览器或换一个工具 |
| 2 | 问一句"你是谁、能做什么" | 它正常回答 | 没回答就检查网络，或换工具再试 |
| 3 | 再问一句："请把我今天做的三件事改成三条待办，每条含做什么、为什么、预计耗时，用表格输出" | 一张待办表 | 输出很乱就说明工具偏弱，换一个 |
| 4 | 把这次问答截图或复制到备忘录 | 一条记录 | 懒得存就存标题一行 |
| 5 | 对照上表，圈出你"还没有"的准备项 | 通常只剩电脑或邮箱 | 没有也照学，用到再补 |

第 3 步如果做成了，你其实已经完成人生第一次"让 AI 干活"。

## 常见错误

- **错误一：在准备阶段就研究"哪个模型最强"。** 今天只要工具能回答就行，选型是后面的事。
- **错误二：一上来就装开发型 Agent 工具。** 第 02 章才需要，现在装容易卡在配置里出不来。
- **错误三：因为"没有电脑"就不开始。** 本章到 01 章手机完全够用。
- **错误四：提前焦虑 API 费用。** 体验期免费额度通常够，花钱在第 07 章之后才谈。
- **错误五：准备了工具却从不提问。** 工具不是准备出来的，是用出来的。

## 本节练习

5 分钟，手机就能做。把这一节变成一次真实操作：

```text
我的工具是：【 】
它今天能正常回答吗：【能 / 不能】
我第一个想问它的问题是：【 】
```

三行都填完，你今天的准备任务就结束了。
不用做更多，剩下的等 01 章开始。
