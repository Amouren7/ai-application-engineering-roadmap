# 00｜开始之前：这门课到底教什么

> 本章目标：回答三个问题——这门课是给谁的？教什么、不教什么？你第一天能做出什么？
> 学完本章，你手上会有一张任务卡，上面写着你交给 AI 的第一件真事。

## 本章开始前：准备与产出

| 项目 | 说明 |
|-|-|
| 账号要求 | 一个可用的 AI 聊天工具（豆包、Kimi、DeepSeek、ChatGPT 任选其一，手机 APP 或网页版都行） |
| 能否只用手机完成 | 可以。本章所有练习手机就能做完 |
| 主线要不要写代码 | 不需要。这门课主线**不要求你写任何代码** |
| 安装软件 | 本章不需要。需要装东西时，对应章节会明确告诉你，并带你装 |
| 预计用时 | 约 1.5 小时，建议分 3 次学完 |
| 本章产出 | 一张"任务卡"：你想让 AI 帮你完成的第一件真实事情 |

## 这一章为什么值得先花一小时

它不教技能，它决定你后面 10 章的学法。

学错地方最常见的表现是：一上来就想学编程，学到一半放弃。
或者把 AI 当搜索引擎用了一个月，却从没让它替你干过一件活。

| 你现在的状态 | 学完本章的状态 |
|-|-|
| 不确定这门课是不是给自己的 | 能一句话说清"我是四类人里的哪一类" |
| 以为要先把 Python 学完 | 知道主线零手写代码，代码由 Agent 写 |
| 只有一个模糊愿望，没有具体任务 | 手上有第一张任务卡，写着一件真事 |
| 不知道学到哪算好 | 看得懂 L0–L6 七个阶段，知道自己的下一级 |

## 本章的产出物长什么样

一张任务卡，写在手机备忘录里就够。
它至少有两行：**日期**和**任务名称**。

剩下几行边走边补：要什么结果、给什么材料、边界、过程、结果、卡住的地方、下一步。
第 09 节会给完整模板和填写示例。

## 本章只会出现三个新词

| 词 | 一句话人话解释 | 第一次出现在 |
|-|-|-|
| Agent（智能体） | 会替你动手干活的 AI 工具，不只是回答问题 | 02 节 |
| 任务书 | 你写给 AI 的要求，说清要什么、给什么、不许做什么、什么算完成 | 02 节 |
| 任务卡 | 你自己留的记录，写下目标、过程、结果、卡住的地方 | 09 节 |

其他名词（Token、API、框架名）一律推迟到第 11 章词典和附录。
本章不需要你记任何技术名词。

## 本章怎么学最快

1. 先读 01 和 02，确认这门课对口、期待没跑偏。
2. 再读 03，把三句话抄进备忘录——它们是后面所有章节的判据。
3. 然后读 09，当场填出你的第一张任务卡。
4. 04、05、06、07、08 属于"随时回来看"的说明书。

## 学完本章你应该能

- 一句话说清"我是四类人里的哪一类"；
- 说出这门课承诺什么、不承诺什么；
- 背出第一句："AI 负责干活，你负责说清楚、检查、负责"；
- 说出自己现在在 L0–L6 的哪一级；
- 手上有第一张任务卡，至少填了日期和任务名称。

五条里有三条做不到，就把对应的小节再读一遍，不必往后赶。

> 一句话：本章不是知识章，是**装备章**。读完就该能开工。
