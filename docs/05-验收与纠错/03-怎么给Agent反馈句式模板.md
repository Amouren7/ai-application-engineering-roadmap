# 05.03｜怎么给 Agent 反馈：三句式模板

## 本节目标

把"不对，重做"改成一段 AI 照着就能改的返工单。

## 一句话结论

> 反馈要说三件事：具体错在哪、你期望什么、要不要给依据。说"哪错了"比说"它不对"有用一百倍。

## 展开讲

差的反馈只表达情绪，AI 只能猜。

好的反馈是**可执行的修改指令**，它读完就知道改哪、改成什么。

### 三句式

| 部件 | 你写什么 | 举例 |
|-|-|-|
| ① 具体错在哪 | 指出位置 + 现象，最好引原话 | "第 2 条概念的解释还是太术语" |
| ② 我期望什么 | 给一个能核对的标准 | "换成给小学生讲的说法" |
| ③ 要不要依据 | 说清按什么改 | "以原文第 3 段为准，找不到就标'不确定'" |

三个部件不用每次都全。**但"具体错在哪"必须有。**

### 差 vs 好 对照

| ❌ 差（它会继续懵） | ✅ 好（它能直接改） |
|-|-|
| "不对，重做。" | "第 2 条概念的解释还是太术语，换成给小学生讲。" |
| "你写得太少了。" | "摘要现在 40 字，我要的是 100 字左右，请补足到 100 字。" |
| "这个数据不对吧？" | "你写'报销上限 300'，但原文第 3 段写的是 500，请核对后改正，并标出依据。" |
| "感觉不好。" | "表格少了'负责人'这一列，请加上；原文没写负责人的行，填'待定'。" |
| "太啰嗦了。" | "正文压到 3 段以内，每段不超过 3 行。" |
| "再专业一点。" | "把'赋能'改成'帮助'，把'闭环'改成'完整流程'。" |
| "你理解错了。" | "我要的是待办清单，不是会议纪要，请按清单重排。" |

右边那列有共同点：**都说了具体现象，还说了改成什么。**

### 反馈模板

> 复制后把【】里的内容换成你的。

```text
【第几处】不对：
现象是【具体现象，最好引它的原话】。
请改成【明确、可核对的要求】。
依据以【原文第几段 / 我给的哪份材料】为准，找不到就写"不确定"，不要编。
其他部分不用动。
```

最后那句"其他部分不用动"很重要。**不写，它可能顺手把好的地方也改了。**

### 一条反馈说几条

| 情况 | 怎么做 |
|-|-|
| 3 条以内的小问题 | 一次说全，省时间 |
| 有一条反复改不动 | 只发这一条，其他先放着 |
| 大方向就错了 | 别改，重发一份任务书 |
| 它改一条又弄坏另一条 | 拆开，一次只让它动一处 |

### 小橙的完整反馈

她按三句式，把两条 ❌ 写成了一段话：

```text
1）摘要只有 40 字，我要 100 字左右，请补足；
2）第 3 个概念写的依据，我在原文没搜到，请回到原文核对，找不到就删掉并标"不确定"。
其他部分不用动。
```

Agent 一轮就改对了。

### 反馈的三条纪律

1. **在同一个对话里发。** 重开窗口它就失忆了，见 04 节。
2. **说现象，不评价人格。** "这里错了"能改，"你太笨"只会让它乱改。
3. **改完再验一次。** 改动本身可能带出新问题。

## 照着做

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 从验收清单挑 2–3 条 ❌ | 具体问题列表 | 超过 3 条就分两轮发 |
| 2 | 每条写"哪一处 + 现象" | 它能定位到位置 | 说不出位置就先回去核对 |
| 3 | 每条补"改成什么" | 一个能核对的标准 | 想不出标准就写"以原文为准" |
| 4 | 补一句依据要求 | 防它再编 | 涉及数字的条目必须写 |
| 5 | 末尾加"其他部分不用动" | 一句保险 | 忘了写，它可能全篇重排 |
| 6 | 发送后看它改哪了 | 它回复改了哪几条 | 没改到位就把现象再说一遍 |
| 7 | 重新用四看过一遍 | 打钩清单 | 还有 ❌ 就再来一轮 |

第 7 步是很多人的盲点：**改完不验，等于没改。**

## 常见错误

- **错误一：只说情绪不说现象。** "不对""重做"没法执行，它只能瞎猜。
- **错误二：一次列十条。** 它会改乱，你也验不过来。
- **错误三：说"再专业一点"。** 感受词无法执行，换成具体动作。
- **错误四：反馈里不写依据要求。** 它可能改出新的一处编造。
- **错误五：反复改同一个地方超过三轮。** 这时候问题在你的任务书，不在它。

> 复制后把【】里的内容换成你的。

```text
【哪一处】不对：现象是【具体现象】。
请改成【明确要求】。
依据以【原文第几段】为准，找不到就写"不确定"。
其他部分不用动。
```

发出去，看它改没改到位。改完再用四看验一遍。
