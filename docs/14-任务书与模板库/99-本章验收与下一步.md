> 14 任务书与模板库 ｜ 本章收尾

# 14｜本章验收与下一步

## 常见误区（本章汇总）

- **误区一：把模板当标准答案，不敢改。** 模板是草稿，删行加行都行，换成你的说法也行。
- **误区二：一次塞太多要求。** 任务书越长越容易乱；先用通用版四要素，不够再补。
- **误区三：拿到 AI 结果就直接交。** 至少过一遍 B 组的"验收四看"。
- **误区四：留着【】就发。** 它会把占位符当内容。发之前扫一眼。
- **误区五：一个任务抄好几个模板。** 一个任务抄一个就够，混着用反而乱。
- **误区六：提修改时一次说一堆。** 一次只说一处，你才知道是哪处起了作用。
- **误区七：忘了说"其他部分不要动"。** 它可能顺手把没让你改的地方也改了。
- **误区八：一卡住就重开窗口。** 上下文没了，它更容易重犯同一个错。
- **误区九：在同一个对话里让 AI 审自己。** 它多半给自己打高分，换工具或新开对话。
- **误区十：把审查结果全当真。** 审查员也会编，每条都要回原文核一遍。
- **误区十一：只验收格式，不验收事实。** 排版整齐最容易被放过，编造的数字最伤人。
- **误区十二：做一次就固化流程。** 规律还没形成，固化出来的模板下次多半用不上。

## 本章验收

- [ ] 能说出五组模板各管什么时机（开工 / 收工 / 救场 / 外援 / 复用）
- [ ] 从 A 组挑一个模板，真实写一份任务书并跑完
- [ ] 用过一次"验收四看"，至少发现并改掉一处问题
- [ ] 卡住时用过 C 组的一句落地句式，而不是干等
- [ ] 提修改时用上了"其他部分不要动"这句
- [ ] 请另一个 AI 审查过一次产出，并回原文核对了它挑的问题
- [ ] 模板库里至少有 1 份能直接复制的任务书
- [ ] 手机或备忘录里能一秒找到你要的那个模板

## 可选动手（想做就做，不做不影响主线）

**复制粘贴级练习：** 把下面的任务书整段复制，发给你的 AI 工具。

把【】换成你自己的一篇长文，比如你最近在看的公众号文章。

> 这是任务书模板，复制后替换【】里的内容即可。
```text
请把下面这篇文章整理成学习笔记：
1）用一句话总结这篇文章说了什么；
2）列出 3 个关键概念，每个用一句大白话解释；
3）标注每个概念的原文依据（引用原句）。

要求：只使用文章内容，不要补充外部信息；文章里没有的就写"文章未说明"；
用表格输出，三列：概念、大白话解释、原文依据。

文章内容：【在这里粘贴文章】
```

拿到结果后，抄 B 组的四看过一遍：摘要有没有、概念是不是 3 个、依据能不能在原文搜到。

| 四看 | 查什么 | 不过就怎么办 |
|-|-|-|
| 看事实 | 3 条依据能不能在原文搜到 | 搜不到就标"无依据"，让它换原文里的句子 |
| 看覆盖 | 摘要 + 3 个概念 + 依据，三个都在吗 | 少了哪块就让它补，别自己动手 |
| 看格式 | 摘要不超 100 字、表格三列 | 超了就让它压，并说"其他部分不要动" |
| 看稳定 | 换文章另一节再跑一次 | 差别大就说明不稳，别直接拿去用 |

有 ❌，就抄 B 组的修改句式，一次只提一处。

**进阶可选：** 把这份任务书存进你的模板库，按 `场景类型-具体场景` 命名，再用 E 组模板补上两条翻车点。

## 本章小结

模板的价值不在"背下来"，而在**用到时一秒能抄到**。

五组各管一个时机：A 开工说清、B 收工把住、C 半路救火、D 请外援、E 存起来复用。

真正让模板生效的只有一件事：抄完把【】全换掉，然后老老实实验收一遍。
