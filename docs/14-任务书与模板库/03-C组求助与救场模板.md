# 14.03｜C组求助与救场模板：卡住时怎么说

## 本节目标

任务跑不动时，能立刻发出一句有效的话，而不是干等或重开窗口。

## 一句话结论

> 卡住时最贵的动作是"重开窗口重来"。先说清现象，再要一个最小验证步骤。

## 展开讲

"卡住"有三种常见样子，对应三招。

| 卡住的样子 | 你心里的话 | 用哪一招 |
|-|-|-|
| 它答得驴唇不对马嘴 | "它是不是听不懂我" | 把状态说全 |
| 它说"资料不足"或明显在猜 | "它没看我的文件" | 补材料 |
| 它一口气干完，全干错了 | "我根本插不上手" | 要求分步 |

> 一次只用一招。三招混着发，它反而抓不住重点。

### 卡住三招的落地句式

> 什么时候用：任务跑不下去。三招 = 把状态说全、补材料、要求分步，一次用一招。

> 复制后把【】里的内容换成你的。
```text
（把状态说全）
"我现在卡在这一步：【现象】。我已经试过：【做法】，结果是：【结果】。
请你先告诉我最可能是哪里出问题，再给一个最小验证步骤。"

（补材料）
"我把相关文件和报错贴在下面了，请先读它们再判断，不要凭空猜。"

（要求分步）
"请一步一步来，每做完一步就停下来给我看，我确认后再做下一步，不要一次全做完。"
```

| 复制后改哪里 | 改成什么样 |
|-|-|
| 【现象】 | 写你看到的东西，别写"就是不行" |
| 【做法】 | 写你试过什么，一条一行 |
| 【结果】 | 写试完发生了什么 |
| 最小验证步骤 | 保留这句，它会让 AI 给便宜的动作 |
| 贴在下面了 | 真的把材料贴上去，别只说贴了 |

**填写示例（三招各一条）：**

> 复制后把【】里的内容换成你的。
```text
（把状态说全）
"我现在卡在这一步：整理会议记录时，它把两个同名的负责人合并成一个人了。
我已经试过：让它重做一遍、把记录重新贴了一次，结果是：还是合并。
请你先告诉我最可能是哪里出问题，再给一个最小验证步骤。"

（补材料）
"我把会议记录原文和它上次的输出都贴在下面了，请先读它们再判断，不要凭空猜。"

（要求分步）
"请一步一步来，先把记录里的负责人名单单独列出来给我看，我确认后再整理待办，不要一次全做完。"
```

### 三招分别治什么

| 招 | 治什么毛病 | 不用的后果 |
|-|-|-|
| 把状态说全 | 它在瞎猜你的情况 | 它给一堆无关建议 |
| 补材料 | 它没看到关键信息 | 它编一个看起来对的答案 |
| 要求分步 | 它一口气全做完 | 全错，你还得从头再来 |

> 最省事的一招是第三招：**先要名单，再要结果。** 中间那一步比最终结果便宜得多。

### 为什么"说全状态"比"说清需求"更急

卡住的时候，你第一反应常常是**重新说一遍需求**。

但需求你早就说过了，它没做对，说明问题不在需求。

| 你重说需求 | 你说全状态 |
|-|-|
| "我要的是待办清单，三列表格" | "卡在负责人被合并这一步，我试过重贴记录，结果一样" |
| 它再答一遍同样的错 | 它开始定位原因 |
| 你更急 | 你有下一步可做 |

> 记住这句：**卡住时缺的不是需求，是现状。**

### 三招里最容易被忽略的一招：要求分步

很多人不愿意用第三招，觉得"那不就等于我自己在干吗"。

不是。分步是**把验收点提前**，不是把活接回来。

| | 一次全做完 | 要求分步 |
|-|-|-|
| 你参与几次 | 0 次 | 每步 1 次 |
| 出错时改多大 | 整个结果 | 只改最后一步 |
| 总耗时 | 常常更长（要重做） | 略长，但不用重做 |

> 一句话：**分步不是慢，是不用重来。**

### 复现问题模板

> 什么时候用：出错后要把问题讲清楚。重点改：现象、我做了什么两行。

> 复制后把【】里的内容换成你的。
```text
现象：
我做了什么（一步步写）：
我给的输入（关键信息请脱敏）：
AI 报的错 / 不对劲的输出：
最近改了什么：
请先给最多 3 个可能原因，每个配一个验证步骤，别直接全量重做。
```

| 复制后改哪里 | 改成什么样 |
|-|-|
| 现象 | 一句话说清"哪里不对" |
| 我做了什么 | 按顺序编号，1、2、3 |
| 我给的输入 | 贴关键那几行就够，**先脱敏** |
| 报的错 | 原文照抄，别自己总结 |
| 最近改了什么 | 上一次改动是什么，没有就写"没改" |

> **脱敏**就是把人名、手机号、金额、公司名这类信息换成"某某"，再贴给 AI。

**填写示例：**

> 复制后把【】里的内容换成你的。
```text
现象：整理待办清单时，两条不同的人被写成同一个负责人
我做了什么（一步步写）：
1. 贴入 8 月周会记录原文
2. 发任务书要求整理成三列待办表
3. 它输出后发现第 2、4 行的负责人写成了同一个人
我给的输入（关键信息请脱敏）：会议记录第 3 段写"小李跟进"、第 7 段写"李工跟进"
AI 报的错 / 不对劲的输出：两行都写成"小李"
最近改了什么：没改任务书，只换了输入记录
请先给最多 3 个可能原因，每个配一个验证步骤，别直接全量重做。
```

### 复现模板每一行都要写吗

不用。**最少写前三行**，能定位问题就够。

| 行 | 必填吗 | 缺了会怎样 |
|-|-|-|
| 现象 | 必填 | 它完全不知道你说什么 |
| 我做了什么 | 必填 | 它无法排除你操作的问题 |
| 我给的输入 | 尽量填 | 它只能猜你的材料长什么样 |
| 报的错 / 不对劲的输出 | 有就填 | 少了最直接的线索 |
| 最近改了什么 | 有就填 | 漏掉最可能的原因 |
| 最后那句要求 | 必填 | 它可能直接全量重做 |

> 最后那句"别直接全量重做"最容易被漏，也最省事。**它能帮你省掉一次白干。**

### 把"现象"写清楚的三句话

| 写法 | 例子 |
|-|-|
| 哪里不对 | "第 2 行负责人写错了" |
| 应该是什么 | "应该是李工，不是小李" |
| 影响多大 | "这一行会影响后面的待办分配" |

三句话写完，现象这一行就够了。别写"感觉不太对"。

### 卡住时不要做的三件事

| 别做 | 为什么 |
|-|-|
| 直接重开新窗口 | 上下文丢了，你得从头讲一遍，它还会犯同样的错 |
| 干等或反复发"？" | 它不会自己变好 |
| 自己上手改结果 | 那这活就没交给 AI，等于白做 |

> 重开窗口只有一个理由：**当前对话已经被你带偏了。** 先试三招，再考虑重开。

## 照着做

下次卡住时，按这 6 步走：

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 停手，别重开窗口 | 省下一次重讲 | 已经重开了就先把任务书重新贴一遍 |
| 2 | 判断卡在哪一类 | 三招里的某一招 | 分不清就先用第一招 |
| 3 | 抄对应那一招的句式 | 一句能直接发的话 | 句式里没有你的情况就自己补一行 |
| 4 | 把【】换成你的真实内容 | 一段具体的话 | 现象写不出就截个图照着描述 |
| 5 | 发出去，只等它回这一句 | 它给出原因或一个验证步骤 | 它又跑偏了就补"先别动手，只给原因" |
| 6 | 按它给的步骤验一次 | 确认是不是这个原因 | 三招都无效，才考虑重开窗口 |

## 常见错误

- **错误一：三招一次全发。** 它抓不住重点。一次一招。
- **错误二：现象写成情绪。** "它总是乱来"没法定位。写"第 2 行负责人写错了"。
- **错误三：只说"我贴了"却没贴。** 它看不到就是看不到。
- **错误四：忘了脱敏。** 贴输入前把人名、金额、公司名换掉。
- **错误五：一卡住就重开窗口。** 上下文没了，它更容易重犯。
- **错误六：让它"全量重做"。** 重做一遍可能错得更远，先要原因和验证步骤。

## 本节练习

5 分钟，手机就能做。回想你最近一次卡住，用复现模板填三行：

> 复制后把【】里的内容换成你的。
```text
现象：【一句话】
我做了什么：【1、2、3】
我给的输入（已脱敏）：【关键那几行】
```

填完存起来。下次真卡住时，你只需要改两个字就能发出去。
