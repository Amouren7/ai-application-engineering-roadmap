# 14.01｜A组任务书模板：开工前把话说清

## 本节目标

拿到 5 个能直接复制的任务书模板，知道什么时候抄哪一个。

## 一句话结论

> 任务书模板不用背，用的时候抄一份、改三行。改的是【】里的占位内容，不是整段重写。

## 展开讲

A 组管"开工"。任务还没发出去之前，先把话说明白。

这 5 个模板覆盖你九成以上的活。它们结构一样，只是字段不同。

### 5 个模板分别管什么

| 模板 | 什么时候抄它 | 重点改哪两行 |
|-|-|-|
| 通用版 | 接到任何一件想交给 AI 的活 | 目标、验收 |
| 文档处理版 | 总结、改稿、转表格 | 具体要求、验收 |
| 表格与数据处理版 | 整理 Excel、清洗数据 | 规则、边界 |
| 做应用版 | 想让 Agent 做出一个能用的软件 | 最小版本、验收 |
| 让 AI 教你版 | 你不只想让它干活，还想学会 | 我现在的水平、验收 |

> 记法：**不知道抄哪个，就抄通用版。** 通用版能跑通大多数活。

### 一个模板的固定三段

每个模板下面都有三段内容，顺序固定，别跳。

| 段 | 讲什么 | 你要做什么 |
|-|-|-|
| 什么时候用 | 这个模板对哪种活 | 对上号再抄 |
| 复制后改哪里 | 哪几行是关键，别漏 | 优先改那两行 |
| 一个填写示例 | 填好的样子长什么样 | 照它的语气填 |

### 通用版（任何任务都能用）

> 什么时候用：接到任何一件想交给 AI 的活。重点改：目标、验收这两行，它们决定活干得对不对。

> 复制后把【】里的内容换成你的。
```text
目标（我要的最终结果，能验收）：
资料（我给 AI 什么：文件、链接、背景）：
边界（绝对不许 AI 做的事）：
验收（做到哪几点才算完成）：
输出（放在哪个文件、什么格式）：
```

| 复制后改哪里 | 改成什么样 |
|-|-|
| 目标 | 一句话，末尾能打钩，例："整理成 5 条待办" |
| 资料 | 写清是贴文字、上传文件，还是给链接 |
| 边界 | 至少一条"不许编" |
| 验收 | 2–3 条能打钩的，别超过 5 条 |
| 输出 | 文件还是消息、表格还是清单 |

**填写示例：**

> 复制后把【】里的内容换成你的。
```text
目标：把这份 8 月周会记录整理成待办清单，一行一件事
资料：会议原始记录，我贴在下面（未经整理）
边界：不许补充记录里没有的内容；没写负责人的写"待定"
验收：① 每条只有一个负责人 ② 没有编造的人名 ③ 条数不少于记录里的动作数
输出：直接发消息给我，用三列表格
```

### 文档处理版（总结 / 改稿 / 转表格）

> 什么时候用：处理文档类任务。重点改：具体要求、验收两行。

> 复制后把【】里的内容换成你的。
```text
我要处理的文档：
我要的结果：一份（如：3 条要点 / 润色后的正式稿 / 一张表）
具体要求：字数、语气、是否标注原文出处
边界：不许改写事实 / 不许编造原文没有的内容
验收：能逐条对回原文，没有多出来的东西
```

| 复制后改哪里 | 改成什么样 |
|-|-|
| 我要的结果 | 说清形态和数量，例："3 条要点，每条一句话" |
| 具体要求 | 字数上限 + 语气 + 要不要标出处 |
| 边界 | 两条固定话：不改事实、不编内容 |
| 验收 | 写"能对回原文"，这是最硬的一条 |

**填写示例：**

> 复制后把【】里的内容换成你的。
```text
我要处理的文档：一篇 3000 字的行业分析文章（贴在下面）
我要的结果：一份 5 条要点的学习笔记
具体要求：总字数不超过 300 字；用大白话，不用行业黑话；每条要点后面标出原文句
边界：不许改写事实；不许编造原文没有的内容
验收：5 条要点都能在原文里搜到对应句子
```

### 表格与数据处理版

> 什么时候用：整理 Excel、清洗数据。重点改：规则、边界两行。

> 复制后把【】里的内容换成你的。
```text
我的数据在哪（表名 / 文件 / 范围）：
我要的结果：一张整理后的表（每列叫什么、要哪些列）
规则：去重、统一格式、标出异常值等
边界：不许删原始数据 / 不许改数字
验收：抽查几行，和原始数据对得上
```

| 复制后改哪里 | 改成什么样 |
|-|-|
| 我的数据在哪 | 表名或文件名 + 大概多少行 |
| 每列叫什么 | 列名写死，别让它自己起名 |
| 规则 | 一条一行，例："金额统一保留两位小数" |
| 边界 | 必写"不许删原始数据、不许改数字" |
| 验收 | 写"抽查几行对得上"，别写"看着没问题" |

**填写示例：**

> 复制后把【】里的内容换成你的。
```text
我的数据在哪：销售流水.xlsx 的 Sheet1，约 320 行
我要的结果：一张整理后的表，四列：日期、客户、金额、备注
规则：日期统一成 2026-08-01 格式；金额保留两位小数；重复订单只留一条并标"重复"
边界：不许删原始数据；不许改任何数字；拿不准的行标"待人工确认"
验收：抽查 5 行，和原始表逐格对得上
```

### 做应用版（接第 07 章）

> 什么时候用：想指挥 Agent 做出一个能用的软件。重点改：最小版本、验收两行。

> 复制后把【】里的内容换成你的。
```text
我要做的应用：一句话说清它给谁用、解决什么
第一版只做什么（最小版本）：
数据 / 资料从哪来：
边界：不上传敏感数据 / 不自动花钱
验收：我自己点一遍能跑通，结果能用
暂不做的（以后再说）：
```

| 复制后改哪里 | 改成什么样 |
|-|-|
| 一句话说清 | 格式："给【谁】用，解决【什么】" |
| 最小版本 | 只写 1–2 个功能，多了第一版做不完 |
| 数据从哪来 | 你自己的文件，还是先用手写几条假数据 |
| 暂不做的 | 把"以后再说的"列出来，防止它自作主张加功能 |

**填写示例：**

> 复制后把【】里的内容换成你的。
```text
我要做的应用：给不会编程的我自己用，把一篇长文变成带问答的学习笔记
第一版只做什么：贴入一篇文字，输出"摘要 + 3 个概念"，能点按钮重新生成
数据 / 资料从哪来：我自己粘贴的文本，先不接文件上传
边界：不上传敏感数据；不自动花钱；不联网抓取
验收：我自己点一遍能跑通，摘要不超过 100 字，概念刚好 3 个
暂不做的：多文件批量、账号登录、发布给别人用
```

### 让 AI 教你学东西版

> 什么时候用：你不只是想让它干活，还想顺便学会。重点改：我现在的水平、验收两行。

> 复制后把【】里的内容换成你的。
```text
我想学会：
我现在的水平（完全没学过 / 会一点）：
请这样教：先用一句话+一个类比讲清，再给一个小练习，别一次灌太多
验收：我能用自己的话复述，并能做一个最小练习
```

| 复制后改哪里 | 改成什么样 |
|-|-|
| 我想学会 | 一个具体问题，别写"我想学会 AI" |
| 我现在的水平 | 老实写，写"完全没学过"不丢人 |
| 请这样教 | 保留那句"别一次灌太多" |
| 验收 | 两条：能复述 + 能做出一个小练习 |

**填写示例：**

> 复制后把【】里的内容换成你的。
```text
我想学会：什么是"上下文"，为什么对话长了它就忘事
我现在的水平：完全没学过，只会用聊天工具
请这样教：先用一句话+一个类比讲清，再给一个小练习，别一次灌太多
验收：我能用自己的话复述，并能举一个"我遇到的忘事例子"
```

### 五个模板的公共部分

这五行几乎每个模板里都有，抄的时候顺手带上：

| 公共行 | 为什么必须有 |
|-|-|
| 目标 / 结果 | 没有它，AI 自己定方向 |
| 资料在哪 | 不给料，它只能编 |
| 边界 | 不写红线，它可能删数据、改数字 |
| 验收 | 不写标准，你没法判断对不对 |
| 输出形态 | 不写格式，拿回来还要自己排版 |

## 照着做

用通用版走一遍，10 分钟：

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 挑一件今天真要做的活 | 一件真事 | 没有就先抄小橙的会议记录例子 |
| 2 | 整段复制通用版模板 | 五行空的模板 | 复制漏行就重新复制一次 |
| 3 | 先填"目标"和"资料"两行 | 两行有内容了 | 目标写不出就回 03 章 01 节 |
| 4 | 填"边界"，至少一条"不许编" | 一条红线 | 想不出就照抄示例里那句 |
| 5 | 填"验收"，写 2–3 条能打钩的 | 一份打钩清单 | 写不出就打钩不了，回去改目标 |
| 6 | 填"输出" | 五行齐了 | 拿不准就写"直接发消息，用表格" |
| 7 | 扫一眼有没有【】残留 | 干净的模板 | 有残留就换掉，别直接发 |
| 8 | 发出去 | AI 开始干活 | 结果不对就进 02 节 |

## 常见错误

- **错误一：把模板当标准答案不敢改。** 模板是草稿，删行加行都行。用不上的字段直接删。
- **错误二：留着【】就发。** 它会把占位符当内容。发之前扫一眼。
- **错误三：五个模板想一次全用。** 一个任务抄一个模板就够，混着用反而乱。
- **错误四：验收写成感受。** "专业一点""简洁一点"没法打钩，换成数字和条数。
- **错误五：做应用版里不写"暂不做的"。** 不写它就会顺手加功能，第一版永远做不完。
- **错误六：边界照抄不改。** 你的任务可能怕的是别的风险，按自己的活补一条。

## 本节练习

5 分钟，手机就能做。抄通用版，填一件真事，只填"目标"和"边界"两行：

> 复制后把【】里的内容换成你的。
```text
目标（我要的最终结果，能验收）：【一句话】
资料（我给 AI 什么）：【贴文字 / 上传文件 / 链接】
边界（绝对不许 AI 做的事）：【至少一条"不许编"】

输出（什么格式）：【表格 / 清单 / 几段话】
```

填完把它存进备忘录，这就是你模板库的第一个文件。
