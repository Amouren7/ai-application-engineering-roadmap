## 2026-02｜零代码"Agent 驾驶"路线重构

- **课程定位**：从"工程向"改为"面向纯零基础、指挥 Agent 干活与做应用"。
- **主线策略**：主线不再要求写代码；代码改由 Agent 写，学员只负责拆任务、写任务书、验收和纠错。
- **章节改名与重写**：
  - 00、01、02 作为样板先行重写；
  - 03–10 按新定位重写（主线教学章）；
  - 11–15 改造为参考 / 工具 / 进阶章。
- **新增附录**：新增《附录：真正的工程进阶》，承接原工程向内容（Python 最低基础、命令行、Git、API、JSON）。
- **与飞书工程版的关系**：本仓库教学版与飞书工程版保持对照关系，每章顶部注明对应原文链接。

## 2026-09｜精细化改版：每章拆成短小节

这一版解决的是"每章太粗、学不到具体怎么做"的问题。

- **结构变化**：原来一章一个 md（96–199 行）→ 现在一章一个目录，目录里 7–12 个短小节，每节 10–15 分钟只讲一个动作。
- **文件命名**：全部目录与文件改为中文命名（如 `docs/03-任务书方法论/01-要什么结果.md`），旧英文文件名不再保留。
- **每节固定模板**：本节目标 → 一句话结论 → 展开讲 → 照着做（步骤表：你做什么 / 会看到什么 / 不对怎么办）→ 常见错误 → 本节练习 → 下一步。
- **新增内容**：每节都有"照着做"分步表和"出错怎么办"；每章新增 `00-导读.md`（小节地图）与 `99-本章验收与下一步.md`（验收清单）。
- **写作规范**：写入 `docs/重构设计-2026-精细化改版.md`，作为后续所有章节改写的唯一规格。
- **内容不变**：课程定位、读者对象、L0–L6 能力地图、贯穿案例"小橙"、与飞书工程版的对照关系全部保留；原章知识点一条没删，只是讲得更细。

> 想看这次改版的完整规格（每章有哪些节、每节讲什么），读 [精细化改版规格](重构设计-2026-精细化改版.md)。
