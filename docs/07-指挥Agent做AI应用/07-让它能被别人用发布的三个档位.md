# 07.07｜让它能被别人用：发布的三个档位

## 本节目标

分清"本地跑 / 发给别人 / 上网"三个档位，知道现在该停在哪一档。

## 一句话结论

> 先在自己电脑上跑通，再谈发布。发布分三个档位，绝大多数人停在前两档就够了。

## 展开讲

应用做好了，在你电脑上跑没问题。那怎么"给别人用"？

这一步叫**发布**，也叫**部署**（deploy，就是"把程序放到一个别人能访问的地方运行"）。

### 三个档位

| 档位 | 谁能用 | 要花什么 | 门槛 |
|-|-|-|-|
| ① 自己电脑用 | 只有你 | 免费，本地跑 | 最低，能跑就行 |
| ② 发给别人用 | 会装的人 | 打包发过去，对方自己跑 | 中，对方要会一点操作 |
| ③ 网页上跑 | 任何人，点链接就用 | 通常要少量费用（租服务器/托管），可能需账号或额度 | 最高，涉及钱和账号 |

**档位越高，麻烦越多。** 不是越高越好，是够用就好。

### 每一档具体要什么

| 档位 | 你要准备 | 对方要做什么 |
|-|-|-|
| ① 本地 | 你的电脑 + 装好的运行环境 | 无 |
| ② 发给别人 | 把文件打包，写一份使用说明 | 装环境、按说明跑 |
| ③ 上网 | 一个托管账号、少量费用、一个链接 | 点链接就能用 |

第 ② 档最容易翻车：对方没装环境，打不开，然后来找你。

**所以要配一份"三句话说明"：这是什么、怎么打开、出错了找谁。**

### 你现在该停在哪一档

| 你的情况 | 建议档位 |
|-|-|
| 只有你自己用 | ① 本地 |
| 要给一两个同事用，他们愿意装 | ② 发给别人 |
| 要给不特定的人用，点开就用 | ③ 上网 |
| 还在改功能 | ① 本地，先别发布 |
| 涉及别人的数据、要花钱 | 先别发布，等学完第 08 章 |

> 一句话：**能本地跑通，就已经是 L5 的成果。发布是加分项，不是必答题。**

### 关于第 ③ 档的钱和账号

想发布到网上，通常要花一点钱，按用量付费，起步很少。

也可能需要一个海外账号或 API 额度。这两件事都要提前想清楚。

| 你可能担心的 | 实话 |
|-|-|
| 会不会很贵 | 起步通常很少，用多少花多少 |
| 会不会自动扣钱 | 要设上限，第 08 章会讲 |
| 没有账号能不能做 | 可以先停在 ① ② 档，不影响主线 |
| 上线了会不会被人乱用 | 可以设访问密码或只发给熟人 |

**到那一步，直接让 Agent 带着你一步步做。** 它会告诉你每一步点哪里、填什么。

本章不展开，先把"应用能在你电脑上跑通"做到。

### 发布前自检

不管哪一档，发布前先过这五条：

| 检查 | 合格 |
|-|-|
| 空输入有提示吗 | 有中文提示，不是报错 |
| 正常样例能过吗 | 能 |
| 至少三个刁难样例能过吗 | 能 |
| 有使用说明吗 | 三句话：干什么、怎么开、出错找谁 |
| 有成本上限吗 | 设了，或知道去哪设 |

五条都过，再谈给谁用。

## 照着做

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 先在你自己电脑上跑一遍 | 能出结果 | 跑不通先回第 05 节 |
| 2 | 判断这个应用要给谁用 | 自己 / 几个人 / 不特定的人 | 拿不准就先按"自己"办 |
| 3 | 按上面表格选档位 | ① / ② / ③ | 犹豫就选低一档 |
| 4 | 过一遍发布前自检五条 | 五条打钩 | 有没过的，先修再发布 |
| 5 | 如果是 ② 档，让 Agent 写一份使用说明 | 三句话说明 | 说明里出现术语就让它改人话 |
| 6 | 如果是 ③ 档，让 Agent 带你做 | 一步步的操作指引 | 任何一步涉及花钱，先停下问清楚 |
| 7 | 把发布方式记进备忘录 | 一行记录 | 顺手记下花没花钱 |

第 6 步里，**凡是让你填支付信息的地方，都先停下来问清楚再继续。**

## 常见错误

- **错误一：一上来就要"发布到网上、给全世界用"。** 先在自己电脑跑通，再谈发布。
- **错误二：把发布当成必答题。** 本地能跑通就是 L5 成果，发布只是加分。
- **错误三：发给别人却不写使用说明。** 对方打不开，最后还是要你远程教。
- **错误四：没设成本上限就上线。** 上线后可能被反复调用，花钱不受控。
- **错误五：以为发布要花很多钱。** 起步通常很少，但必须设上限、知道在哪看用量。
- **错误六：功能还在改就发布。** 每次改完都要重新发布一次，先稳定再发。

## 本节练习

5 分钟。填三行：

```text
这个应用我要给谁用：【自己 / 几个人 / 不特定的人】
我选的档位：【① 本地 / ② 发给别人 / ③ 上网】
我发布前还差的一条：【 】
```

最后一行那个"还差的一条"，就是你现在要回去修的地方。
