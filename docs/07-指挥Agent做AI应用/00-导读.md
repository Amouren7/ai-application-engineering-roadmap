# 07｜指挥 Agent 做 AI 应用：从文档助手到可运行产品

> 本章目标：看懂"做应用"和"干一次活"的区别，跟着小橙走完从一句话需求到能运行产品的全过程，并学会怎么验收一个应用。
> 这一章对应能力地图的 **L5**：从"用一次"走到"能反复用"。

## 本章开始前：准备与产出

| 项目 | 说明 |
|-|-|
| 账号要求 | 一个开发型 Agent 工具（Codex / Claude Code / Cursor 任选其一）；只跟读主线可以不装 |
| 能否只用手机完成 | 不建议。做应用、跑程序建议用电脑 |
| 主线要不要写代码 | 不需要。你写任务书，代码全部由 Agent 生成 |
| 预计用时 | 约 2 小时，建议分 4 次学完 |
| 本章产出 | ① 一份应用类任务书；② 看懂小橙做"文档学习助手"的全程；③ 可选：自己指挥出一个能运行的小应用 |

### 准备到什么程度就够了

不需要提前装好工具。前 4 节全是"看懂 + 写任务书"，手机也能跟。

第 05 节开始要跑应用，那时再装工具也不晚。

## 这一章和你前面学的有什么关系

前面六章，你练的都是"把一件活干完"。这一章换个对象：让 Agent 帮你**做一个能反复用的东西**。

| 你已经会的 | 这一章往上加什么 |
|-|-|
| 写任务书四要素 | 加"输入 / 输出"两个固定口子 |
| 验收一张表、一份纪要 | 验收一个程序：跑正常样例 + 刁难样例 |
| 它做完你看结果 | 它写完代码，你要能看出"它有没有越界" |
| 一件事干一次 | 固化下来，别人也能用 |

方法没变，还是写任务书、看结果、让它改。变的只是对象变大了。

## 学完本章你会有的四样东西

## 一句话预告

> 这一章最想让你带走的一句话：**应用 = 把任务书固化成一个产品。需求你提，代码 Agent 写，多出来的是"反复用 + 会处理出错"。**
