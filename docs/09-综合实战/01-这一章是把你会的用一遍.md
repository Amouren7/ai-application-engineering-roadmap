# 09.01｜这一章是把你会的用一遍

## 本节目标

搞清楚这一章不是学新东西，而是把你会的动作串起来用一次。

## 一句话结论

> 这一章没有新概念，只有一件事：把你前 8 章学会的驾驶动作串成一条线，交付一个真东西。

## 展开讲

你已经学完了全套动作：

- 说清楚（02、03 章）
- 拆任务（03 章）
- 看过程（04 章）
- 验收纠错（05 章）
- 做应用（07 章）
- 守边界（08 章）

这一章要做的，是把它们**按顺序用一遍**。

### 学会动作 vs 串成一条线

| | 学会动作（前 8 章） | 串成一条线（本章） |
|-|-|-|
| 练什么 | 单点技能：写任务书、看 diff、验收 | 完整流程：从 0 到交付 |
| 谁给题目 | 教材给（小橙的案例） | 你自己选一件真事 |
| 结果归谁 | 练手，不一定要用 | 你真的会用它 |
| 判断标准 | 这一步做对没有 | 整个东西能不能给别人看 |

单点练十次，不如完整走一次。

因为真实项目里，动作是连着的：任务书没写清，第 3 步就拆不开；没拆开，第 4 步就没法验收。

### 为什么"完整"比"大"重要

| 做法 | 结果 |
|-|-|
| 一个只有三步、但完整走完的小项目 | 你能说清每一步怎么做的，能给别人看 |
| 十个停在想法里的大项目 | 一个都交付不了，也没法复盘 |

> 记住：**一个只有三步、但完整走完、能给别人看的小项目，胜过十个停在想法里的大项目。**

### 这一章你会产出什么

| 产出 | 长什么样 | 谁看 |
|-|-|-|
| 选题一句话 | "用户是谁、解决什么问题、要什么结果" | 你自己 |
| 任务书 | 四要素齐全的一段文字 | Agent 执行 |
| 3–5 步拆解 | 每步一个"能验收的结果" | 你自己排期 |
| 验收记录 | 至少 2 步的验收动作和结论 | 你复盘用 |
| 复盘 | 复盘四问填完 | 你自己成长 |
| 成果 | 文件夹 / 文档 / 截图都算 | 同事、朋友 |

### 四个动作，这一章要连起来做

前 8 章教的动作，归成四个。这一章就是把这四个连成一条流水线：

| 动作 | 人话解释 | 一次项目里你会做几次 |
|-|-|-|
| 说清楚 | 把"要什么结果、给什么材料、边界、什么算完成"写进任务书 | 每个大任务 1 次 |
| 拆开 | 把大目标切成 3–5 个能验收的小步 | 1 次，项目开始时 |
| 盯着看 | 看它做到哪了、改了什么 | 每一步都看 |
| 验一遍 | 对照"什么算完成"逐条核对，不对就让它改 | 每一步都验 |

四个动作缺一个，项目就会漏。漏得最多的是第四个。

### 小橙在这一章的状态

小橙前面 8 章练的都是教材里的例子。到了这一章，她第一次拿**自己的真事**做：部门三年的培训文档。

她的感受是："原来那些动作单独练的时候没感觉，连起来做才发现——卡住的地方，全在前 8 章讲过。"

## 常见错误

- **错误一：以为这一章要学新东西。** 不学。这一章是考试，考的是前 8 章的动作。翻不到新概念是正常的。
- **错误二：等"准备好"再开始。** 没有准备好的时刻。选一个你真会用到的小事，边做边补。
- **错误三：把项目定得太大。** "整理全公司三年的文档"太大。改成"整理我手边最常用的 10 份"。
- **错误四：只做不记。** 每步做完记一行（做了什么、看到什么、结论），不然复盘时什么都想不起来。
- **错误五：把这一章当"复习"扫过去。** 读一遍不等于做一遍。这一章的唯一通过方式是交付一个真东西。
- **错误六：等着"学完再练"。** 这一章没有新知识可学，练就是学。
