# 09｜综合实战：一个人从 0 交付一个真实成果

> 本章目标：把你前 8 章学会的驾驶动作串成一条线——选一个真实项目，从写任务书到验收、复盘、展示，完整走一遍。

## 本章开始前：准备与产出

| 项目 | 说明 |
|-|-|
| 账号要求 | 一个 AI 聊天工具即可（豆包/Kimi/DeepSeek/ChatGPT 任选）；做"AI 应用型"选题再准备开发型工具（见 07 章） |
| 能否只用手机完成 | 前四步（选题、任务书、拆解、复盘）手机就能做；执行文件级任务建议用电脑 |
| 主线要不要写代码 | 不需要。代码由 Agent 写，你写任务书、做验收 |
| 预计用时 | 约 2–3 周，每天 25–40 分钟 |
| 本章产出 | 一个真实项目：任务书 + 3–5 步拆解 + 至少 2 步的验收记录 + 一份复盘 |

## 三种时间，三条读法

你手上时间不一样，读法也不一样：

| 你的情况 | 怎么读 | 大约花多久 |
|-|-|-|
| 只想先弄明白这一章干什么 | 只读 01 + 02 | 20 分钟 |
| 准备这周就开项目 | 01 → 02 → 03 → 04，边读边填 | 45 分钟 |
| 项目已经做了一半 | 直接读 05 复盘 + 06 示范 | 25 分钟 |
| 完整学一遍 | 从 01 到 07 按顺序 | 约 1.5 小时 |

> 没读完就开工也行。**卡到哪一步，再回来读那一步。**

## 这一章和前 8 章的关系

前面每一章教一个动作。这一章不教新动作，只做一件事：**把它们串成一条线。**

| 你学过的动作 | 在哪一章 | 在这一章里用在哪一步 |
|-|-|-|
| 说清要什么、给什么材料、边界、完成标准 | 02、03 | 第 2 步写任务书 |
| 把大任务拆成 3–5 步 | 03 | 第 3 步拆解 |
| 看过程、看 diff、判断对不对 | 04、05 | 第 4 步每步验收 |
| 验收四看、反馈句式、失败自救 | 05 | 第 4 步出错时 |
| 指挥 Agent 做应用 | 07 | 选"AI 应用型"选题时 |
| 安全、成本、边界三栏清单 | 08 | 每一步交付前 |

> 一句话：这一章是**考试**，不是**新课**。考卷就是你自己那件真事。

## 第一次做，记住三条

| 别做 | 改成 |
|-|-|
| 想做个"大而全"的项目 | 做小、做完整，砍功能也是能力 |
| 跳过任务书直接让 Agent 开干 | 先写四要素，翻车返工更慢 |
| 攒到最后一起验收 | 做一步验一步，错一步别带三步 |

## 开工前，先回答三个问题

| 问题 | 如果答不上来 | 去哪一节 |
|-|-|-|
| 我要做的这件事，做完给谁用？ | 说明选题还没落地 | 02 节 |
| 我手上的资料在哪？ | 说明资料还没到手 | 02 节"照着做" |
| 我每天能挤出多少分钟？ | 说明排期还没排 | 04 节 |

三个都答得上来，你就可以直接开第 1 步了。

> 建议顺序：先看 01 节搞清楚这一章要干什么，再从 02 节选一个选题。
