# 01｜认识"会干活的 AI"：聊天机器人 vs Agent 工具

> 本章目标：分清"会聊天的 AI"和"会干活的 AI"，知道你现在手里有什么、还差什么，并选定你第一件要交给它的真实任务。

## 本章开始前：准备与产出

| 项目 | 说明 |
|-|-|
| 账号要求 | 一个 AI 聊天工具即可；想试用办公综合型 Agent（如腾讯 WorkBuddy）可另注册 |
| 能否只用手机完成 | 可以 |
| 主线要不要写代码 | 不需要 |
| 本章产出 | 你选定一件真实任务，并判断它适合交给哪一类 AI |

## 先看一个差距：聊天和干活是两回事

同样一句话，两种 AI 的反应完全不同。

**你问（对普通聊天 AI）：**"帮我把这份 3 万字的调研报告整理成 10 页 PPT 的要点。"

普通聊天 AI 的回答是：好的，我建议 PPT 分这几部分：一、……二、……（它给你的是**建议**，活还得你自己干）。

**你问（对 Agent 工具，且给了它文件）：**"读一下 `调研报告.docx`，整理成 10 页 PPT 的要点，每页一个主题加三条要点，输出到 `汇报要点.md`。"

Agent 工具的流程是：打开文件 → 阅读 → 分析 → 生成要点 → 写入新文件 → 告诉你"已完成，文件在 XXX，我按每页一个主题整理了……"。它做的是**执行**，你拿到的是**成品**。

> 一句话区分：**聊天 AI 给你答案，Agent 给你结果。** 这门课教你怎么拿到结果。

## 三种 AI 入口，先认个全貌

你现在可能只见过第一种。它们不是竞争关系，是**三种档位的车**：

| 类型 | 代表工具 | 它擅长 | 门槛 | 类比 |
|-|-|-|-|-|
| 问答型 | 豆包、Kimi、DeepSeek、ChatGPT | 回答、写作、翻译、总结，一次一问 | 注册即用（手机/网页） | 出租车：招手即停，说去哪去哪，但只送你到地方 |
| 办公综合型 | 腾讯 WorkBuddy 等"替你干活"类 | 接管你电脑/工作台，替你操作多个步骤：读写文档、填表、整理文件 | 免费或内测，下载安装 | 代驾司机：把车钥匙给它，它替你开完全程 |
| 开发型 | OpenAI Codex、Claude Code、Cursor | 读写你电脑里的文件、写代码、跑程序、把想法做成能用的软件 | 需要海外账号或少量 API 预算 | 外包开发团队：你出需求和验收标准，它出成品 |

> 记不住没关系。你只要记住：**问答型练手，办公综合型感受"替你干活"，开发型做应用。** 后续章节会分别带你上手。

## Agent 工具到底能替你干什么

以下都是**今天就能让 AI 干**的真实任务（按难度从低到高）：

- 把一篇长文章总结成 3 条要点 + 1 张表格；
- 把会议记录改写成待办清单（含负责人和截止时间）；
- 把杂乱的 Excel 整理成规范的表格，并标出异常值；
- 把一批文件批量重命名（如"第1章_标题"格式）；
- 把录音转成的文字稿润色成正式文档；
- 给你写的一篇文章挑逻辑漏洞、提修改建议；
- 把几十封邮件分类并起草回复；
- 从网上帮你收集某主题的资料并整理成带出处的清单；
- 做一个能回答你自己资料问题的小应用（L5 你会亲手做到）；
- 让一个 3 万字的项目资料"开口说话"——你问它问题，它引用原文回答。

先别急着全做。**从中选一件你最近真的会遇到的事**，它就是你的第一个任务。

## 它能干什么、不能干什么：边界要早知道

AI 不是万能的，下面这张表值得打印出来贴在桌上：

| AI 能干 | AI 不能干 / 你绝不能让它干 |
|-|-|
| 读写你给它的文件、按步骤执行任务 | 替你做最终决定（尤其涉及钱、合同、人事） |
| 联网查公开资料（部分工具） | 访问你公司内部系统，除非你明确授权 |
| 写代码、运行程序 | 保证结果 100% 正确——它会一本正经地编造（幻觉） |
| 24 小时不休息地干活 | 替你承担责任——**结果出了错，责任是你的** |
| 整理、改写、翻译你的材料 | 知道"你公司的规矩"，除非你写进任务书 |
| 分步执行复杂任务 | 一次搞定你没说清楚的事——它只会猜 |

三个重点，现在就要记住：

1. **幻觉是常态，不是 bug。** AI 在不知道答案时会流畅地编一个。所以重要结论必须验证来源——这门课 L3 专教验收。
2. **授权才执行。** 它碰你电脑里的文件、发消息、花钱之前，应该先问你。如果某个工具不问你直接干，别用它处理重要资料。
3. **你负责，它不负责。** 它只是工具，签字的、背锅的、受益的都是你。

## 只需要 5 个名词

这门课尽量避免术语轰炸。主线你只需要这 5 个，每个配一个类比，其余名词放到 11 词典：

| 名词 | 一句话 | 类比 |
|-|-|-|
| 模型 | AI 的"大脑"，负责理解和生成文字的那部分 | 一个读过海量书的员工 |
| Agent（智能体） | 会自己安排步骤、调用工具、完成任务闭环的 AI | 一个会主动干活的助理 |
| 任务 | 你交给 AI 的、有明确结果的一件事 | 一张写清楚交付物的工单 |
| 上下文 | AI 这次"眼前看到"的全部信息（你的要求+资料+历史） | 助理手边的文件夹 |
| 工具 | AI 可以调用的能力（读文件、查网页、发消息） | 助理能用的电话、电脑和打印机 |

> 现在不要深究"模型内部怎么工作"。你只需要知道：**它看到的资料（上下文）决定它答得准不准；你交代的任务（任务书）决定它干得对不对。**

## 为什么"不会编程"也能做 AI 应用

这是本门课最重要的认知，值得单独说：

过去做一个软件应用，必须会编程。现在不用了，因为**编程这项能力可以被"外包"给 Agent**：

```text
旧方式：你学编程 → 你写代码 → 你调试 → 你做应用
新方式：你提需求 → Agent 写代码 → 你验收 → 你做应用
                    ↑ 这段归 Agent
```

但这不等于你什么都不用会。你不写代码，却要补上三样新能力——**这门课就教这三样**：

1. **说清楚**：把想法写成 Agent 能执行的任务书（L2 专讲）；
2. **看得懂**：能看懂 Agent 改了什么、结果对不对（L3 专讲）；
3. **守得住**：知道边界在哪，什么能交、什么不能交（安全边界在 L6 与第 08 章专讲）。

> 你不需要成为"会写代码的人"，但要成为"AI 干活的合格监工"。

## 常见误区

- **误区一：所有 AI 都一样。** 问答型、办公综合型、开发型是三种档位，选错工具就像用自行车拉货。
- **误区二：把 Agent 当搜索框。** 它是来干活的，不是来被提问的；给它任务，别只给它问题。
- **误区三：以为 Agent 会"自己全懂"。** 它只知道你给它的上下文，不知道你公司的规矩、你文件的背景。
- **误区四：看到"AI 说的"就信。** 幻觉随时可能发生，越是重要内容越要自己验证。
- **误区五：一上来就想做"万能应用"。** 先做一件小事、做好、验收，再扩大。小橙也是从"总结一篇文章"开始的。

## 可选动手（想做就做）

**对比实验：** 用你的问答型 AI 问同一个问题两次，体会"上下文"的作用：

1. 第一次直接问："这篇文章写了什么？"（不给文章——看它怎么尴尬）；
2. 第二次把一篇 200 字短文贴进去再问："总结这篇文章的三个要点。"

把两次回答的差别记下来。你会发现：**AI 的答案质量，很大程度取决于你给了它什么。** 这正是后面所有章节的地基。
