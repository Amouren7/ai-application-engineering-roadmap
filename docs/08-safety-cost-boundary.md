# 08｜安全、成本与边界：什么能交、什么绝不能交

> 本章目标：给你一套"交任务前的安全习惯"——知道什么能交给 Agent、什么要小心、什么绝不能交，以及出事了怎么停、钱花多了怎么控。

| 项目 | 说明 |
|-|-|

## 先把最重要的一句话记住

> **Agent 是工具，签字的是你。** 它干得再快，结果出了错，责任都是你的。所以你的任务不是"信任它"，而是"知道什么能给它"。

这一章不是让你害怕 AI，而是让你变得**能放心地用 AI**：边界划清楚了，你才敢把活交给它。

## 三栏清单：什么能交、什么要小心、什么绝不能交

把要交给 Agent 的东西，先扔进下面三个篮子。这一动作只要 10 秒，却能挡住绝大多数事故：

| 能交给 Agent | 要小心（先看它计划再动手） | 绝不能直接交（必须人来） |
|-|-|-|
| 公开资料的整理、总结、翻译 | 自己电脑里不含机密的个人文件 | 账号密码、支付密码、验证码 |
| 文字润色、起标题、写初稿 | 公司内部资料（先评估是否涉密） | 对外的正式发布（新闻稿、公告、发消息） |
| 零散记录整理成规范表格 | 合同、薪酬、客户隐私（先脱敏） | 法律、人事的最终决定（签不签、用不用人） |

- **能交**：资料公开、后果可控，交给 Agent 整理最省时间。
- **要小心**：可以交，但先让它把"第一步计划"说给你听，你确认没问题，再让它继续。
- **绝不能直接交**：一旦泄露或出错，损失无法挽回——必须你本人来做，或你亲自确认后才执行。

> 一条万能底线：**凡是能花钱、能对外说话、能泄露隐私、能替你做决定的动作，默认先停下，人来。**

## 敏感数据：交之前先问自己三句

**敏感数据** = 一旦泄露会造成损失的数据，比如个人信息、公司机密、合同、薪酬。判断"能不能交"别凭感觉，用三句话过一遍：

1. **这是什么数据？**（工作报告？合同？聊天记录？）
2. **里面有没有能识别到人的信息？**（姓名、工号、电话、身份证号、地址、照片）
3. **如果泄露，最坏后果是什么？**（自己尴尬 / 公司罚款 / 客户投诉 / 法律纠纷）

只要第 2 问是"有"、第 3 问不是"无所谓"，就先脱敏，再给 AI。

### 先脱敏，再给 AI

**脱敏** = 把能识别到人的信息换成假名，结构和规律保留给 AI 用。比如你要让 AI 整理一份报销明细，原表里有真人信息，给它之前先改成这样：

| 字段 | 原样（别给） | 脱敏后（可以给） |
|-|-|-|
| 姓名 | 王芳 | 张三 |
| 工号 | 04821 | 001 |
| 电话 | 138xxxx1234 | 删掉 |
| 金额 | 5280.00 | 约 5000（只留数量级） |

> 一个口诀：**名字换成"张三/李四"，工号换成"001/002"，电话邮箱删掉，金额只留数量级。** AI 要的是"字段规律"，不是"真人是谁"。

## 日志：负责任的 Agent 会像行车记录仪一样记下它做了什么

**日志** = 工具自动记录的一串"谁在什么时候做了什么"的流水。好的 Agent 工具都会留日志，第 04 章教你看"过程"，日志就是那份过程的存档。

把它想成行车记录仪：平时你不看它，一旦出了事故（结果错了、文件被误删、钱花超了），你就能调出来看"到底哪一步出了问题"。

> 所以别嫌日志烦，也别随手关掉它。**日志不是监视你，是保护你——出问题能复盘。**

## 幻觉兜底：重要结论，必须人工复核

**幻觉** = AI 在不知道答案时，流畅地编一个看着像真的答案（前几章反复提过）。它不会自己承认"我编的"，所以越重要的结论，越要你亲自核对。

规则很简单：**谁用谁负责。** AI 可以帮你查、帮你整理，但"这个结论能不能用"，最后拍板的是你。

小橙到了 L6，用 Agent 整理培训资料里引用的几个"行业数据"。交出去之前，她只核对三件事：

```text
小橙的核对清单（重要结论专用）
1. 这个结论，AI 有没有给出处？（没出处 = 先当存疑）
2. 按出处回去查，原文真的有这句话吗？（搜关键词核对）
3. 这个数据/结论如果错了，会不会害别人做错决定？（会 = 必须核到原文）
```

三条全过，她才放心用；有一条不过，就退回给 Agent 让它补出处或删掉。

## 成本：让 AI 做应用为什么花钱，怎么控制

做应用（第 07 章）时，应用背后调用的"云端大脑"（模型）是**按量计费**的——每问一次、每生成一段，都可能算一点钱，就像打电话按分钟计费，不是买断。

但不用慌，控制成本有四个动作，按顺序做：

1. **先问一句"大约花多少钱"。** 让 Agent 动手前估个量级：这个任务大概会调多少次模型、一次多少钱。心里有数再开始。
2. **从免费额度起步。** 大多数工具给新用户送一小笔免费额度（相当于送的试打电话费），先用它跑通，别急着充值。
3. **设预算上限。** 在工具设置里给"每天/每月最多花多少"设个上限，花到就停，不会一夜超支。
4. **用完即停。** 任务跑完就关掉还在运行的 Agent，别让它空转——空转也在按量花钱。

> 常见价格概念，一句话带过：你交的钱 = 模型读进去的字数 + 生成出来的字数，按"量"算，读得越多、写得越多越贵。**所以任务书写得越精炼，往往越省钱**——这也是第 03 章练任务书的另一个回报。

## 出事了怎么停：四个"紧急刹车"

不管多小心，都可能遇到意外。记住这四个刹车，每个都是一句话：

| 动作 | 一句话 |
|-|-|
| 停止任务 | 在工具里点"停止"，让它立刻别再往下做 |
| 撤销授权 | 把给过工具的"允许它做什么"的许可收回来 |
| 断开工具 | 关掉它连接你电脑/账号的入口（断开连接） |
| 回滚（应用版） | 退回到上一个还能用的版本，当这次改坏的东西没发生过 |

**授权** = 你允许一个工具做某件事的许可，比如"允许它读这个文件夹、发邮件"。给的时候想清楚，出事时收回来。

> 不用背。你只要记住：**任何时候发现不对，先停下、再收权、最后才考虑补救。**

## 交任务前的 5 个安全检查

这是本章要带走的核心产物。每次把任务交给 Agent 前，用 5 秒过一遍：

```text
交任务前 5 查（答不上来就先别交）
1. 我给它的是公开资料，还是已经脱敏？（敏感内容必须脱敏后给）
2. 我有没有写明"不许它做什么"？（花钱 / 对外发送 / 删文件）
3. 这个结果如果错了，我能不能自己发现并负责？（不能就别全交）
4. 我设了成本上限吗？（做应用时必查）
5. 我知道出事了怎么停吗？（停止 → 收权 → 断开 / 回滚）
```

5 条都过，你就已经是"会守住边界的人"，而不只是"会用 AI 的人"。

## 常见误区

- **误区一：只要是大厂出的工具，就什么都敢交。** 大厂不等于零风险，泄露的后果还是你担。判断标准是"数据敏不敏感"，不是"工具名气大不大"。
- **误区二：把敏感数据"顺手贴进去问一句"。** 问一句也可能被记录、被用于训练。先脱敏，再问。
- **误区三：以为设了预算上限就万事大吉。** 还要确认它真的"用完即停"——空转也在花钱。
- **误区四：重要结论 AI 说"没问题"就信了。** 幻觉不会自己承认，出处要你自己核。
- **误区五：出事了第一反应是"再让它修一下"。** 先停、先收权，再谈补救。
