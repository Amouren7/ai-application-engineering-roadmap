# 15.01｜看不懂代码一点也不丢人

## 本节目标

把"我看不懂"从羞耻感里拆出来，换成一个具体问题。

## 一句话结论

> 看不懂代码不是能力问题，是分工问题——你负责要什么，Agent 负责怎么写。

## 展开讲

第一次看到满屏英文、括号和缩进，心慌很正常。

心慌的来源不是代码本身，是三个默认想法。

| 你的默认想法 | 事实 |
|-|-|
| "看不懂就是我笨" | 你没学过，看不懂才是正常结果 |
| "看懂代码是及格线" | 主线没有这条及格线 |
| "不学会就没资格指挥 AI" | 你一直在指挥，而且有效 |

### 先把分工说清楚

这套课里，你负责三件事：

1. 说清要什么结果。
2. 提供材料和边界。
3. 验收结果对不对。

写代码是 Agent 的活。它有它的活，你有你的活。

> 术语：Agent 就是"能自己动手干多步活儿的 AI"。它不只是聊天，还会改文件、跑程序。

### 程序员也常常看不懂别人的项目

一个真实场景：程序员接手别人的项目，第一周同样看不懂。

他要靠三样东西摸清：说明书、目录结构、问人。

所以"看不懂"是所有人在新项目前的第一状态，不分职业。

> 术语：项目就是"一个能跑起来的东西"对应的一堆文件和文件夹。

### 怕的不是看不懂，是不知道怎么问

不会看代码的人卡住时，往往做两件事：

- 关掉窗口，重开一次。
- 自己乱改，越改越乱。

会看代码的人卡住时，做的是第三件事：**把问题描述清楚，然后问。**

| 卡住的样子 | 无效反应 | 有效反应 |
|-|-|-|
| 报错看不懂 | 关掉重来 | 整段复制，让 AI 用大白话解释 |
| 不知道改哪个文件 | 一个个点开乱找 | 问"想改 X 功能，该看哪个文件" |
| 一大段代码读不下去 | 硬读到底 | 问"这段用 3 句话讲给我听" |
| 一个词不认识 | 装作懂了 | 问"用一句人话解释这个词" |

有效反应有一个共同点：**把"我不会"换成"我要什么"。**

### 小橙的第一次心慌

小橙让 Agent 做了一个文档学习助手。

交付后 Agent 给了一串文件名，她点开一看，全是英文。

她第一反应是"我是不是走错路了"。

她做了两件事，五分钟就不慌了：

1. 问 Agent："这几个文件分别管什么？各用一句话说。"
2. 问 Agent："我想改摘要的长度，该看哪个文件？"

Agent 答得很清楚。她发现：代码看不懂，但问题问得清，照样能干活。

> 一句话：**你不缺看懂代码的能力，你缺的是提问的句式。**

### 把"我看不懂"改成一句具体问题

"我看不懂"是情绪，AI 接不住。

"这个文件是干什么的"是问题，AI 一句话就能答。

| 别这么说 | 换成这么说 |
|-|-|
| 我完全看不懂 | 这个文件负责什么？一句话说 |
| 这代码太乱了 | 这段代码的输入和输出分别是什么 |
| 我不会编程，怎么办 | 我想改摘要长度，该动哪个文件 |
| 报错了，救命 | 这是报错原文，请用大白话解释并给下一步 |

这四句话，你在后面几节还会反复用到。

## 照着做

花 3 分钟，做一次"把心慌换成问题"的练习。

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 打开任意一个 Agent 给过你的代码页面 | 一屏英文 | 手头没有，就让 Agent 随便生成一个示例文件 |
| 2 | 找出第一个不认识的词 | 一个单词或文件名 | 找不到，就先看文件列表里的名字 |
| 3 | 在心里写一句"这个 X 是什么" | 一句问题 | 问题太大，就缩成"这个文件干什么" |
| 4 | 把问题发给 AI | 一段大白话解释 | 解释里还有术语，回一句"再用更简单的话说一遍" |
| 5 | 用自己的话复述一遍 | 一句话 | 复述不出来，就再问一次 |
| 6 | 记下这次的问题句式 | 一句可复用的话 | 忘了就翻回本节最后那张表 |

做完你会发现：心慌没了，剩下的只是一个待办问题。

## 常见错误

- **错误一：把"看不懂"当成"我不行"。** 换成一句："我只是还没问而已。"
- **错误二：硬读每一行。** 读代码不是考试，跳过 90% 也是合法读法。
- **错误三：不敢问"蠢问题"。** 问"这是什么"永远不蠢，猜着改才蠢。
- **错误四：关掉报错重开。** 报错是唯一的线索，关掉等于把线索扔掉。
- **错误五：看一次不懂就下结论"我不适合"。** 一次看不懂，只说明这一次没问对。

## 本节练习

3 分钟，手机就能做。写下你最近一次"看不懂"的场景，改成一句问题：

> 复制后把【】里的内容换成你的。

```text
我看到的是一段【代码/报错/文件名】，我看不懂的是【具体哪一块】。
请用大白话告诉我：这是什么，下一步我该做什么。
```

发出去，看它的回答是不是你第一次真听懂的。
