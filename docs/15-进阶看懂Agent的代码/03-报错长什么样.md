# 15.03｜报错长什么样：三句话读完一段英文

## 本节目标

学会从报错里读出：哪一步、什么问题、下一步做什么。

## 一句话结论

> 报错不是天塌，是程序在说"我卡在这一步了"。整段复制给 AI，是你随时能用的一招。

## 展开讲

Agent 报错时，通常甩出一大段英文。别慌。

它其实只在说三件事。

| 报错在说什么 | 对应英文线索 |
|-|-|
| 在哪一步卡住 | 文件名 + 行号 |
| 出了什么问题 | 冒号后面那类错误名 |
| 大概什么原因 | 引号里的具体内容 |

记住这三条，一段英文就变成三句话了。

### 一个最短的例子

> 下面这段代码由 Agent 生成。你不需要会写，只需要看懂大意：它在找一个叫 data.csv 的文件，没找到。

```text
FileNotFoundError: [Errno 2] No such file or directory: 'data.csv'
```

翻译成人话：**"我没找到叫 data.csv 的文件。"**

就这一句。没有更多含义。

### 一个长一点的例子

报错常常不止一行。别怕，重点只有一处。

> 下面这段代码由 Agent 生成。你不需要会写，只需要看懂大意：程序在 app.py 第 12 行停下来，因为它要的文件不在它以为的位置。

```text
Traceback (most recent call last):
  File "app.py", line 12, in <module>
    df = read_data("data.csv")
FileNotFoundError: [Errno 2] No such file or directory: 'data.csv'
```

> 术语：Traceback 就是"走过的路"。它从下往上报，最下面一行才是真原因。

读法是：**先看最下面一行，再看倒数第二行里的文件名和行号。**

### 常见报错的人话对照表

这张表存下来，遇到时对一眼。

| 报错里的关键词 | 人话 |
|-|-|
| FileNotFoundError / No such file | 找不到文件，路径或文件名不对 |
| Permission denied | 没权限，可能是只读或没授权 |
| ModuleNotFoundError / No module named | 少装了一个依赖 |
| SyntaxError / Invalid syntax | 写法有错，通常是打错了一个符号 |
| KeyError | 要的那一项不存在 |
| Timeout / Connection refused | 网络不通，或者对方没在等它 |

### 为什么必须"整段复制"

只贴最后一行，AI 可能给出三种不同猜测。

整段贴上，它一次就能定位。

| 你贴的内容 | AI 能做什么 |
|-|-|
| "报错了" | 只能猜 |
| 只贴最后一行 | 猜得近一点，但仍可能猜错 |
| 整段 + 文件路径 | 直接定位，给出下一步 |

**整段复制，是最省时间的一步。**

### 报错和"结果不对"是两回事

这两种情况，处理方式完全不同。

| 情况 | 现象 | 该怎么办 |
|-|-|-|
| 报错 | 程序停下来，屏幕上一段英文 | 整段复制给 Agent，让它解释并修 |
| 结果不对 | 程序跑完了，但内容不是你想要的 | 这是任务书没写清，回到第 03 章改要求 |

分不清这两种，就会一直修错东西。

### 小橙的一次报错

小橙的助手第一次跑，屏幕上一片红。

她没关窗口，做了三件事：

1. 整段复制报错。
2. 加一句："我是纯小白，用大白话解释，再告诉我下一步。"
3. 照 AI 说的，把 data.csv 放到正确的文件夹。

第二次跑就通了。

她后来总结：**报错其实是在给你指路，不是在骂你。**

## 照着做

下次遇到报错，按这张表走。

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 别关窗口，别重开 | 报错原文还在 | 已经关了，就让它重跑一次 |
| 2 | 从最下面一行开始看 | 一行错误名 | 看不懂错误名，直接进第 4 步 |
| 3 | 找文件名和行号 | 类似 app.py line 12 | 没有行号，说明问题在配置或环境 |
| 4 | 整段复制（含路径） | 一段完整文本 | 太长就复制前后各 20 行 |
| 5 | 加上一句提问模板 | 发给 AI | 它答得太术语，回"再用大白话讲一遍" |
| 6 | 照它说的改一处，再跑一次 | 通过或新报错 | 又报新错，重复第 1 步 |
| 7 | 把这次报错记一行 | 一条经验 | 不记也行，但下次会重踩 |

一次只改一处。改多了，你不知道是哪处生效。

## 常见错误

- **错误一：关掉报错重开。** 线索没了，问题还在。
- **错误二：只看第一行。** 真原因通常在最后一行。
- **错误三：只贴一句"报错了"。** AI 只能猜，来回三次还不如一次贴全。
- **错误四：自己猜着改代码。** 你不是来改代码的，让 Agent 改。
- **错误五：把报错当"我不行"的证据。** 报错是程序的常规反馈，人人都会遇到。

## 本节练习

5 分钟，不用等报错也能做。把下面这段模板存到备忘录：

> 复制后把【】里的内容换成你的。

```text
下面是完整的报错原文（含文件名和行号）：
【整段粘贴报错】

我是纯小白。请用大白话告诉我：
1）哪一步出的问题；
2）为什么会这样；
3）下一步我该做什么，一次只说一个动作。
```

以后任何报错，直接套这个模板。
