# 15.04｜什么时候值得认真学编程：三个判断问题

## 本节目标

用三个问题，判断自己到底该不该花时间学编程。

## 一句话结论

> 编程是"想深入时才走"的岔路，不是主线必过的收费站。

## 展开讲

"要不要学编程"这个问题，答案取决于你的目标，不取决于你聪不聪明。

先看这张表，对号入座。

| 你的情况 | 建议 | 为什么 |
|-|-|-|
| 想做复杂、长期维护的产品 | 值得学 | 光靠指挥，改不动深层问题 |
| 想转开发岗 | 值得学 | 这是硬门槛，绕不过 |
| 不想永远依赖工具 | 值得学 | 自己会读会改，更自由 |
| 单纯好奇，想搞清原理 | 可以学 | 但慢慢来，别当成任务 |
| 只想用 AI 提效 | 不必学 | 把主线练熟，收益更大 |

### 什么时候不必学

如果你的目标只是用 AI 提效，那就别逼自己学编程。

具体包括这几件事：

- 整理文档、做表格、出周报。
- 做个小助手自己用。
- 把重复的活儿交给 Agent。

这些事，把主线第 03、05、06 章练熟，收益比硬啃一门编程课大得多。

> 一句话：**先把能立刻见效的事做完，再考虑啃硬骨头。**

### 三个判断问题

不确定的时候，问自己这三句。

| 问题 | 答"是"说明 | 答"否"说明 |
|-|-|-|
| 我要做的东西，要长期改、长期维护吗 | 该学 | 先不用学 |
| 我需要它给我带来收入或工作机会吗 | 该学 | 先不用学 |
| 我卡住时，是"没人能做"还是"我不会指挥" | 前者该学 | 后者先练主线 |

第三句最容易被忽略。

很多人以为卡住是因为不会编程，其实只是任务书没写清。

### 成本账要算清楚

学编程不是免费的，成本是时间。

| 投入 | 大致需要 | 回报 |
|-|-|-|
| 看懂报错、能问对问题 | 几周 | 立刻能用，收益最快 |
| 能读别人的项目 | 1–2 个月 | 能自己判断好坏 |
| 能独立写小工具 | 3–6 个月 | 不再依赖工具 |
| 能接开发工作 | 1 年以上 | 换赛道的门槛 |

**只有第一档是"几乎人人该做"的。**

后面几档，看你的目标，不看别人的进度。

### 不学编程，也能做的四件事

不学编程不等于原地不动。这四件事照样能提升你。

| 做法 | 效果 |
|-|-|
| 把常用任务写成任务书模板 | 每次少说十句话，结果更稳 |
| 建一个自己的模板库 | 经验能复用，不用重想 |
| 练验收：拿固定输入反复试 | 一眼看出结果有没有变差 |
| 练提问：把"不会"换成具体问题 | 求助效率翻倍 |

### 小橙的选择

小橙问过自己那三个问题。

她要做的是自己的学习助手，不打算转开发，也不靠它赚钱。

所以她的结论是：**先不学编程。**

她的做法是：想改功能就说清要求，让 Agent 改；改完自己跑两个样例验收。

三个月后，她的助手比很多"会写代码的人"做的还贴合自己需求。

## 照着做

花 5 分钟，给自己一个明确结论。

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 写下你最近想做的那个东西 | 一句话 | 想不出来，就写"用 AI 提效" |
| 2 | 答第一个问题：要不要长期维护 | 是 / 否 | 答不上，就按"否"处理 |
| 3 | 答第二个问题：要不要带来收入 | 是 / 否 | 说不清，就先按"否" |
| 4 | 答第三个问题：卡在哪 | 一句原因 | 写成"我不会指挥"，就先练主线 |
| 5 | 三个都答完，写一句结论 | "我现在学 / 不学" | 结论含糊，就按"先不学" |
| 6 | 把结论写进任务台账 | 一行记录 | 三个月后回看，看要不要改 |

结论不是永久的。三个月后目标变了，答案可以变。

## 常见错误

- **错误一：因为别人在学，所以自己也学。** 你的目标和别人的不一样。
- **错误二：把"不会编程"当成卡住的唯一原因。** 八成的卡住是任务没写清。
- **错误三：决定学，就从最难的地方开始。** 先看懂报错，别一上来啃语法。
- **错误四：决定不学，就什么都不做。** 不学编程，也要练任务书和验收。
- **错误五：反复纠结不落笔。** 写一句结论，比想一个月有用。
- **错误六：把学习当逃避。** 用"我在学编程"躲开真正该交付的东西。

## 本节练习

3 分钟，手机就能做。写下三行，得出你的结论：

> 复制后把【】里的内容换成你的。

```text
我要做的东西：【一句话】
要不要长期维护：【是/否】　要不要带来收入：【是/否】
卡住的原因通常是：【我不会指挥 / 真的需要写代码】
结论：我现在【学 / 先不学】编程，因为【一句话理由】。
```

把结论存进你的任务台账。下次纠结时，直接看这一行。
