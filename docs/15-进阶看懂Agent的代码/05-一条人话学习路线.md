# 15.05｜一条人话学习路线：真要学，按这个顺序

## 本节目标

拿到一条从零开始、不用背语法的学习顺序。

## 一句话结论

> 先看附录有个整体印象，再跟一门动手课，最后用自己的 Agent 任务当练习。

## 展开讲

原章给的路线只有三步，这里把它拆开讲细。

| 顺序 | 做什么 | 目的 |
|-|-|-|
| 第一步 | 读附录《真正的工程进阶》 | 先有整体印象，不慌 |
| 第二步 | 跟一门带小例子的入门课 | 建立手感 |
| 第三步 | 用自己的 Agent 任务当练习 | 真用得上 |

**顺序不能换。** 先建立印象，再练手感，最后上真事。

### 第一步：先把名词认全

本仓库的附录《真正的工程进阶》把几样东西浓缩成了入门版。

它讲的是：Python 最低基础、命令行、Git、API、JSON。

先认这几个词的人话意思：

| 名词 | 一句话解释 |
|-|-|
| Python | 一门常用的编程语言，Agent 写的代码多半是它 |
| 命令行 | 用打字代替点鼠标，让电脑执行命令 |
| Git | 记录文件每次改动的工具，像改稿历史 |
| API | 两个程序之间的接口，像取件窗口 |
| JSON | 一种固定格式的文本数据，像填好的表格 |

这一步不用练，只要读一遍，知道有这些词就行。

**花 1–2 小时，读完就好。**

### 第二步：挑一门"跟着做"的课

选课只有一个标准：**带小例子、要你动手。**

| 选这种 | 别选这种 |
|-|-|
| 每节都让你敲一遍小例子 | 只有视频，从头看到尾 |
| 讲完一个概念就配一个小练习 | 一口气讲二十个概念 |
| 出错时教你怎么查 | 只说"这个很简单" |
| 一节课 20–30 分钟 | 一节课 3 小时 |

判断方法很土但有效：**看完第一节，你能不能让电脑做出一件小事？** 不能就换。

### 第三步：用自己的 Agent 任务当练习

这是最快的学习法。

你不是从零造车，而是在修一辆会跑的车。

具体做法：

1. 让 Agent 写一小段代码，实现你想要的功能。
2. 你自己读一遍，看大意。
3. 改一行——比如把 200 改成 100。
4. 再跑一次，看结果怎么变。

**改一行，比读一百行有用。**

> 下面这段代码由 Agent 生成。你不需要会写，只需要看懂大意：它把摘要的字数上限设成 200，你把它改成 100，结果就会变短。

```python
# 由 Agent 生成（阅读样例，你不需要会写）
MAX_SUMMARY_WORDS = 200   # 摘要字数上限，试着改成 100
```

改完记得跑一次。看到结果变短，你就完成了一次真正的"改动 → 验证"。

### 时间怎么排

| 每周 | 做什么 | 判断进展 |
|-|-|-|
| 第 1 周 | 读附录，认全 5 个名词 | 能用人话解释这 5 个词 |
| 第 2–4 周 | 入门课，每周 3 次 × 30 分钟 | 能独立做出课里的小例子 |
| 第 5 周起 | 改 Agent 写的代码，一次改一行 | 改完能说出结果为什么变 |

一周三次、每次半小时，比周末突击四小时有效。

### 不要做的三件事

| 别做 | 为什么 |
|-|-|
| 从零背语法 | 你是为了看懂和改一行，不是考试 |
| 一次买十门课 | 看完一门再说 |
| 一上来啃大项目 | 会被劝退，先从最小示例开始 |

### 小橙的路线

小橙最终决定：先不系统学编程，但保留一条小路。

她每周花 30 分钟，做一件事：读一段 Agent 写的代码，改一个数字。

三个月后，她发现报错能自己看懂了，改需求也说得更准。

**她没变成程序员，但变成了更好的指挥者。**

## 照着做

想学的话，从今天这一步开始。

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 打开附录《真正的工程进阶》的导读 | 一份大纲 | 找不到，就先看本仓库目录 |
| 2 | 读完导读和"最小环境"那两节 | 5 个名词的人话解释 | 有词还不懂，问 AI"用一句话解释 X" |
| 3 | 挑一门带小例子的入门课 | 一门课 | 选不出来，就先只做第 4 步 |
| 4 | 让 Agent 给你一个 15 行以内的小例子 | 一段短代码 | 太长，就说"缩到 15 行以内" |
| 5 | 改其中一行（数字或文字） | 结果变化 | 没变化，就问"为什么改这行没效果" |
| 6 | 把这次改动记一行 | 一条学习记录 | 忘了记也行，下次连着记两条 |

第 5 步看到"结果变了"，就是今天最大的收获。

## 常见错误

- **错误一：先背语法再动手。** 顺序反了，容易两周放弃。
- **错误二：只看视频不动手。** 看会了不等于做得出。
- **错误三：一开始就啃大项目源码。** 从最小示例开始，跑通再读。
- **错误四：改十行再看结果。** 一次改一行，你才知道是哪行起作用。
- **错误五：把课看完再练。** 学到第三节就开始用，边学边用。
- **错误六：拿学习当交付。** 学是为了解决你手上的真事，不是攒课时。

## 本节练习

5 分钟，手机或电脑都行。让 Agent 当你的陪练：

> 复制后把【】里的内容换成你的。

```text
我在学编程入门，今天想练【一个知识点，比如"读写文件"】。
请给我一个 15 行以内的例子，每行后面加一句中文注释。
先不要解释原理，等我问了再解释。
```

拿到代码后，只做一件事：改一个数字或一句文字，看结果怎么变。
