# 15｜进阶看懂 Agent 的代码：走向真实工程

> 本章目标：让"看不懂代码"这件事不再让你慌。学会看结构、读报错、判断要不要学编程。
> 本章是**可选章**。你跳过它，主线照样通关。

## 本章开始前：准备与产出

| 项目 | 说明 |
|-|-|
| 账号要求 | 一个 Agent 工具（看它生成的代码）+ 一个 AI 聊天工具（让它翻译报错） |
| 能否只用手机完成 | 大部分可以。看项目文件结构时用电脑更顺 |
| 主线要不要写代码 | 不需要。本章只要求"看懂"，不要求你会写 |
| 预计用时 | 约 1 小时，建议分 3 次学完 |
| 本章产出 | 一段被 AI 翻译成人话的报错 + 一句"我要不要学编程"的结论 |

## 这一章适合谁

| 你的情况 | 这一章对你有用吗 |
|-|-|
| 好奇"Agent 到底改了哪些文件" | 有用，看 02、03 两节 |
| 一看代码就心慌，怀疑自己不适合 | 有用，先看 01 节 |
| 在纠结要不要花时间学编程 | 有用，看 04 节 |
| 想让 Agent 带你读别人的项目 | 有用，看 06 节 |
| 只想用 AI 提效，没别的打算 | 不看也完全不影响主线 |

## 这一章不承诺什么

| 不承诺 | 原因 |
|-|-|
| 学完你会写代码 | 这一章只讲"看懂"和"提问" |
| 学完你能改复杂项目 | 改项目要靠真的动手练 |
| 学完你能看懂任何代码 | 没有这种能力，程序员也不行 |

## 一句话放这里

> 这一章不教你写代码。它只教你三件事：不慌、会问、会判断。
