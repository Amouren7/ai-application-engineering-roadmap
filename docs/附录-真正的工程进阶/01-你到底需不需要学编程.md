# 附录.01｜你到底需不需要学编程

## 本节目标

用四类人对号入座，10 分钟内得出"我要不要学编程"的结论。

## 一句话结论

> 目标只是用 AI 干活，主线已经够了；想搞懂或想自己写，才需要学。

## 展开讲

先纠正一个误会：学编程不等于背语法。

它的目标是三级的，一级比一级难：

| 级别 | 你会什么 | 大概要多久 |
|-|-|-|
| 第一级：能看懂 | 看到一段代码，能说出它大概在干嘛 | 几天到两周 |
| 第二级：能改一行 | 改个名字、改个数字、改个地址，能跑通 | 一两个月 |
| 第三级：能写小东西 | 从零写出一个小脚本、一个小工具 | 三到六个月 |

本附录只负责把你送到**第一级**，顺手摸一下第二级的门。

### 四类人，对号入座

| 你的情况 | 建议 | 要不要进本附录 |
|-|-|-|
| 目标是用 AI 提效、交付任务 | 主线已够，编程非必需；偶尔让 Agent 解释代码即可 | 不用 |
| 好奇 Agent 改的是什么、怕被它糊弄 | 学"看懂"部分就够 | 只学 03、05 节 |
| 想自己写工具、做复杂产品、转开发 | 认真学：本附录 → Python 入门课 → 用真实任务练 | 全学 |
| 不确定 | 先学本附录前三节，学完再决定 | 学 01–03 节 |

### 三个问题，帮你不纠结

拿不准就回答下面三句，答完答案自己就出来了：

1. **我最近有没有被代码挡住过？** 有具体例子 → 该学一点。
2. **我愿不愿意花两周、每周两小时？** 不愿意 → 先别学。
3. **我学它是为了好奇，还是为了干活？** 只为了好奇 → 只看 03 节就够。

### 学编程能给你带来什么，不能带来什么

| 你以为 | 实际 |
|-|-|
| 学了就能自己做出完整产品 | 还得学工程、部署、运维，路很长 |
| 不学就会被淘汰 | 不学也能指挥 Agent 干活，这是本课主线 |
| 学了就能看懂所有代码 | 只能看懂你熟悉的那一类，陌生代码照样吃力 |
| 学了就不用 Agent 了 | 恰恰相反，会读代码的人用 Agent 更狠 |

### 什么时候"不该"学

- 你手上有急活要交付 → 先用主线把活干完。
- 你只是被"别人都在学"带着焦虑 → 这不是理由。
- 你连编辑器都没装过、也不想装 → 说明现在还不是时候。

### 什么时候"该"学

- 你反复遇到同一个技术卡点。
- 你想改 Agent 生成的东西，但不知道从哪下手。
- 你打算把 AI 应用做成能给别人用的产品。

> 想再细看这个判断，读主线的 [15.04｜什么时候值得认真学编程](../15-进阶看懂Agent的代码/04-什么时候值得认真学编程.md)。

> 记住这句：**判断标准不是"难不难"，是"有没有用得上"。**

## 照着做

用下面这张表，给自己走一遍判断流程：

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 在四类人表里找最像自己的一行 | 有一行看着像你 | 像两行就选"更保守"的那行 |
| 2 | 问自己"最近有没有被代码挡住" | 想得出具体例子，或想不出 | 想不出 = 暂时不用学 |
| 3 | 问自己"每周能不能挤出两小时" | 能 / 不能 | 不能 = 先留在主线 |
| 4 | 写下一句结论 | 如"我先只看 03 节" | 写不出来就写"暂时不学" |
| 5 | 把结论存进任务卡 | 一行字 | 没任务卡就直接记在手机备忘录 |

结论只有三种，选一种就行：**全学 / 只学看懂 / 暂时不学。** 三种都是正确答案。

## 常见错误

- **错误一：把"不学"当成落后。** 不学是合理选择，主线本来就为零基础设计。
- **错误二：一上来就买课。** 先看本附录前三节，花不到一小时，再决定要不要花钱。
- **错误三：拿"我数学不好"当理由。** 看懂代码用不到数学，用到的是耐心。
- **错误四：想一次学完一门语言。** 目标是"看懂一段"，不是"精通一门"。
- **错误五：以为学了编程就不需要 Agent。** 会用 Agent 加会读代码，才是最强的组合。

## 本节练习

3 分钟，手机就能做。在备忘录里写下三行：

> 复制后把【】里的内容换成你的。

> 下面这段代码由 Agent 生成。你不需要会写，只需要看懂大意：它是一张填空模板，填完就是你的结论。

```text
我的目标：【用 AI 提效 / 好奇 / 想转开发 / 不确定】
我最近被代码挡住的一次是：【写一件真事，没有就写"没有"】
我的结论：【全学 / 只学看懂 / 暂时不学】
```

写不出第二行，就是"暂时不学"的明确信号，安心回主线。
