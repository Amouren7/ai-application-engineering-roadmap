# 附录.03｜最小Python六个概念

## 本节目标

认住六个词，看到一段 Python 代码能说出它大概在干嘛。

## 一句话结论

> AI 应用的代码翻来覆去就这六样：变量、列表、字典、函数、循环、条件。

## 展开讲

你现在不需要会写。先做到一件事：**看到六行示例，能说出"这行大概在干嘛"。**

这就是"读懂"。

### 六个概念，一张表

| 概念 | 人话 | 长什么样 |
|-|-|-|
| 变量 | 贴了名字的盒子，存东西 | `name = "小橙"` |
| 列表 | 按顺序排好的盒子串 | `tasks = ["写周报", "开会"]` |
| 字典 | 贴标签的抽屉，按标签取 | `doc = {"title": "笔记", "text": "……"}` |
| 函数 | 可重复使用的小机器 | `def summarize(text): ...` |
| 循环 | 对一串东西逐个做同一件事 | `for t in tasks: print(t)` |
| 条件 | 如果……就…… | `if not text: print("文件为空")` |

### 一个一个说清楚

**变量**：给它起个名字，把东西放进去，以后用名字就能取出来。

| 你写的 | 意思 |
|-|-|
| `name = "小橙"` | 造一个盒子叫 name，里面放"小橙" |
| `count = 3` | 造一个盒子叫 count，里面放数字 3 |

**列表**：一串按顺序排好的东西，第 1 个、第 2 个这样数。

| 你写的 | 意思 |
|-|-|
| `tasks = ["写周报", "开会"]` | 一个叫 tasks 的列表，里面有两件事 |
| `tasks[0]` | 取出第一件事（从 0 开始数） |

**字典**：不是按顺序取，是按标签取。标签叫"键"，内容叫"值"。

| 你写的 | 意思 |
|-|-|
| `doc = {"title": "笔记"}` | 一个抽屉，标签是 title，里面是"笔记" |
| `doc["title"]` | 按标签 title 取出"笔记" |

**函数**：把一段动作打包成一台小机器，给它原料，它给你结果。

| 你写的 | 意思 |
|-|-|
| `def summarize(text):` | 造一台机器叫 summarize，原料是 text |
| `summarize("……")` | 把一段文字喂进机器 |

**循环**：一件事要对一串东西做很多遍，就用它。

| 你写的 | 意思 |
|-|-|
| `for t in tasks:` | 对 tasks 里的每个东西，挨个做下面的事 |
| `print(t)` | 把当前这个打印出来 |

**条件**：满足条件才做，不满足就跳过。

| 你写的 | 意思 |
|-|-|
| `if not text:` | 如果 text 是空的 |
| `print("文件为空")` | 就打印"文件为空" |

### 为什么要先学"读"而不是"写"

| 先学写 | 先学读 |
|-|-|
| 要背语法、要练手速 | 只要认得出这六样 |
| 卡住就没法往下 | 卡住还能看懂大意 |
| 一个月才有成就感 | 十分钟就有 |

### 六个概念怎么拼起来

真实代码里，这六样是**叠在一起**用的：函数里有变量，循环里有条件，列表里装字典。

看下面这段，六样全齐。

> 下面这段代码由 Agent 生成。你不需要会写，只需要看懂大意：它打开一个文件、统计字数并打印结果。

```python
# 下面这段代码由 Agent 生成。你只需要看懂大意：
# 它打开一个文件、统计字数并打印结果。
from pathlib import Path            # 引入"文件路径"工具

path = Path("notes.txt")            # 指向 notes.txt 这个文件
text = path.read_text(encoding="utf-8")  # 读出全部文字
print("字符数：", len(text))        # 打印字符数
```

逐行对照，其实只有三样：

| 这一行 | 用了哪个概念 |
|-|-|
| `path = Path("notes.txt")` | 变量（盒子叫 path） |
| `text = path.read_text(...)` | 变量 + 函数（调用一台机器） |
| `print("字符数：", len(text))` | 函数（打印）+ 函数（数字数） |

`len` 是"数一数有多长"的机器，`print` 是"打印出来"的机器。

> 看懂这段，你就已经能读懂大部分 AI 生成的短脚本了。

## 常见错误

- **错误一：想背下来。** 这六样不用背，用几次自然记住。现在只求认得。
- **错误二：纠结语法细节。** 冒号、缩进、括号先不管，看大意。
- **错误三：列表从 1 开始数。** 代码里多数从 0 开始，`tasks[0]` 是第一件。
- **错误四：把字典当成列表。** 列表按顺序取，字典按标签取，这是最大区别。
- **错误五：看到函数就慌。** 函数只是"打包好的一段动作"，当它是一台机器就好。
- **错误六：以为看不懂是自己笨。** 第一次看都这样，多认几遍就顺了。

```python

doc = {"title": "笔记", "text": "……"}   # 字典

```
