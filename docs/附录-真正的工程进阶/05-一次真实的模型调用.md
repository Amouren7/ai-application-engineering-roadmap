# 附录.05｜一次真实的模型调用（阅读样例）

## 本节目标

读完一段真实的调用代码，能说出它的数据流：连上 → 发问 → 拿答案。

## 一句话结论

> 模型调用只有三步：创建连接、发请求、拿结果。看懂的标志是能指出这三步在哪。

## 展开讲

本节是**阅读样例**，不是要你写。你只需要跟着注释读一遍。

不同厂商的 SDK 写法略有差异，以你实际使用的官方文档为准。

### 先看全景

| 第几步 | 干什么 | 对应代码里的哪一行 |
|-|-|-|
| 1 | 创建连接（带着门禁卡） | `client = OpenAI(...)` |
| 2 | 发请求（模型名 + 要问的话） | `client.responses.create(...)` |
| 3 | 拿结果（把答案打印出来） | `print(response.output_text)` |

记住这三步，任何厂商的代码都能对上号。

### 完整代码，逐行读

> 下面这段代码由 Agent 生成。你不需要会写，只需要看懂大意：它连上模型服务，问一句话，把回答打印出来。

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["OPENAI_API_KEY"])  # 从环境变量读密钥

response = client.responses.create(
    model="your-model",                    # 换成实际模型名
    input="用三句话解释什么是 Agent。",
)

print(response.output_text)                # 打印模型回答
```

逐行翻译成人话：

| 这一行 | 人话 |
|-|-|
| `import os` | 拿来一个系统工具，用来读环境变量 |
| `from openai import OpenAI` | 拿来别人写好的"连接器" |
| `client = OpenAI(...)` | 用你的门禁卡，创建一个连接 |
| `os.environ["OPENAI_API_KEY"]` | 从环境变量里取出密钥 |
| `client.responses.create(...)` | 发出请求 |
| `model="your-model"` | 告诉它用哪个模型 |
| `input="……"` | 告诉它要问什么 |
| `response` | 装着回答的盒子 |
| `print(response.output_text)` | 把回答打印出来 |

### 你实际要做的事只有两件

| 要改的地方 | 改成什么 |
|-|-|
| `model="your-model"` | 服务商文档里给的模型名 |
| `input="……"` | 你想问的那句话 |

其余都不用动。这就是"能改一行"的第一课。

### 一次调用之后会发生什么

| 步骤 | 结果 |
|-|-|
| 代码跑通 | 屏幕上出现模型的三句话回答 |
| 密钥没设 | 报错说找不到密钥 |
| 模型名写错 | 报错说模型不存在 |
| 余额或额度不够 | 报错说额度不足 |

### 报错了怎么办

这是本附录最重要的一条操作习惯：

> 把**完整报错**复制给 AI，让它解释。

不要说"跑不起来"，要说"我运行这段代码，报了下面这个错，请解释并给出修改方案"，然后贴上完整报错。

| 你给的 | AI 能帮你吗 |
|-|-|
| "报错了，怎么办" | 基本帮不上 |
| 完整报错 + 你改过的行 | 大多能直接定位 |

你已经会"驾驶"，现在只是把驾驶对象换成了代码。

## 照着做

下面这张表，选择"只读"也能走完；想真跑一遍就按右列准备。

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 读一遍代码，指出三步分别在哪行 | 你能指出来 | 指不出就看上面的对照表 |
| 2 | 找出"要改的两处" | model 和 input 两行 | 找不到就问 AI"这段里哪行是模型名" |
| 3 | （可选动手）把密钥设成环境变量 | 环境变量里有 `OPENAI_API_KEY` | 不会设就让 AI 给 Windows 设置步骤 |
| 4 | （可选动手）跑一次 | 屏幕上出现三句话回答 | 报错就把完整报错复制给 AI |
| 5 | （可选动手）把 input 换成你自己的问题 | 回答跟着变 | 没变化说明改错了地方 |
| 6 | 关掉代码，用自己的话复述数据流 | 一句话能说清 | 说不清就再读一遍第 1 步 |

只想"看懂"的人，做完第 1、2、6 步就够了。

## 常见错误

- **错误一：把密钥直接写进代码。** `api_key="sk-……"` 写死在文件里是红线，必须走环境变量。
- **错误二：忘了换模型名。** 留着 `your-model` 一定报错，去文档抄真实模型名。
- **错误三：以为要背下这段代码。** 它是样例，抄改即可，不用记。
- **错误四：报错只说"跑不起来"。** 必须给完整报错，否则 AI 只能瞎猜。
- **错误五：跑一次就以为学会了。** 换个 input 再跑一次，才算真验证。
- **错误六：拿模型回答当事实。** 三句话解释也可能是编的，关键结论自己核一遍。
