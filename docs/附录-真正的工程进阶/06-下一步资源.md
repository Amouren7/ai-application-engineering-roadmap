# 附录.06｜下一步资源

## 本节目标

看懂之后，知道想继续走该往哪走，不用再到处找。

## 一句话结论

> 三条路：继续让 Agent 写代码你来读、上一门 Python 入门课、走飞书工程版原路线。

## 展开讲

资源很多，但你现在只需要三条，按顺序用。

### 三条路，一张表

| 路线 | 适合谁 | 怎么用 | 大概多久 |
|-|-|-|-|
| 1. 用起来 | 所有人，尤其"只想看懂"的人 | 让 Agent 写代码，你负责读 + 改一行 + 跑通 | 一直做 |
| 2. 学语法 | 决定认真学的人 | 选一门 Python 入门课，学完基础语法就回来 | 4–8 周 |
| 3. 走工程路线 | 想转开发的人 | 参考飞书工程版原路线（各章顶部有对照链接） | 半年以上 |

**路线 1 是主线，路线 2、3 是分支。** 先做 1，别急着跳。

> 想把顺序排得更细，看主线的 [15.05｜一条人话学习路线](../15-进阶看懂Agent的代码/05-一条人话学习路线.md)。

### 路线 1 怎么做：把第 15 章的方法用起来

| 你做什么 | 具体动作 |
|-|-|
| 让 Agent 写 | 用主线学的任务书方法，让它写一个小脚本 |
| 你负责读 | 用 03 节的六个概念，指出每行在干嘛 |
| 你负责改一行 | 改名字、改数字、改文件路径 |
| 你负责跑通 | 跑一次，报错就把完整报错给 AI |

循环做十次，比看十小时视频有用。

### 路线 2 怎么选课

任何口碑好的 Python 入门课都行。挑选只看三条：

| 看什么 | 合格的样子 |
|-|-|
| 有没有让你动手 | 每节都有小练习 |
| 讲不讲"为什么" | 不只说"这样写"，还说"为什么这样" |
| 学完能做什么 | 明确给出一个小成品 |

学完基础语法就回来，不用学完整个课程体系。

### 路线 3 什么时候走

只有这三种情况值得考虑：

1. 你已经在用路线 1，并且经常需要自己动手。
2. 你打算把应用做成能给别人用的产品。
3. 你明确想转开发岗位。

不符合这三条，就先不碰。

### 学编程的时间预算

| 目标 | 每周投入 | 大概多久见效 |
|-|-|-|
| 看懂代码 | 2 小时 | 2 周 |
| 能改一行 | 3 小时 | 1–2 个月 |
| 能写小工具 | 5 小时以上 | 3–6 个月 |

看不完的课、收藏夹里没打开的链接，都不算投入。

### 一个反直觉的建议

| 常见做法 | 更好的做法 |
|-|-|
| 先看完一门课再动手 | 边做边学，卡住再查 |
| 收集一堆资料 | 只用一条路线，走完再换 |
| 追求"学全" | 够用就停，回去干活 |

> 记住：**学编程是为了让你更能指挥 Agent，不是为了变成全职程序员。**

## 照着做

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 先选一条路线，只选一条 | 你写下"路线 1"或"路线 2" | 犹豫就选路线 1 |
| 2 | 路线 1：让 Agent 写个 10 行小脚本 | 一段代码 | 不会下任务书就回主线 03 章 |
| 3 | 用六概念标出每行在干嘛 | 标出三到五行 | 标不出就问 AI"这行是什么" |
| 4 | 改一处，再跑一次 | 结果跟着变 | 报错就把完整报错给 AI |
| 5 | 路线 2：只挑一门课，加进日程 | 日程上有一个固定时间 | 挑不出来就先走路线 1 |
| 6 | 把三条路线写进任务卡 | 三行字 | 没任务卡就记在备忘录 |

## 常见错误

- **错误一：三条路线同时开。** 精力分散，哪条都走不完。一次只走一条。
- **错误二：收藏代替学习。** 存了 50 个链接不等于学会，选一个开始做。
- **错误三：非要学完整个课程体系。** 学完基础语法就回来练，缺什么再补。
- **错误四：以为路线 1 太简单不值钱。** 它是回报最高的一条，别跳过。
- **错误五：学编程后就不再指挥 Agent。** 会读代码的人用 Agent 效率更高。
- **错误六：卡住就换方向。** 卡住先问 AI，再决定换不换。
