# 附录.04｜程序怎么开口说话：API 与 JSON（概念版）

## 本节目标

搞懂程序怎么向云端模型提问，以及模型怎么把结果送回来。

## 一句话结论

> 程序调 AI 和你打字提问本质一样，只是把"手动发送"换成了"自动发送"。

## 展开讲

当你让程序调用云端 AI（比如给模型发一段文字要摘要），双方通过 HTTP 接口通信。

HTTP 你不用学，只要知道：**它是互联网上"一问一答"的规矩。**

### 三个词，先认清

| 词 | 人话解释 | 类比 |
|-|-|-|
| API | 程序与云端服务之间"约定好的服务窗口" | 餐厅点餐窗口，按菜单点、按菜单上 |
| JSON | 一种结构化文本，机器能读的"表单" | 填好的点菜单 |
| 密钥（API Key） | 你的"门禁卡"，证明你有权限调用 | 会员卡 |

第一次听这三个词会有点虚，往下看一遍就好。

### API 到底是什么

它就是**一份约定**：你按什么格式发，它按什么格式回。

| 你要做对的事 | 结果 |
|-|-|
| 发的东西格式对 | 它正常回结果 |
| 发的东西格式错 | 它回一个错误，不会瞎猜 |
| 门禁卡不对 | 它直接拒绝 |

这就是为什么"格式"这么重要——API 不像人，不会猜你的意思。

### JSON 长什么样

JSON 是一种文本，用花括号和大括号把东西装起来。

> 下面这段代码由 Agent 生成。你不需要会写，只需要看懂大意：它是一段 JSON，记着模型名和一句话。

```json
{
  "model": "your-model",
  "input": "用三句话解释什么是 Agent。"
}
```

读法很简单：**左边是标签，右边是内容，中间用冒号。**

| JSON 里的写法 | 意思 |
|-|-|
| `{ }` | 一整个抽屉 |
| `"model": "your-model"` | 标签叫 model，内容是 your-model |
| `[ ]` | 一串东西，按顺序排 |
| `,` | 两个东西之间的逗号 |

### 模型回什么

模型回给你的也常常是文本或 JSON。程序拿到之后要做三件事：

1. **校验**：是不是我想要的形状。
2. **保存**：存到文件或数据库。
3. **展示**：给你看，或者给下一个程序用。

### 一次对话的完整走法

> 下面这段由 Agent 生成。你不需要会写，只需要看懂大意：数据从你的程序出发，去云端绕一圈再回来。

```text
你的程序
  ↓ 发送模型名、任务、文字、输出要求
云端模型服务
  ↓ 返回文本或结构化结果
你的程序（校验、保存、展示）
```

| 位置 | 谁在干活 | 你关心什么 |
|-|-|-|
| 第一行 | 你的程序 | 发的东西写对没 |
| 中间 | 云端模型服务 | 模型名、费用、速度 |
| 最后一行 | 你的程序 | 结果有没有用 |

### 密钥的铁律

这是本附录唯一一条"绝不允许出错"的规矩：

| 做法 | 可以吗 |
|-|-|
| 放在环境变量里，程序去读 | ✅ 唯一正确做法 |
| 直接写进代码文件 | ❌ 会随代码一起泄露 |
| 截图发群里 | ❌ 截图也能被读出来 |
| 提交到公开仓库 | ❌ 会被自动扫描盗用 |

> 环境变量是什么？一句话：**存在系统里的一张小纸条，程序能读，代码里看不到。**

一旦密钥泄露，别人可以拿它花你的钱。发现泄露就立刻去服务商后台作废重发。

## 照着做

不用真调 API，先用眼看懂这一套：

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 打开你用的模型服务商文档，找"API Key"页面 | 一串以字母数字开头的长字符串 | 找不到就搜"获取 API Key" |
| 2 | 看它给的第一个示例请求 | 一段 JSON 或一行命令 | 看不懂先看它的字段名 |
| 3 | 找出这段里的"模型名"和"输入文字" | 两个字段 | 找不到就问 AI"哪个是模型名" |
| 4 | 看它给的示例返回 | 一段 JSON | 认出里面哪部分是答案 |
| 5 | 把 API Key 存进环境变量，不写进任何文件 | 一个环境变量名 | 不会设就问 AI"Windows 怎么设环境变量" |

第 5 步只做一次，以后所有代码都靠它。

## 常见错误

- **错误一：把密钥写进代码。** 这是最常见也最危险的一条，改法只有一个：放进环境变量。
- **错误二：以为 API 会猜你的意思。** 它只认格式，格式不对就报错。
- **错误三：把 JSON 当成编程语言。** 它只是"数据的写法"，不是要执行的东西。
- **错误四：忘了看费用。** 每次调用都可能花钱，先看清计价方式和额度。
- **错误五：把返回结果当最终稿。** 模型可能编，重要结论要人工复核。
- **错误六：拿到报错就放弃。** 把完整报错复制给 AI，让它解释，八成能解决。
