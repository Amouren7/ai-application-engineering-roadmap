## 三条底线，先说清楚

1. **不背语法。** 本附录没有一句"请你默写"。
2. **不求会写，只求看懂。** 看懂是目标，写出来是副产品。
3. **卡住就退回主线。** 卡住不是失败，是这条路暂时不适合你。

## 术语先说一遍

本附录会出现几个新词。这里各给一句人话：

| 词 | 一句话解释 |
|-|-|
| 代码 | 写给电脑看的一串指令，电脑照着做 |
| 环境 | 电脑上"能跑代码"的那套东西：语言、工具、编辑器 |
| 命令 | 你敲给电脑的一行字，让它立刻做一件事 |
| API | 程序之间约定好的服务窗口，按格式问、按格式答 |
| JSON | 一种机器好读的结构化文本，像能读的表单 |
| 密钥 | 你的门禁卡，证明你有权限调用别人的服务 |

第一次看不懂没关系，往下走会各讲一节。
