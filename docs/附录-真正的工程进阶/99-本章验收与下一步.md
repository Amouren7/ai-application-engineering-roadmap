# 附录｜本章验收与下一步

## 常见误区（本附录汇总）

- **误区一：以为附录是必修。** 主线不需要它。跳过这个附录，你照样能交付主线作业。
- **误区二：以为学编程要背语法。** 目标是"看懂"，不是"默写"。看得懂就能改一行。
- **误区三：以为不装环境也能学。** 看代码可以，跑代码不行。四条命令确认一下就够。
- **误区四：把密钥写进代码。** 本附录唯一红线。只放环境变量。
- **误区五：报错只说"跑不起来"。** 必须给完整报错，AI 才能帮你定位。
- **误区六：三条学习路线一起开。** 一次只走一条，走完再换。
- **误区七：以为学了编程就不需要 Agent。** 会读代码的人用 Agent 更狠。

> 下面这段代码由 Agent 生成。你不需要会写，只需要看懂大意：它连上模型服务，问一句话，把回答打印出来。

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["OPENAI_API_KEY"])  # 从环境变量读密钥

response = client.responses.create(
    model="your-model",                    # 换成实际模型名
    input="用三句话解释什么是 Agent。",
)

print(response.output_text)                # 打印模型回答
```

跑之前确认两件事：环境变量里已设好密钥；`model` 已换成文档里的真实模型名。

跑不通就把完整报错复制给 AI，让它解释。
