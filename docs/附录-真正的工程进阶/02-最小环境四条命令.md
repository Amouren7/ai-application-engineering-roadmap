# 附录.02｜最小环境四条命令

## 本节目标

在电脑上敲四条命令，确认 Python、编辑器、Git 都到位。

## 一句话结论

> 只确认四样东西在不在：Python、一个编辑器、Git、命令行窗口。

## 展开讲

"环境"这个词听着吓人，其实就一句话：**你的电脑上，有没有能跑代码的那套东西。**

本附录只要四样，多一样都不要。

| 第几条 | 是什么 | 人话解释 | 检查它的命令 |
|-|-|-|-|
| 1 | Python | 让电脑按你写的步骤执行的语言 | `python --version` |
| 2 | 编辑器 | 用来看和改代码的软件，如 VS Code、Cursor | 在窗口里敲 `code .` |
| 3 | Git | 给项目留存档点，改坏了能退回 | `git --version` |
| 4 | 命令行窗口 | 你敲命令的地方，Windows 上叫 PowerShell | 敲 `python` 能进交互模式 |

### 第 4 条到底是什么

严格说"命令行窗口"不是一个软件，是**你和电脑说话的一种方式**。

- 平时你点鼠标，那是图形界面。
- 敲命令是另一种方式：打一行字，电脑立刻做一件事。

Windows 上打开它的办法：按 Win 键，输入 `powershell`，回车。

### 为什么只要四条

工程环境可以装几十样东西。本附录只要你确认这四样，因为：

| 东西 | 不装会怎样 |
|-|-|
| Python | 05 节的样例代码没法跑 |
| 编辑器 | 代码只能看，改不了 |
| Git | 改坏了没法退回，心里没底 |
| 命令行 | 装不了、也跑不了任何东西 |

### 怎么知道"装好了"

命令执行后会打印一行版本号。**看到版本号就是成功**，看到"不是内部或外部命令"就是没装好。

| 你敲的 | 成功长什么样 | 失败长什么样 |
|-|-|-|
| `python --version` | `Python 3.12.4` | 不是内部或外部命令 |
| `git --version` | `git version 2.45.1` | 不是内部或外部命令 |
| `code .` | 编辑器打开当前文件夹 | 报错或没反应 |

版本号具体是几不重要，能显示就行。

### 装 Python 的一个坑

去 python.org 下载安装包，安装界面底部有个勾选框：**Add Python to PATH**。

| 你做了 | 结果 |
|-|-|
| 勾了 Add Python to PATH | 命令能直接用 |
| 没勾 | 命令提示"不是内部或外部命令" |

忘勾了不用慌，重新装一次、这次勾上就行。

> PATH 是什么？一句话：它是电脑找命令时翻的那张"通讯录"，没登记就找不到。

## 照着做

按顺序敲下面四条，一条一条来：

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 按 Win 键，输入 `powershell`，回车 | 一个黑色或蓝色的窗口 | 找不到就在开始菜单搜"PowerShell" |
| 2 | 敲 `python --version` 回车 | 一行版本号 | 提示"不是内部或外部命令"→ 去 python.org 重装并勾 PATH |
| 3 | 敲 `git --version` 回车 | 一行版本号 | 提示找不到 → 去 git-scm.com 下载安装 |
| 4 | 敲 `code .` 回车 | 编辑器打开当前文件夹 | 没反应 → 去 code.visualstudio.com 装 VS Code，或改用 Cursor |
| 5 | 敲 `python` 回车，看到 `>>>` 后敲 `exit()` | 进交互模式，再退出 | 进不去说明 Python 没装好，回第 2 步 |

四条全绿就结束，不用再装别的东西。

## 常见错误

- **错误一：装 Python 时没勾 PATH。** 症状是命令找不到。重装一次，勾上即可。
- **错误二：把命令敲进了编辑器。** 命令要敲在 PowerShell 窗口里，不是敲在代码文件里。
- **错误三：用了中文输入法敲命令。** 会出现奇怪的字符。敲命令前切回英文。
- **错误四：以为要装一堆工具才敢开始。** 本附录只要这四样，装完就够。
- **错误五：命令报错就重装系统。** 先复制完整报错给 AI，让它解释，九成是小问题。
- **错误六：在错误的文件夹里敲 `code .`。** `code .` 里的点代表"当前文件夹"，先确认位置。
