# 13｜学习进度与打卡`n`n> ✅ **提示**`n> 打卡不是记录“看了多久”，而是记录“产出了什么证据、遇到了什么失败、下一步如何验证”。能力出口比完成日期重要。

# 学习者档案

| 字段 | 填写 |
|-|-|
| 专业 / 行业 | 你的背景和可使用的真实场景 |
| 当前阶段 | L0–L8；附最近一次可验证证据 |
| 目标岗位 | AI Application、Agent、Automation、Solutions、FDE 或其他 |
| 项目方向 | 科研、销售、客服、采购、运营、数据分析等 |
| 时间预算 | 每天和每周可投入时间 |
| 当前阻塞 | 一句话描述最影响进度的问题 |

# 复盘问题

- 我今天解决的是用户问题还是课程问题？
- 哪一个判断是我做的，哪一段实现是 AI 帮助的？
- 如果明天系统坏了，我能从哪里开始定位？
- 我是否新增了可复现测试，而不是只记住一个答案？
