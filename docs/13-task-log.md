# 13｜任务台账：记录、复盘与进步

> 本章给你一套"记账"方法：每做完一个任务记一笔，每周每月回看一次。记录不是为了交差，是为了让你看见自己真的在进步。

## 本章开始前：准备与产出

| 项目 | 说明 |
|-|-|
| 账号要求 | 不需要 |
| 能否只用手机完成 | 可以；用备忘录、飞书文档或纸笔都行 |

## 任务卡模板（全课通用，复制走）

```text
日期：
任务名称：

【任务书四要素】
目标（我要什么结果）：
资料（我给 AI 什么）：
边界（不许 AI 做什么）：
验收（什么算完成）：

【过程】AI 做了什么、我改了什么：
【结果】做成了吗、差在哪：
【经验】下次照做 / 下次别犯：
```

不用一次填满。先填前四行，跑完任务再补后面的。

## 一份"好"记录 vs 一份"敷衍"记录

先看"敷衍"版：

```text
日期：3月12日
任务名称：整理会议记录
过程：让 AI 弄了
结果：还行
经验：无
```

它的问题：没有目标和验收，所以"还行"到底是真好还是蒙混，说不清；没有过程，卡住时无从回看；没有经验，下次还犯同一个错。

再看"好"版：

```text
日期：2026-03-12
任务名称：把会议记录整理成待办清单
目标：得到 8 条以内、每条含"谁做+什么时候+做什么"的待办
资料：给了 3 页会议记录原文
边界：不许编造会议里没提过的人名和日期
验收：每条都能对着原文找到出处，没有多出来的事
过程：AI 先给了 12 条，我让它合并重复的、删掉无关的，改到 8 条
结果：8 条全部有原文依据，通过
经验：资料里没写的，AI 真的会自己编；下次先让它在每条后面标"出自原文第几段"
```

差在哪？三句话：**目标可验收，卡住能回看，下次不再犯。**

## 周复盘模板

```text
本周做了哪几个任务：
哪个最顺，为什么：
哪个卡住，最后怎么出来的：
一个"差点踩坑"的地方：
下周唯一最重要的一个任务：
```

## 月复盘模板

```text
这个月做成了哪些能给别人看的东西：
比起上个月，哪件事明显更快了：
哪个老毛病还在反复出现：
下个月想固化下来的一个模板或流程：
```

## 你在进步的四个信号

不用靠感觉打分，看这四条有没有一条条出现：

1. **能独立拆任务**：拿到一件模糊的事，你自己就能拆成几步，不再只会说"帮我搞定"。
2. **卡住能自己救**：出了错先自己描述现象、补材料、要求分步，而不是干等。
3. **验收越来越快**：看一眼结果就知道该查哪几点，返工次数变少。
4. **开始复用旧模板**：新任务不再从零写，而是翻出上次的任务书改一改。

出现任意两条，你就已经比第一天的自己强多了。

## 与 14 章模板库的分工

一句话分清：**14 章给你"开工模板"（开工前怎么把任务说清楚），13 章给你"记账模板"（干完后怎么记录和复盘）。** 开工用 14，收工回 13。

## 常见误区

- **误区一：只记"做了什么"，不记"结果对不对"。** 没有验收的记录，等于没记。
- **误区二：一次填太多，坚持不下去。** 先只填四要素，其他跑完再补，别让记账变成负担。
- **误区三：只看完成了多少章。** 章节能看完，能力不一定涨；记录里的"经验"才是你真正攒下的东西。
