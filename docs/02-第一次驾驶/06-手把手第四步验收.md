# 02.06｜手把手第四步：验收

> 现在你在第 4 步：它说做完了，你要自己量一遍。

## 本节目标

用四要素当尺子，逐条核对它的产出。

## 一句话结论

> 它说"已完成"不等于完成了。验收这一步，只有你能做。

## 展开讲

任务书是你写的，验收标准也在里面。

所以验收不是"看着顺不顺眼"，是**拿着任务书逐条打钩**。

### 四要素逐条核对

| 要素 | 怎么核 | 不合格的样子 |
|-|-|-|
| 要什么结果 | 形态对不对、长度对不对、给谁看对不对 | 要表格给了段落；要 100 字给了 800 字 |
| 给什么材料 | 它说的内容，原文里能不能找到 | 出现原文没有的人名、数字、结论 |
| 边界 | 有没有越界、有没有编造 | 擅自改了文件名；编了负责人姓名 |
| 什么算完成 | 任务书里那条标准，逐项打钩 | 说"3 个概念"，只给了 2 个 |

四条里有任意一条不合格，就进下一节：让它改。

### 三条最快见效的检查

**第一条：数数。** 要求 3 条就数 3 条，要求 100 字就数一下。数字最好核。

**第二条：搜原文。** 它说"根据第 3 段"，你就去原文搜关键词。搜不到就是编的。

**第三条：读一遍能不能直接用。** 你是要复制到周报里，还是给自己复习？用不了就是不合格。

### 验收前 vs 验收后

| | 不验收就交付 | 验收后交付 |
|-|-|-|
| 事实 | 可能带着编造的数字发出去 | 每条依据都在原文找到 |
| 覆盖 | 少一条你到用的时候才发现 | 当场发现，当场补 |
| 格式 | 你还要自己整理半小时 | 直接复制就能用 |
| 责任 | 出错是你的 | 你提前拦住了 |

> 记住一句：**AI 负责产出，你负责判断。** 判断这一步外包不出去。

### 一个可以照抄的验收动作

拿到结果后，在纸上或备忘录里写四行：

```text
要什么结果：✅ / ❌ + 一句话
给什么材料：✅ / ❌ + 一句话
边界：✅ / ❌ + 一句话
什么算完成：✅ / ❌ + 一句话
```

四行里出现 ❌，就把它抄进下一节的修改要求里。

### 小橙的验收结果

小橙逐条核对了 AI 的输出：

| 要素 | 核对结果 |
|-|-|
| 要什么结果 | ❌ 要求 3 个概念，它给了 4 个 |
| 给什么材料 | ❌ 依据只写"第 3 段"，没给原句，原文也没搜到 |
| 边界 | ✅ 没有编造外部信息 |
| 什么算完成 | ❌ 概念数量不对，依据无法核对 |

她拿到 3 条 ❌。这就是下一节要发出去的修改要求。

### 别一次挑十个毛病

第一次验收，挑最要紧的 2–3 条就够了。

全挑出来会让它改乱。改完再验，一轮一轮来。

## 照着做

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 把任务书翻出来放在旁边 | 四要素清晰可见 | 没存任务书就凭记忆写一遍 |
| 2 | 核对"要什么结果" | 形态、长度、读者对不对 | 不对就记下来 |
| 3 | 核对"给什么材料" | 抽 1–2 条内容去原文搜 | 搜不到就是编造，重点记 |
| 4 | 核对"边界" | 有没有越界动作、有没有编 | 越界了先确认有没有造成损失 |
| 5 | 核对"什么算完成" | 逐项打钩 | 打不上钩的记下来 |
| 6 | 挑最要紧的 2–3 条写成清单 | 一份修改要求 | 超过 3 条就分两轮改 |

第 6 步的清单，直接带进下一节。

## 常见错误

- **错误一：看着差不多就交付。** "差不多"就是没验收。
- **错误二：只核对长度和格式，不核对事实。** 编造的内容才最伤人。
- **错误三：它说"已完成"就信。** 它说完成是它的判断，不是事实。
- **错误四：一次挑十个毛病让它改。** 它会改乱，你也没法判断改没改好。
- **错误五：验收完就把任务书扔了。** 存下来，下次同样的任务直接复用。
