# 02.09｜任务卡：从今天开始记账

## 本节目标

用一张任务卡，把这次驾驶完整记下来。

## 一句话结论

> 任务卡是这门课的账本。一个月后你会惊讶自己干了多少活。

## 展开讲

任务卡就是你每次干完活记的一笔账。

记什么？四件事：目标、过程、结果、疑问。

### 任务卡模板（复制到备忘录里）

```text
日期：
任务名称：
工具（哪一类、哪一个）：
任务书（要什么 / 给什么 / 边界 / 什么算完成）：
过程（它做了什么、我改了什么要求）：
结果（成了？差在哪？）：
这次学到的经验：
```

复制后每次新建一条，填空就行。**不用一次填满，跑完任务再补后面几行。**

### 一张填好的任务卡长什么样

这是小橙记的第一条：

```text
日期：9 月 3 日
任务名称：把《AI 应用工程入门》长文整理成学习笔记
工具：问答型（豆包）
任务书：
  要什么：学习笔记，100 字摘要 + 3 个概念（各配大白话解释）
  给什么：文章全文，分 3 段贴，每段先只读
  边界：只用原文，不确定写"原文未提及"
  什么算完成：摘要 100 字左右、概念正好 3 个、依据能搜到
过程：它先列了步骤；第一版给了 4 个概念，依据只写段号
结果：差一点。改一轮后达标，摘要 96 字
经验：要求写数字（3 个、100 字）比写"简洁"管用
```

### 好记录 vs 敷衍记录

| 敷衍记录 | 好记录 |
|-|-|
| "总结了一下文章，还行" | 记了工具、四要素、改了几轮、差在哪 |
| 只存最终结果 | 结果和过程都留 |
| "失败了" | "失败在它编了原文没有的数据，原因是我没写'只用原文'" |
| 每次都重写一遍 | 同样的任务，直接复制上次的任务书 |

> 判断标准很简单：**一个月后回头看，这张卡能不能让你少踩一次坑。**

### 为什么要记"过程"和"失败"

只存最终结果，你只能看到成品。

存过程，你能看到自己是怎么从不对变对的。**这段才是你真正长本事的地方。**

而且，失败的记录才是最好的模板——下次写任务书时，直接照着改。

### 记在哪

| 方式 | 适合 |
|-|-|
| 手机备忘录 | 最快，随时能记 |
| 飞书 / 石墨文档 | 方便按日期整理，能分享 |
| 一个 Word 文件 | 想攒成作品集时 |
| 纸质本子 | 喜欢手写的人 |

选一个就行，别在选工具上花时间。

### 记完这一笔，你就有东西了

| 你现在有的 | 它的用处 |
|-|-|
| 一份任务书 | 下次同样的任务直接复用 |
| 一张任务卡 | 回顾进步、写进作品集 |
| 一次失败记录 | 第 12 章"翻车现场"里你会有共鸣 |

## 照着做

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 打开备忘录，新建一条 | 空白页 | — |
| 2 | 填日期和任务名称 | 两行 | 名称写"把 X 整理成 Y"这种格式 |
| 3 | 填工具 | 工具名 + 类型 | 记不清类型就只写名字 |
| 4 | 填任务书四要素 | 四行 | 任务书还留着就直接复制 |
| 5 | 填过程：它做了什么、你改了什么 | 两三句话 | 想不起来就翻聊天记录 |
| 6 | 填结果：成了没、差在哪 | 一句话 | 别只写"还行" |
| 7 | 填这次学到的经验 | 一句话 | 实在没有就写"暂无" |

第 7 步是这张卡最值钱的一行。

## 常见错误

- **错误一：嫌麻烦不记。** 不记就等于每次从零开始，白学。
- **错误二：只记结果不记过程。** 过程才是经验来源。
- **错误三：只记成功的。** 失败记录更有用，写下来下次就避开了。
- **错误四：任务书没保存。** 存任务书，下次同类任务直接复用。
- **错误五：一天开十个记录文件。** 一个地方记就够了。

