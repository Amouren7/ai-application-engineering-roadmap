# 02｜本章验收与下一步

## 常见误区（本章汇总）

- **误区一：下载了 5 个工具，一个都没跑通。** 工具按任务选，先用一个，跑通再扩展。
- **误区二：把任务说得像发朋友圈。** "帮我搞一下"不是任务书，四要素齐全才算。
- **误区三：AI 做砸了就换工具重来。** 先在同一对话里补信息、改要求。重开会丢上下文，往往更糟。
- **误区四：只存最终结果，不存过程。** 过程（尤其失败和修改）才是你成长最快的地方。
- **误区五：急着让它一次做完大任务。** 大任务拆小步、逐步确认，是第 03 章的核心方法。
- **误区六：材料只贴一半，还指望它知道另一半。** 它会用常识补上，而且不告诉你。
- **误区七：它说"已完成"就当完成了。** 验收这一步只有你能做，外包不出去。

## 本章验收

跑完下面六条，这一章就算过关。都是可勾选、不用写代码的：

- [ ] 根据你的第一个任务，选定了合适的工具入口（不一定要装新的）；
- [ ] 用四要素（要什么 / 给什么 / 边界 / 什么算完成）写出一份任务书；
- [ ] 把材料给到了 AI 手里（贴文字、上传文件或分段贴，三选一）；
- [ ] 跑通了一次完整的"下任务 → 执行 → 验收 → 修改 → 交付"闭环；
- [ ] 至少卡住过一次，并用三招之一成功自救；
- [ ] 完成了一张任务卡记录。

六条里做到四条以上，就可以进第 03 章。没做完的，边学 03 边补。

### 自查：你的任务书能打几分

| 检查项 | 打钩 |
|-|-|
| 写了输出形态（表格 / 清单 / 几段话） | ☐ |
| 写了给谁看 | ☐ |
| 写了长度或条数上限 | ☐ |
| 材料明确给了（贴了或给了路径） | ☐ |
| 写了至少一条边界 | ☐ |
| 写了可打钩的完成标准 | ☐ |

六个勾全有，你的任务书就是合格线以上。

## 可选动手（想做就做，不做不影响主线）

### 练习一：文件级任务（建议用电脑）

如果你的工具能读文件，把一份真实的 Word / PDF / Excel 交给它。

任务可以这样写：

```text
读一下这份表格，把重复的行标出来，并说明你为什么判断它们重复。
不要修改原文件，把结果单独输出。
```

如果遇到"打不开文件""格式不支持"这类报错，**把报错原文复制给 AI**，让它教你解决。

这也是一次真实的驾驶练习。

### 练习二：三次对比实验（手机就能做）

同一件事，用三种写法各发一次，对比结果：

| 第几次 | 你怎么写 |
|-|-|
| 第一次 | "帮我总结这篇文章" |
| 第二次 | "总结成 3 条要点，每条一句话" |
| 第三次 | 第二次的基础上，加"只用原文，不确定写'原文未提及'" |

把三次结果并排看。你会清楚看到：**差别不在 AI，在你的任务书。**

## 本章小结

三句话：

1. 选工具看任务，不看热度——先用已有的跑通第一单。
2. 任务书就四个要素，写全了 AI 就能照做，你就能验收。
3. 闭环是五步：给材料 → 发任务书 → 看过程 → 验收 → 让它改。
