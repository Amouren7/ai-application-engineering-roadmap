## 这一章要带你走完一个闭环

上一章你认清了"会干活的 AI"长什么样，也选好了一件想交给它的真事。这一章就把它跑完。

先记住这一章最重要的一个词：**任务书**。

任务书就是你交给 AI 的那段话，里面写清四件事：

| 四要素 | 一句话 |
|-|-|
| 要什么结果 | 输出成表格、清单还是几段话？给谁看？多长？ |
| 给什么材料 | 它依据什么干活？原文贴出来还是给文件路径？ |
| 边界是什么 | 哪些事不许做？不知道的写"待定"还是瞎编？ |
| 什么算完成 | 你怎么判断它做完了？哪几条能打钩？ |

这四个词在 02.02 会完整讲一遍。这一章剩下的节，都是围着它转。

整个闭环只有五步：

| 步骤 | 你做的事 | 在哪一节 |
|-|-|-|
| 1 | 把材料给它 | 03 |
| 2 | 发出任务书 | 04 |
| 3 | 看它怎么做 | 05 |
| 4 | 验收 | 06 |
| 5 | 不满意就让它改 | 07 |

跑完这五步，你就拿到了人生第一个"AI 交付的成品"。以后所有任务，都是这个闭环的放大版。

| 你现在的状态 | 学完本章的状态 |
|-|-|
| 只会问它问题，它给你建议 | 会下任务，它给你成品 |
| 要求写得像发朋友圈 | 四要素齐全，AI 能照着做 |
| 结果不对只能重来 | 能定位是材料没给全还是要求没写清 |
| 干完就忘 | 有一张任务卡，进步看得见 |

## 贯穿案例：小橙的第一单

小橙不会编程，目标是做一个"文档学习助手"。

她的第一单不是做助手，而是**让 AI 把一篇长文章整理成学习笔记**。

这一章后面每节都用她的这单举例。你手上的任务不一样也没关系，流程完全一样。

### 小橙这一章会经过什么

| 节 | 小橙做的事 |
|-|-|
| 01 | 判断这单不用碰文件，选问答型 |
| 02 | 把"帮我总结一下"补成四要素 |
| 03 | 文章 4000 字，分 3 段贴，每段先只读 |
| 04 | 发出任务书：100 字摘要 + 3 个概念 + 原文依据 |
| 05 | 发现它给了 4 个概念、依据只写段号 |
| 06 | 四要素逐条核对，3 条不合格 |
| 07 | 一轮改对，摘要 96 字 |
| 08 | 中途卡在"提示超长"，用报错原文问它解决 |
| 09 | 记下第一条任务卡 |

### 你可以怎么用这一章

| 你的情况 | 建议 |
|-|-|
| 完全没跑通过 | 从 01 顺着学到 09，全程跟做 |
| 已经跑通过几次 | 只学 02、06、08 三节，补上方法和验收 |
| 时间只有 25 分钟 | 学 02 + 03 + 04，先写出你的第一份任务书 |

> 一句话：这一章不讲新方法，只让你把方法用一次，用完整。
