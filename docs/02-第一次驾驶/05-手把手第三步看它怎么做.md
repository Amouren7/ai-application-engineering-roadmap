# 02.05｜手把手第三步：看它怎么做

> 现在你在第 3 步：任务书已经发出去，它正在回话。

## 本节目标

在它干活的过程中，看出哪些信号值得留意。

## 一句话结论

> 别只盯结果。过程里已经藏了八成问题。

## 展开讲

任务书发出去，你有两种反应：等结果，或者看过程。

**看过程的人，验收时省一半力气。** 因为很多问题在过程中就露头了。

### 四个观察点

| 观察点 | 好的样子 | 危险信号 |
|-|-|-|
| 它先说什么 | 先说"我打算这么做"，列步骤 | 直接甩一大段结果，不提做法 |
| 它依据什么 | 引用你材料里的原话 | 出现材料里没有的名字、数字 |
| 它做了几步 | 分点、分段，对得上你的要求 | 一口气糊成一段 |
| 它有没有问你 | 材料不够时主动说"缺少 X" | 材料不够也照做，还做得很完整 |

第三条最容易看出问题。**你的任务书里有 3 条要求，它的输出就该有 3 块。**

### 好的 Agent 和差的 Agent

| | 好的 Agent | 差的 Agent |
|-|-|-|
| 开工前 | "我先做第一步，确认后继续" | 什么都不说，直接开干 |
| 遇到不确定 | "原文没写负责人，我标了'待定'" | 直接编一个名字 |
| 材料不够 | "你给的是摘要，无法给出原文依据" | 硬写几条依据 |
| 交付时 | "按你要求做了 3 块，第 3 块依据在第 2 段" | "已完成" |

右边那种不一定是工具差，很多时候是**任务书没写清**。两种可能都存在，先别急着换工具。

### 它开始跑偏的五个信号

| 信号 | 什么意思 |
|-|-|
| 输出比你要求的长很多 | 它把"顺便"的内容也加上了 |
| 出现你没给的人名、数字、链接 | 它在编 |
| 要求 3 条，它做了 5 条 | 它自己加了任务 |
| 只做了一条就收尾 | 它漏了要求 |
| 通篇形容词，没有具体内容 | 它在凑字数 |

看到任意一个，先别打断。**让它做完，然后在验收环节一次说清。**

### 什么时候可以中途打断

| 情况 | 怎么办 |
|-|-|
| 它开始编材料里没有的内容 | 立刻说"停下，只使用我给的原文" |
| 它跑去做完全不相干的事 | 立刻说"停下，只做我要求的三项" |
| 它在做一件不可逆的事（改名、删除、发送） | 立刻说"停下，先别动，等我确认" |
| 只是结果不满意 | 别打断，做完再说 |

第三条是铁律。**涉及改名、删除、发送、花钱的动作，永远先停下来问你。**

### 小橙看到了什么

小橙的任务书要求 3 块：摘要、3 个概念、原文依据。

AI 的输出：摘要有了，概念给了 4 个，依据那一条写着"根据文章第 3 段"。

她记下三件事：概念多了 1 个；依据只说了段号，没给原句；摘要她还没数。

**这三条就是下一节验收的检查项。**

## 照着做

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 看它第一句话有没有说做法 | 有步骤说明 / 直接给结果 | 没说也不影响，继续往下看 |
| 2 | 数它做了几块 | 和你任务书要求条数对上吗 | 多了少了都记下来，验收时说 |
| 3 | 扫一遍有没有陌生信息 | 人名、数字、链接 | 找到可疑的，去原文搜关键词 |
| 4 | 看它有没有主动说"缺什么" | 有 / 没有 | 没有也别怪它，可能你材料确实够 |
| 5 | 检查有没有不可逆动作 | 改名、删除、发送 | 有就立刻喊停 |
| 6 | 把发现的问题记在纸上 | 2–3 条具体问题 | 记不住就复制原文出来 |

第 6 步的问题清单，下一节直接拿来用。

## 常见错误

- **错误一：只看最后一段。** 中间跑偏了你没看见，验收时才发现，返工更贵。
- **错误二：看到不满意就立刻打断。** 打断会让它丢掉上下文，重新开始更慢。
- **错误三：把"它没问我要材料"当成好事。** 它不问，往往是在自己编。
- **错误四：看到数字和名字就信。** 尤其人名、金额、日期，一定要回原文核对。
- **错误五：忽略"不可逆动作"。** 改名、删除、发送、花钱，这四类必须先停。

## 本节练习

5 分钟。把上一节你发出去的任务书，回头看它的输出，数两个数：

```text
我要求了几条：【数字】
它做了几块：【数字】
有没有出现材料里没有的信息：【有 / 没有】
```

两个数字不一样，或最后一个是"有"，就在下一节验收时重点查。
