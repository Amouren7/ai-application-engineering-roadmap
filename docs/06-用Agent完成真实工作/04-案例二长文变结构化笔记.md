# 06.04｜案例二：3 万字长文变结构化学习笔记

## 本节目标

把一篇长文压成能复习、能核对的笔记，且每一条都能回到原文。

## 一句话结论

> 长文的价值不在字多，而在**能复习、能核对**。摘要和概念都必须能回到原文——回不去的，就是它编的。

## 展开讲

### 这个案例适合谁

| 适合 | 不适合 |
|-|-|
| 要读长报告、长讲义、长文档的人 | 只想看个热闹、不需要复习的人 |
| 需要把资料转成"能讲给别人听"的人 | 材料太短（一页纸直接读就行） |
| 手边只有问答型工具的人（门槛最低） | 要求它读完整个知识库的人（那是 07 章） |

> 场景：一篇很长的报告/讲义，想变成能复习的结构化笔记。
> 这个案例门槛最低，**问答型工具就能做**，也是小橙的起手案例。

### 成果长什么样

```text
摘要（100 字以内）：本文讲的是……（用原文事实概括，不加评论）

概念 1：上下文——就是 AI 这次"眼前看到"的全部信息。
概念 2：……
概念 3：……

原文依据：
- 摘要对应原文第 X 段
- 概念 1 对应原文第 Y 段
```

注意三件事：摘要不夹评论、概念用大白话、每条都标出处。

### 完整任务书示例

> 下面这段可以直接复制，把【】里的内容换成你的。

```text
你是我的学习助理，给零基础的我讲，用大白话和短句，不要用术语解释术语。

请把下面这篇长文整理成学习笔记，只使用原文，原文没有的不要补、不要推断。
要求：
1）摘要：100 字以内，只写原文说了什么，不要加你的评价、建议或结论；
2）关键概念 3 个：每个配一句给非专业人士看的大白话解释，不超过 40 字；
3）每条摘要要点和每个概念后面，标出对应原文第几段，引用原句里的说法；
4）原文里反复出现但没解释的词，归到"需要额外查证"一栏，不要自己解释；
5）不确定的地方标"【不确定：……】"，不要硬写；
6）不要开场白、不要总结段、不要客套话。

文章如下：
……（粘贴或上传）
```

### 验收标准

| 序号 | 验收项 | 怎么查 |
|-|-|-|
| 1 | 摘要在 100 字左右 | 数一下字数 |
| 2 | 摘要没写原文没有的结论 | 逐句回原文找对应 |
| 3 | 3 个概念是大白话 | 读一遍，有没有用术语解释术语 |
| 4 | 抽查一条"依据"能回原文找到 | 复制依据里的句子，原文里搜 |
| 5 | 没有夹带"建议""值得关注"这类评论 | 扫一遍全文找这些词 |

### 常见翻车点

| 翻车点 | 它长什么样 | 怎么防 |
|-|-|-|
| 摘要混入评价 | "本文观点值得深思……" | 任务书写"只写原文说了什么" |
| 依据给得太笼统 | "见第 3 章"（找不到具体句子） | 写"标第几段，并引用原句" |
| 用术语解释术语 | "上下文指模型的 context window" | 写"给非专业人士看的大白话" |
| 把没说的补上 | 摘要出现原文没有的数字 | 写"原文没有的不要补" |
| 概念挑得太偏 | 选了三个冷门词 | 写"选原文反复强调的 3 个" |

### 升级玩法：这就是小橙的雏形

跑通之后，让它再出一版"10 个检验你是否读懂的问题 + 答案 + 出处"。

> 这就是小橙"文档学习助手"最早的雏形。第 07 章她会把这个任务固化成一个小产品。

## 照着做

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 挑一篇 3000 字以上的文章 | 一篇长文 | 太长先截前三分之一试 |
| 2 | 复制上面的任务书，粘上文章 | 它开始输出笔记 | 文章超长就先分段，别一次塞太多 |
| 3 | 数摘要字数 | 100 字上下 | 超了就说"摘要压到 100 字以内" |
| 4 | 读 3 个概念，看是不是大白话 | 有一句看不懂 | 说"这句还是术语，换成大白话" |
| 5 | 抽 1 条依据，回原文搜 | 能搜到原句 | 搜不到就说"这条依据原文里找不到，请重标" |
| 6 | 扫一遍有没有评论句 | 出现"值得关注" | 说"删掉所有评价，只留事实" |
| 7 | 存下这份任务书 | 一个模板文件 | 加备注"用于长文笔记" |

## 常见错误

- **错误一：材料太长就一口气全塞。** 超出它一次能处理的范围，摘要会漏掉后半段。分段做。
- **错误二：不查依据就信了。** 依据这一列就是给你抽查用的，不查等于没验收。
- **错误三：嫌"大白话"要求啰嗦。** 不写这句，它给你的解释是"给同行看"的，你自己看不懂。
- **错误四：让它"顺便提点建议"。** 一提建议，摘要就开始编。
- **错误五：摘要超字数就算了。** 字数超说明它没抓住重点，压到 100 字以内它才会做取舍。

## 本节练习

8 分钟，手机就能做。找一篇你一直想读但没读完的长文：

```text
① 用本节任务书跑一遍；
② 抽查 1 条"依据"，回原文找到那句话；
③ 把摘要读给一个不懂这行的朋友听，问他"听懂了吗"。
```

第三步能听懂，说明"大白话"这一条达标了。
