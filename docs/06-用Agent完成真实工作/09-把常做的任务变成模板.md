# 06.09｜把常做的任务变成模板

## 本节目标

把跑通的任务书存成模板，下次改几个字就能复用。

## 一句话结论

> 好任务书长得都差不多——**要什么结果、给什么材料、边界是什么、什么算完成**。跑通一个就存一个，这就是你的个人模板库。

## 展开讲

### 你跑完六个案例会发现一件事

六个案例的任务书，骨架是同一个。

| 骨架 | 六个案例里对应什么 |
|-|-|
| 角色 + 读者 | "你是我的会议记录助理，给零基础的我讲" |
| 要什么结果 | 四列表格 / 四段周报 / 改名清单 |
| 给什么材料 | 纪要 / 长文 / 表格路径 / 零散记录 |
| 边界 | 不许编、不许改原文件、不许替你承诺 |
| 什么算完成 | 每条能回原文 / 原文件没动 / 有清单 |

> 差别只在中间那三行的具体内容。**所以模板能复用，不是每次从零写。**

### 什么样的任务值得存成模板

不是所有任务都值得存。判断标准是"频率"和"痛感"。

| 任务 | 每周做几次 | 值不值得存 |
|-|-|-|
| 周报 | 1 次 | ★ 值得 |
| 会议纪要 | 2–3 次 | ★ 值得 |
| 长文变笔记 | 不定期但很痛 | ★ 值得 |
| 一次性活动方案 | 一次 | 不值得 |
| 批量改名 | 偶尔 | 存"边界那几句"就够 |

> 判断口诀：**三个月内还会再做一次的，就存。**

### 模板怎么存：三件事

| 存什么 | 具体做法 |
|-|-|
| 任务书全文 | 存成一条笔记，标题写"用途_频率" |
| 可变的地方 | 用【】标出来，比如【材料路径】【命名规则】 |
| 一句话备注 | 写在最上面："这份用于周报，材料要给 10 条以上" |

### 模板命名法

| 好的命名 | 差的命名 |
|-|-|
| 周报_每周五用 | 模板1 |
| 会议纪要_待办提取 | 新建文档 |
| 长文笔记_含出处核对 | 未命名笔记 |

> 命名里带上"干什么用"，半年后你自己还认得。

### 复用模板的固定动作

模板不是复制粘贴就完事，复用时固定走三步：

| 步骤 | 动作 | 为什么 |
|-|-|-|
| 1 | 换掉所有【】里的内容 | 忘了换，它就去处理上一次的材料 |
| 2 | 检查边界那几句还在不在 | 边界最容易被删掉 |
| 3 | 看这次的翻车点有没有变 | 材料变了，风险也变了 |

### 小橙怎么做的

小橙跑完案例二之后，把"长文变笔记"的任务书存了下来。

| 她的动作 | 结果 |
|-|-|
| 存下任务书，标出可变处 | 一份带【】的模板 |
| 每次换材料名，其余不动 | 省掉 80% 的写字时间 |
| 三个月后回头看 | 这份模板成了她"文档学习助手"的说明书 |

> 第 14 章会专门教你怎么把模板越攒越多、越用越顺。
> 现在只养成一个习惯：**跑通一个任务，就把任务书存成模板。**

## 照着做

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 翻出本章你跑通过的那份任务书 | 一份能用的任务书 | 没跑通过就先跑一次再存 |
| 2 | 把里面的具体材料名换成【】 | 一份带占位符的模板 | 换漏了下次会误用旧材料 |
| 3 | 在最上面写一行备注 | "用于 X，材料要给 N 条以上" | 备注别写太长，一句就够 |
| 4 | 按"用途_频率"命名 | 一个好认的名字 | 想不出就写"周报_每周五用" |
| 5 | 存进一个固定位置（笔记 / 文件夹） | 你的模板库 | 位置要固定，别东一份西一份 |
| 6 | 下周复用一次 | 改几个字就能用 | 复用卡住就回来补占位符 |

## 常见错误

- **错误一：跑通就关窗口，不存。** 存模板只花 2 分钟，重写要 20 分钟。
- **错误二：存了但没标【】。** 下次你会漏换材料名，它就去处理上一次的材料。
- **错误三：模板里删了边界那几句。** 边界最容易被当成废话删掉，但它是最值钱的部分。
- **错误四：什么任务都存。** 一次性任务存下来只会占地方，你也不会再看。
- **错误五：命名太随意。** "模板1、模板2"——一个月后你完全不知道哪个是哪个。

## 本节练习

5 分钟，手机就能做。选本章你跑得最顺的那份任务书：

```text
① 复制全文；
② 把所有具体内容换成【】，如【材料】【命名规则】；
③ 顶部加一行：【用于 ____，材料要给 ____ 条以上】；
④ 命名保存：【用途_频率】，例如"周报_每周五用"。
```

存完，你就有了自己的第一个模板。**一个就够，别贪多。**
