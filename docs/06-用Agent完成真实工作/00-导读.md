# 06｜用 Agent 完成真实工作：文档、表格、数据、自动化

> 本章目标：建立"什么活能交给 Agent"的直觉，用六个真实案例练熟"写任务书 → 验收 → 纠错"这套动作。
> 学完本章，你手上会有 2–3 个真实工作产出，每个都带任务书和验收记录。

## 本章开始前：准备与产出

| 项目 | 说明 |
|-|-|
| 账号要求 | 一个能读写文件的 Agent 工具（办公综合型如腾讯 WorkBuddy，或开发型如 Codex / Claude Code）；纯问答型只能做案例二、五 |
| 能否只用手机完成 | 部分可以（整理、改写类）；文件级任务建议用电脑 |
| 主线要不要写代码 | 不需要。你写的是任务书，不是代码 |
| 安装软件 | 只做案例二、五的话不用装；做案例三、四要能读写本地文件 |
| 预计用时 | 约 2.5 小时，建议分 4–5 次学完 |
| 本章产出 | 2–3 个真实工作产出，每个都带任务书和验收记录 |

## 这一章在整条路线里的位置

前面五章你学会了写任务书、看过程、验收纠错。这一章不再教新概念，只做一件事：**真刀真枪干六件活。**

| 你现在的状态 | 学完本章的状态 |
|-|-|
| 知道任务书四要素，但只在小事上试过 | 六个真实场景都有可复制的任务书 |
| 不知道哪些活适合 Agent | 一眼能判断"这活该用 Agent 还是直接问" |
| 怕它乱改文件 | 会写"先只读 + 报计划 + 你确认"这条铁律 |
| 每次都要从零写任务书 | 手上有 1–2 个自己攒的模板 |

## 贯穿案例：小橙在这一章干什么

小橙的目标是做一个"文档学习助手"。
但她没有一上来就做应用。

| 她的阶段 | 在做什么 | 对应本章 |
|-|-|-|
| 练手期 | 拿六类活里的案例反复练，先把"指挥"练熟 | 03–08 节 |
| 沉淀期 | 把"长文变笔记"的任务书存成模板 | 09 节 |
| 下一步 | 把最常用的那个任务固化成产品 | 第 07 章 |

> 一句话：本章是她的**练习场**，不是她的产品。产品在第 07 章。

## 一个提醒

本章每个案例都给你一份"可以直接复制"的任务书。
但**复制不等于照抄**——你要把【】里的内容换成你自己的。

> 记住这条通用铁律，它贯穿全章：**先只读 + 报计划 → 你确认 → 再动。**
