# 06.01｜Agent是多步办事员：派活前先想清它怎么干活

## 本节目标

用"办事员"这个比喻，记住 Agent 干活的三个特征。

## 一句话结论

> Agent 就是你在心里雇的一个办事员：**分步干、有记录、会停下**。你的活是把"什么算做完、什么必须停下来问我"写进任务书。

## 展开讲

派活之前，先想清楚它到底怎么干活。它心里反复走这个循环：

```text
看任务 → 决定下一步 → 动手 → 检查 → 没做完就回去看任务，做完或干不动了就停
```

这个循环不长，但每转一圈都会消耗一点时间，也可能走偏一点。
所以你要理解它的三个特征，才知道任务书该写什么。

### 特征一：它分步干，不会一次做完

一个大任务会被它拆成几步，一步步来。

| 你给的活 | 它心里可能拆成 | 你要盯的地方 |
|-|-|-|
| "整理这个文件夹" | 先列清单 → 再分类 → 再改名 | 每一段之间有没有停下来问你 |
| "把纪要变成待办" | 先读纪要 → 再找事项 → 再填四列 | 四列里有没有它自己编的 |
| "把长文做成笔记" | 先读全文 → 再摘要 → 再找概念 | 摘要有没有超出原文 |

> 记住：它拆得对不对，决定结果好不好。所以任务书里最好自己先说清"分几步做"。

### 特征二：它靠"记在小本子上"推进

它记着自己做到哪一步、刚才查到了什么。
这个"小本子"就是这次对话的上下文。

人话解释：**上下文 = 它这次"眼前能看到"的全部信息。**

| 情况 | 小本子上还剩什么 | 后果 |
|-|-|-|
| 同一对话里继续 | 之前所有材料和要求都在 | 你补一句话它就懂了 |
| 你重开了对话 | 什么都不剩 | 你得从头再讲一遍 |

所以中途改要求、补信息，**别重开窗口**。

### 特征三：它必须有"停"的条件

合格的 Agent 该停时会停下来问你，而不是闷头乱干。

| 该停的时机 | 它应该做什么 |
|-|-|
| 做完了 | 交结果，附上改了哪些地方 |
| 连续失败 | 停下来报告"这条路走不通" |
| 需要你确认 | 涉及改、删、发，先问你再动 |
| 发现干不了 | 直接说"这个我做不了"，不要硬编 |

> 你不写"什么时候停"，它就默认一直干到底。这是最容易出事的一条。

### 什么活不该交给 Agent

反过来想，这个模型也回答了"什么活不用它"。

| 活的样子 | 用什么 | 为什么 |
|-|-|-|
| 步骤固定、闭着眼能背（把十个数加起来） | 普通 AI 一次问就行 | 没有"看结果再决定"的环节 |
| 下一步要看上一步结果才能定 | Agent | 这正是它擅长的 |
| 涉及改文件、删文件、发消息 | Agent + 确认点 | 需要"会停下"这个能力 |

> 一句话：**Agent 的价值，在"下一步要看上一步结果才能决定"的活。**

### 小橙的第一次体会

小橙让 Agent 整理一份 3 万字的产品文档。
它第一步先读全文、第二步做摘要、第三步找概念——每一步都等她点头。

她发现：**只要她中途补一句"概念要写给非专业的人看"，它下一步就改过来了。**
如果她当时重开对话，这一句就白说了。

## 照着做

拿你手上任意一件想交给 AI 的事，先做一次"办事员体检"：

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 写下这件事一句话 | 一句话任务 | 写不清就先挑更小的一件事 |
| 2 | 问：它能一步做完吗 | 不能 | 在任务书里写出"分几步" |
| 3 | 问：它需要记住前面的事吗 | 需要 | 全程别重开对话 |
| 4 | 问：哪些动作必须它停下来问我 | 改文件 / 删文件 / 发消息 | 把这几条写进边界 |
| 5 | 问：这活步骤固定吗 | 固定 | 固定就改用普通 AI 一次问 |
| 6 | 把 2–5 的答案写进任务书 | 一份带分步和确认点的任务书 | 漏了就补，尤其是第 4 步 |

## 常见错误

- **错误一：以为它能一次做完。** 大任务它必然分步，你在任务书里先写清分几步，它拆得才稳。
- **错误二：卡住了就重开对话。** 重开会丢掉它的"小本子"，进度全没。先在同一对话里补信息。
- **错误三：没写"什么时候停"。** 不写它就一直干到底，改错了你也不知道。
- **错误四：把固定的活也交给 Agent。** 简单算术、单次翻译，普通 AI 一次问更快。
- **错误五：只看它做完了没，不看它有没有越界。** 该停下问你的时候它没停，这是严重问题，比做错还麻烦。

## 本节练习

5 分钟，手机就能做。给一件你手上的事填这张体检卡：

```text
我要交给它的事：【一句话】
它能一步做完吗：【能 / 不能，分这几步： 】
它需要记住前面的事吗：【需要 / 不需要】
必须停下来问我的动作：【如"改文件前"】
这活步骤固定吗：【固定（改用普通AI）/ 不固定（用Agent）】
```

填完，你就知道这件事该不该派、派之前要写哪两句。
