# 06.05｜案例三：杂乱 Excel 变规范表格 + 异常标记

## 本节目标

学会让它"先只读报计划、你确认后再改副本"，并标出异常值。

## 一句话结论

> 改表格最容易翻车，就在于**直接覆盖原文件**。铁律只有一句：先只读并汇报计划，你确认后才动——而且只动副本。

## 展开讲

### 这个案例适合谁

| 适合 | 不适合 |
|-|-|
| 手里有填得乱、要交给别人的表格 | 表格很小（十行以内，手改更快） |
| 需要标出"哪些数据有问题"的人 | 指望它替你判断"正确值应该是多少"的人 |
| 愿意先看计划再放行的人 | 想一句"整理一下"就完事的人 |

> 场景：一份填得乱七八糟的表格，要整理干净并标出问题。
> 这一节开始涉及文件，所以要先换到**能读写文件的工具**。

### 成果长什么样：它先回报的计划

```text
我计划这样整理（现在还没动任何文件）：

1）统一列名：把"姓名 / 名字 / name"统一成"姓名"；
2）删除整行都是空的行；
3）"金额"列里为负、为 0 或明显超大的单元格标出来，单独列出；
4）输出一份"问题清单"，每条说明为什么算异常。

我不会直接改原文件，会另存副本再改。请回复"可以"我再动手。
```

看到最后两行，说明它守住了边界。

### 完整任务书示例

> 下面这段可以直接复制，把【】里的内容换成你的路径和列名。

```text
你是我的表格整理助理，只做整理和标记，不改数值、不做业务判断。

第一步：请先只读 D:\数据\客户表.xlsx，不要修改原文件，也不要移动或重命名它。
先向我汇报你的整理计划，内容包括：
1）准备统一哪些列名（列出"原列名 → 统一后列名"）；
2）准备删除哪些行，以及判断标准；
3）怎么判断"异常值"（例如金额为负、为 0、超过正常量级）；
4）准备输出几个文件、分别叫什么名字。

第二步：等我回复"可以"之后，再另存副本 D:\数据\客户表_整理版.xlsx 并在副本上修改。
原文件一个字都不许改。

第三步：把异常项单独列成"问题清单"，每条含：位置（第几行第几列）、原值、为什么算异常、建议你人工确认什么。
要求：
1）异常值只标出来、只列清单，不要替我改成"正确"的值；
2）不确定的地方标"【待人工确认】"，不要猜；
3）删除任何行之前，把被删的行也列进清单给我看一眼。
```

### 验收标准

| 序号 | 验收项 | 怎么查 |
|-|-|-|
| 1 | 动手前先给了计划并等你确认 | 看对话记录，它有没有先停下 |
| 2 | 原文件没被改动 | 打开原文件，看修改时间和内容 |
| 3 | 改动都在副本里 | 找"客户表_整理版.xlsx"是否存在 |
| 4 | 异常项单独列了清单 | 每条都说明"为什么算异常" |
| 5 | 被删的行在清单里出现过 | 对着清单核对删除行数 |

> 第 2 条最重要：**打开原文件亲自看一眼**，不要只听它说"我没改"。

### 常见翻车点

| 翻车点 | 它长什么样 | 怎么防 |
|-|-|-|
| 只说"整理一下"就开干 | 它删掉一堆"它认为没用"的行 | 任务书写死"先报计划等我确认" |
| 直接改原文件 | 原文件内容变了 | 写"另存副本，原文件不许改" |
| 把异常值改成"正确"的 | 负数被改成 0 | 写"只标出来，不要替我改" |
| 删行不打招呼 | 空行、重复行被静默删掉 | 写"删除前列清单" |
| 判断标准太主观 | "明显超大"它自己定 | 任务书里给出具体阈值 |

### 升级玩法

跑通之后，让它把"问题清单"再归类（缺数据 / 格式错 / 数值异常），
并给一句"这类错误以后怎么防"。

## 照着做

| 步骤 | 你做什么 | 会看到什么 | 不对怎么办 |
|-|-|-|-|
| 1 | 找一份真实但**不敏感**的表格，先备份一份 | 两个文件：原件 + 备份 | 没有就把表里人名替换成甲、乙、丙 |
| 2 | 确认你的工具能读写本地文件 | 能/不能 | 不能就换办公综合型或开发型 |
| 3 | 复制任务书，填上真实路径和列名 | 一份针对你表格的任务书 | 路径写错它会找不到文件 |
| 4 | 发出去，看它第一步做什么 | 它只读、然后给计划 | 它直接改了就立刻喊停，让它回到只读 |
| 5 | 逐条读它的计划 | 一份 4 点的计划 | 有你不认可的，回一句"第 2 点改成……" |
| 6 | 回复"可以" | 它开始动副本 | 它又去动原文件，立刻停，检查原文件 |
| 7 | 打开原文件亲自核对 | 内容没变 | 变了就用备份还原，重来一次 |
| 8 | 读"问题清单" | 每条都有理由 | 缺理由就让它补"为什么算异常" |

## 常见错误

- **错误一：不备份就让它动表格。** 第一步永远是备份。备份不花时间，返工很花时间。
- **错误二：只说"整理一下"。** 它只能猜"整理"是什么，猜错你返工。
- **错误三：让它替你填正确值。** 数值对不对是业务判断，它没有依据，只能编。
- **错误四：只看它说"我没改原文件"。** 它可能真的没改，也可能记错了。打开看。
- **错误五：异常判断标准留空。** "明显超大"必须换成具体数字，比如"超过 100 万"。

## 本节练习

10 分钟，需要电脑。挑一份不敏感的小表格：

```text
① 先备份原文件；
② 用本节任务书跑一遍，只做"第一步：报计划"；
③ 在它给计划的时候，故意回一句"第 2 点我不认可，改成……"，看它会不会照改；
④ 最后打开原文件，确认内容没变。
```

第 ③ 步是在练你的"确认点"——你要习惯在它动手前改它的计划。
