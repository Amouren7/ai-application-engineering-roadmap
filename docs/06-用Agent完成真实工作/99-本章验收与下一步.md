# 06｜本章验收与下一步

## 常见误区（本章汇总）

- **误区一：一上来就让它改原文件。** 涉及改、删、发的动作，永远先只读、先报计划、你确认后再动。
- **误区二：任务书只写"帮我整理一下"。** 不写"什么算完成、什么不许做"，它只能猜，猜错你背锅。
- **误区三：结果看都不看就交付。** "它说完成了"不等于完成了。表格和文件要抽查出处，原文件要亲自看有没有被动过。
- **误区四：做砸了就换工具。** 先在同一对话里补信息、改要求——重开会丢掉它"记在小本子"上的进度。
- **误区五：把敏感资料直接贴进去。** 公司数据、客户名单、账号密码，先想清楚能不能给（详见第 08 章）。
- **误区六：把"待定""待确认"当成失败。** 它标"待定"是守规矩；硬填才是问题。
- **误区七：让它替你承诺或决定。** 时间、金额、同意，这些必须你来。它只出草稿。

## 本章验收

- [ ] 完成至少 2 个本章案例，每个都有任务书 + 验收记录
- [ ] 每次涉及改文件/删文件的活，都先让它"只读 + 报计划"并等你确认
- [ ] 能说出 Agent 干活的三个特征：分步干、有记录、会停下
- [ ] 能说出一件"步骤固定、不用开 Agent"的活，和一件"必须用 Agent"的活的区别
- [ ] 把你最常用的一类任务书存成了模板（哪怕只存一个）
- [ ] 能指出六个案例里最危险的那个（案例四批量文件整理），并说出它的铁律

## 本章小结

三句话：

1. **Agent 是分步办事员**——分步干、有记录、会停下。你的活是写清"什么算做完、什么必须停下来问我"。
2. **六个案例练的是同一套动作**——写任务书、先只读、看清单、验收、纠错。
3. **跑通一个就存一个**——模板是你最省时间的资产。

## 可选动手（想做就做，不做不影响主线）

**只读扫描练手：** 挑一个真实的文件夹（别太大），让 Agent 只列清单、不改任何东西。

```text
请只读扫描 D:\下载\ 下所有文件的名称和类型，按类型分类列成表格。
先不要移动、不要改名、不要删除任何文件。
```

观察它有没有遵守"只读"边界。

- 它守住了 → 说明这个工具的边界意识可以，可以继续用它处理重要资料。
- 它未经你同意就动了文件 → 恭喜你发现了它的问题。**这正是你要练的"验收"能力：先看它有没有越界，再决定要不要继续用它。**
