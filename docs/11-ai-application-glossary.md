## 附注词：主线不深讲，想深究看附录

这几个词主线只用一句话带过，不用现在搞懂。想真正弄明白，去看附录《真正的工程进阶》。

| 词 | 一句话人话 |
|-|-|
| API | 让两个程序之间"点菜下单"的接口：点哪道菜，就返回哪道菜 |
| Token | 模型算文字多少的计量单位，像"字数"但又不完全等于字数 |
| JSON | 一种让程序能读懂的、规规整整的数据格式 |
| Git | 记录文件每次改动、能回退的"存档系统" |
| 命令行 | 在黑窗口里敲命令让电脑干活的方式 |
| 编程语言 | 人写给电脑看的指令语言，比如 Python |

## 查词的正确姿势：先描述现象

遇到新词别硬背。先用大白话说清"我看到的现象"，再回来查词：

- "同一个问题每次回答不一样" → 和模型、幻觉有关；
- "答案引用了不存在的段落" → 幻觉；
- "它说完成了，但文件没变" → 去看 diff、日志。

## 容易混的词，一句话分清

- **聊天 AI vs Agent**：一个给答案，一个给结果。
- **模型 vs 工具**：模型是"脑子"，工具是"手"。
- **任务 vs 任务书**：任务是"那件事"，任务书是"把事说清楚的纸"。
- **验收 vs 测试集**：验收是每次收货验一次，测试集是固定考题反复用。

## 常见误区

- **误区一：把词典当课文从头背。** 词典是备查手册，用到哪个查哪个，背下来没用。
- **误区二：看到英文缩写就慌。** 大多数缩写背后就是一件很日常的事，类比一下就好懂。
- **误区三：为了"显得专业"硬用术语。** 任务书写清楚，比用词高级重要一百倍。
