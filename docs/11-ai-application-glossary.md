> 词典不是让你背定义，而是帮助你在遇到问题时快速定位：这个词在系统哪一层、它解决什么问题、它不解决什么问题。

## LLM / Token / Context

- **LLM**：处理语言的模型。能生成合理文本，不等于事实永远正确。
- **Token**：模型处理文本的计量单位，影响容量、延迟和成本。不是“一个汉字一定等于一个 Token”。
- **Context**：本次调用真正提供给模型的信息。模型没看到的内容不能指望它稳定使用。

## Prompt / Structured Output / Embedding

- **Prompt**：任务、角色、限制和输出要求的组合。不是越长越好，而是要减少歧义。
- **Structured Output**：让结果符合字段和类型，方便程序继续处理。仍然要做业务校验。
- **Embedding**：把文字表示成可比较的向量，常用于语义检索。它不负责判断资料真假。

## Retrieval / RAG / Citation

- **Retrieval**：从外部资料中找相关内容。
- **RAG**：把检索结果放进上下文，再让模型生成答案。
- **Citation**：告诉用户答案依据来自哪里，便于复核。引用错了仍然是错误。

## Tool / Workflow / Agent

- **Tool**：程序提供给模型调用的一项具体动作。
- **Workflow**：步骤和分支预先设计好，适合稳定流程。
- **Agent**：根据状态动态选择下一步的循环系统，必须有工具边界和停止条件。

## Memory / State / Trace

- **State**：当前任务的结构化状态，例如已检索片段和重试次数。
- **Memory**：跨步骤或跨任务保存的信息；保存前必须考虑隐私、期限和删除。
- **Trace**：一次请求经过各步骤的记录，用于定位延迟和错误。

## Evaluation / Guardrail / Fallback

- **Evaluation**：用固定样例和指标判断修改是否真的变好。
- **Guardrail**：可执行的边界，如工具白名单、金额上限和人工确认。
- **Fallback**：主路径失败后的安全替代路径，如拒答、重试、转人工。

遇到一个新名词时，先问三句话：它在哪一层？解决哪个具体问题？如果不用它，最简单的替代方案是什么？

## 小测验

“用户问公司制度，系统需要找到原文并附引用”至少涉及哪些词？

参考：Context、RAG、Retrieval、Citation，可能还涉及 Embedding 和 Evaluation；不一定需要 Agent。

## 进一步小白练习

## 继续补充几个容易混淆的词

- **Temperature**：影响生成随机性的参数，像让回答者更保守或更发散；它不能修复缺少资料的问题。
- **Hallucination**：模型生成了没有依据的内容，像自信地补写不存在的规定；需要资料约束和校验。
- **Fine-tuning**：用示例调整模型行为，像训练表达习惯；不等于自动获得实时知识。
- **Chunk**：知识库中的文本片段，像把书拆成便于查找的卡片；切得太小会丢上下文，太大又难检索。
- **Metadata**：片段的附加信息，如来源、日期、部门和权限；像卡片背面的分类标签。
- **Rerank**：对初步检索结果重新排序，像图书管理员把最相关的几本放到最前面。
- **Idempotency**：同一个写入请求重复执行，结果仍只产生一次；像快递单号不能因为点击两次就发两件货。
- **Latency**：一次请求花费的时间；要拆成模型、检索、工具和网络分别测量。
- **Webhook**：外部系统主动通知你的回调地址；像快递到了主动发短信，而不是你每分钟去问一次。
- **Rate Limit**：服务允许的调用频率上限；遇到 429 时应退避或排队，不是无限重试。

## 术语学习法

每学一个词，写一个“反例”：它不能解决什么问题。例如 Embedding 不能验证事实，RAG 不能替代权限，Agent 不能自动获得外部系统的管理权。

从你正在学习的章节中选 5 个词，分别写“一句话定义、一个日常类比、一个不能做的事、一个小实验”。

## 第二轮小白练习

## 按问题查词，而不是按字母背词

当“回答不靠谱”时，优先查 Hallucination、RAG、Citation、Evaluation；当“动作执行错”时，优先查 Tool、Workflow、Idempotency、Guardrail；当“系统变慢”时，优先查 Latency、Token、Caching、Rate Limit。

把词放回问题里，才能知道它是不是解决方案。例如 RAG 适合补充外部资料，但不能修复错误权限；Temperature 影响表达随机性，但不能让过期制度变成最新制度。

## 收尾小白练习

## 读词典时的一个小方法

先用中文描述你遇到的现象，再反查术语。例如“同一个问题每次回答不同”可能涉及随机性和 Evaluation；“答案引用了不存在的段落”可能涉及 Hallucination 和 Citation。先描述现象，可以避免被英文名词带着走。
