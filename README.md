# 普通人 AI 应用工程学习路线

> 这是一套面向零基础学习者的项目式教材：先用人话理解，再做最小练习，最后用失败案例和评估证据验收。

## 建议阅读方式

不要一次读完整个仓库。每天只完成一章中的一个小任务，并留下运行结果、失败记录或一段自己的解释。

1. 先读 00，确定起点和项目方向；
2. 按 01 → 10 逐章学习；
3. 遇到术语查 11，遇到故障查 12；
4. 用 13 记录证据，用 14 让 AI 做导师和审查者；
5. 用 15 学习真实仓库，用 16 跟踪生态变化。

## 贯穿案例

全路线围绕一个逐步升级的“文档学习助手”：

```text
文字总结 → 结构化输出 → 文件输入 → Workflow
        → RAG 与引用 → Agent Loop → 外部系统
        → 评估、权限、日志、部署和 GitHub 作品集
```

## 能力地图

| 阶段 | 学会什么 | 交付证据 |
|-|-|-|
| L0 | AI 工具与 Coding Agent | 能拆需求、读 diff、复现问题 |
| L1 | Python、CLI、HTTP、JSON、Git | 能独立运行和排查小程序 |
| L2 | LLM API、Prompt、Context、结构化输出 | P1 文档分析助手 |
| L3 | Tool Calling、Workflow、状态和确认 | 可控的多步流程 |
| L4 | RAG、Embedding、检索、引用和评估 | P2 知识库助手 |
| L5 | Agent Loop、Memory、Retry、Stop Condition | 有边界的 Agent |
| L6 | Skill、MCP 和外部系统 | 一个安全的只读集成 |
| L7 | 质量、安全、日志、成本、部署和回滚 | 可交付系统 |
| L8 | 真实项目、作品集和面试表达 | P3 完整项目 |
