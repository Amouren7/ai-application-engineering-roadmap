# 普通人 AI 应用学习路线：零代码"Agent 驾驶"版

> 面向**纯零基础**的职场人和学生：不写代码，学会指挥 AI Agent（豆包/Kimi 网页版 → 腾讯 WorkBuddy → OpenAI Codex / Claude Code）把真实工作与 AI 应用做出来。
> **代码让 AI 写，你负责指挥和验收。**

## 这是一门什么课

很多人以为"会用 AI 做应用"必须先学编程。现在不需要了：新一代 **Agent 工具**（Codex、Claude Code、WorkBuddy 等）不只是回答你，还会**替你执行**——读写文件、跑程序、按你的要求一步一步把任务做完。

这门课教你的，是**驾驶这类工具的能力**：

1. 把模糊的想法拆成 AI 能一步步执行的任务（任务书方法）；
2. 看懂它干了什么、改了什么，判断结果对不对（验收）；
3. 不对时怎么让它改、卡住时怎么救回来（纠错）；
4. 知道什么能交给它、什么绝不能交（边界）。

不教什么：不逼你背 Python 语法、不要求你手写代码。主线里的代码只会以"阅读样例"出现——你只需要看懂大意。

## 适合谁

- 零基础，但想用 AI 真正干成事（整理资料、做表格、写文档、做自动化）；
- 想做一个能回答自己资料问题的"知识库小助手"，但不会写代码；
- 只会拿 AI 聊天，想升级成"让 AI 替我干活"；
- 未来想转 AI 应用方向，但不确定要不要先学编程。

## 你会学到什么（能力地图）

| 阶段 | 学会什么 | 你的成果 |
|-|-|-|
| L0 | Agent 能干什么、不能干什么 | 一张想交给 AI 的任务清单 |
| L1 | 第一次驾驶：跑通第一件真事 | 第一条完整任务记录 |
| L2 | 拆任务、写任务书（核心方法） | 一个被拆成 3–5 步的大任务 |
| L3 | 验收与纠错：判断对不对、让它改 | 一次"从失败到修好"的复盘 |
| L4 | 用 Agent 完成真实工作 | 3 个真实工作产出 |
| L5 | 指挥 Agent 做出 AI 应用 | 一个能运行的应用 |
| L6 | 安全、成本、边界 + 沉淀模板库 | 个人任务书模板库 |

## 你需要准备什么

| 准备项 | 什么时候要 | 说明 |
|-|-|-|
| 一个 AI 聊天工具（豆包/Kimi/DeepSeek/ChatGPT） | 今天就要 | 手机或网页都行，第 00 章即可起步 |
| 能上网的电脑 | 第 02 章起 | 做文件级任务时需要 |
| 邮箱 | 注册工具时 | 一个即可 |
| API 预算（少量） | 第 07 章做应用时 | 调用云端模型按量计费；体验期多用免费额度 |
| 编程环境 | 主线始终不需要 | 想学编程再看《附录：真正的工程进阶》 |

## 工具怎么选（分阶段，不锁死一家）

| 阶段 | 工具类型 | 代表 | 用途 |
|-|-|-|-|
| L0–L3 | 问答型 | 豆包 / Kimi / DeepSeek / ChatGPT | 练提问、练任务书、练验收 |
| L1–L3 | 办公综合型 | 腾讯 WorkBuddy 等 | 感受"替你干活"、文件级任务 |
| L4–L6 | 开发型 | OpenAI Codex / Claude Code / Cursor | 做应用、文件与代码级工作 |

教程按"通用方法 + 工具对照"组织：某工具不可用时，用对照表找等价路径即可。

## 阅读顺序

主线：**00 → 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10**（每章约 25–40 分钟 + 一个小练习）。

- 随时查：11 词典（术语人话版）、12 翻车现场（错误自救）、13 任务台账（记录模板）；
- 开工必备：14 任务书与提问模板库（复制即用）；
- 进阶可选：15（看懂 Agent 的代码）与《附录：真正的工程进阶》——想学编程再看；
- 不要一次读完一章：学一点、做一点、记一笔，任务卡是进步的证据。
